# 色彩艺术指导

用于整稿配色、品牌与语义冲突、数据编码、图文共色和深浅场切换。不按行业关键词选色，也不以颜色少作为高级感标准；事实与明确品牌硬约束、可读性及语义辨识优先于装饰。技术取值在 `scripts/policy.json`。

## 1. 先定颜色职责

背景场建立页面明度；中性墨阶区分主标题、正文和辅助；品牌色保证识别；强调色指向结论或行动；状态色表达增长、风险等；数据色区分类别或顺序。同一色可兼任角色，但不得让语义混淆。强调的稀缺按**职责**而非次数计：同一结论在标题和图形中呼应是两处同一用途；若有多个必须区分的状态，不应为了“唯一强调”抹掉它们。

硬性品牌值不可擅改，但可以改变位置、面积或角色；亮黄不必作白底正文，可用于色条或深色背景上的锚点。品牌识别、状态含义、关键数据和文字对比不能兼得时，先遵守硬约束并保证阅读与语义，写明取舍与风险。

## 2. 明度结构先于色相

先看背景明暗与观看环境，再建立主、正文、辅助的可辨墨阶和必要语义，最后选色相、饱和度与冷暖；这个顺序可随品牌和素材约束回看，不是不可逆配方。深底同样要有适合该场的前景层级；具体档数和数值由内容、字体与渲染决定。

叠图或渐变文字看**字形实际落点的最不利背景**，不是平均颜色。墨色相同，面积、字重和材质不同，视觉重量也不同。暖白背景可以减少强白刺激，但如果投影或品牌环境不适合，应换方案而不是套用暖白。

## 3. 面积、重量与稀缺

高饱和小色块也可能很重；大面积强色容易抢占阅读，应以任务判断面积与明度。中性色可以承载层级，但不是“不用颜色”——需要辨识多个状态或分类时，保留必要色与非颜色编码。失败信号：每个标题、边框和图标都刷品牌色，或每处都高亮，主张反而找不到。

## 4. 语义与深浅场

同一语义跨页保持一致；不同市场的红绿涨跌约定先确认。明暗切换可用于转折、开场或收束，也可由素材与可读性要求决定；切换时检查标题、正文、辅助文字、轴线、图标、图表系列及页码在新背景上的对比，而非只换底色。全出血图的页码角区明暗可能与页面底色不同，应按实际图像声明 `page_number_tone`。

## 5. 图像、材质与字体协同

真实证据图不为统一色调而改变事实颜色；页面用中性层级承接。概念图可按页面反推色域、落字区明度与主光，但不能用调色遮掩主体结构错误。图中突然出现的大面积强色可能改变全稿重心，应看最终裁切与相邻页后决定重选素材、调整版面或配色。

## 6. 数据色

先判断关系：分类要可区分；有序数据可用方向明确的明度阶；发散色应围绕有意义的中心；重点系列或异常项可与中性背景拉开。已确认、假设和缺失需直接写明，并辅以线型、标记或分组，不能只靠颜色或透明度；数量流中颜色用于追踪身份，宽度若编码数量须另行核算。深浅场与不同页面保持同一语义，避免仅靠红绿区分；不能为减少色数合并本来不同的类别。

`palette` 按消费位置排列：柱／线按系列，饼／环按类别，单系列柱图 `highlight_category` 用首色、其余退策略中性色。退隐不等于消失——那些柱仍承载数值，所以中性色由编译器按**当页底色**兜底到 `min_contrast` 之上，只动明度不动色相；底色偏离默认白时会以 INFO 披露调整后的 HEX。先在视觉概念中确定映射；编译器检查数量、重复与技术对比风险，不判断配色美感或统计意义。

## 7. 一致与变化

锁定角色、语义与字族墨阶；允许面积、明暗场与密度随页面职责变化。缩略图可转灰度检查：峰值与停顿是否仍可辨、深浅页正文是否同样可读、重点是否真的服务结论。灰度可读不代表色彩语义或色觉可访问性已完整验证。

## 8. 常见冲突与修正

1. **品牌亮色在白底不可读**：保留品牌值，换角色或背景；关键文字另用合适墨色。
2. **图片自带强色**：收敛其他装饰；不修改纪实证据，叠字找连续安静区。
3. **深浅混排**：检查整套前景、系列和页码，不只替换背景。
4. **透明／渐变／阴影**：只在确有层次或承托需要时使用；逐字形落点检查，不以平均色代替。
5. **不能兼得**：记录硬约束、实际折中和剩余风险；必要时拆分信息或请求决策。

## 9. 程序能测什么

程序可计算颜色亮度、可还原图层的合成背景与对比分布；图表或无法还原的图层须标 `UNCERTAIN` 并人工确认。可测对比不等于美感、完整无障碍审计或目标投影实测；字体替换时字形位置只代表替代字体。表现力、语义是否稳定与图文是否同族，必须看真实渲染。

## 10. 修正与交付

按根因依次检查语义错误、可读性、层级、数据辨识、跨页一致，再处理冷暖细节；不要因一处问题推翻整套色板。局部任务给角色与具体调整；整稿写明明暗基调、色值角色、数据映射和切换依据；高约束任务补关键对比实测与例外。实际观感与未验证项如实报告。

## 11. 大胆、丰富、戏剧化：高级感不等于低饱和

**“高级”不能用“低饱和＋低对比＋灰白”来定义。** 以下系统都可能是成熟方案，区别只在于职责与执行，而不在“克制”本身：

| 方向 | 适用语境 | 风险 |
| --- | --- | --- |
| 精密中性 | 专业报告、咨询、金融，靠墨阶与留白建立秩序 | 易显冷、显空、缺乏记忆点 |
| 高饱和品牌场 | 消费、科技发布、文化事件，大面积强色建立识别 | 抢占阅读、色觉疲劳、投影偏色 |
| 双互补撞色 | 冲突、转折、强对比主张 | 过度对抗、破坏层级 |
| 多色族系统 | 多类别数据、复杂生态、机构品牌 | 类别不可辨、重心漂移 |
| 深色戏剧场 | 发布会、夜间、沉浸式结论 | 前景墨阶没拉开、图表编码失效 |
| 暖色编辑场 | 人、食物、生活方式、叙事 | 与冷数据并置时语义错配 |

使用强色时，用以下手段保持专业秩序：① 强色只在“主视觉场”与“强调”出现，其余交给中性墨阶；② 用明度而非色相承担层级——深底上的浅字、浅底上的深字先成立；③ 强色面积受控（小色块/色条/锚点），不是铺满；④ 跨页保持同一套色相与语义，靠面积与明暗制造变化；⑤ 投影/低亮度下先测对比，必要时降饱和保可读。

## 12. 数据色板库（可直接调用，须按语义而不是按美观选）

色板不证明结论；类别可辨、顺序可读、状态无误才是职责。下列为起点，整套必须保持语义一致。

- **分类色（categorical）**：用于互斥类别，彼此可辨且对常见色觉缺陷友好。示例（对红绿色盲较稳健）：
  `#2F5597 蓝 / #C55A11 橙 / #2E7D5B 绿 / #6A4C93 紫 / #B08505 赭 / #1F9DAA 青`。避免使用仅靠“红/绿”区分的状态或类别。
- **顺序色（sequential）**：用于数值由低到高，明度单调推进。浅→深同色相：`#F2F4F7 → #9AA7B8 → #4B5B70 → #1B2735`（冷灰蓝），或暖调 `#FBF3E7 → #E6B97A → #B5651D → #5C2E0E`。
- **发散色（diverging）**：围绕有意义中心（如 0、基准、均值），两端为冷暖对比：`#2E5C8A（低/冷）→ #EDEFF2（中心）→ #B23A3A（高/暖）`；中心须有明确语义，否则改用顺序色。
- **状态色（state）**：成功/增长、警示、风险。建议固定：`#1E7A46 通过/增长`、`#B58500 注意`、`#B23A3A 风险/下降`。涨跌红绿须先确认市场约定，且与分类色共用同一语义规则。
- **强调锚点**：单一品牌强调色用在指向结论或行动处，整稿稀缺；多条必须区分的状态不要为“唯一强调”而抹掉。

色弱友好检查：把整稿缩成灰度，确认类别与状态仍可按明度区分；仅靠色相的差异在灰度下消失的一律补线型/标记/标签。

## 13. 深浅场策略与前景墨阶

深浅场切换必须有叙事或阅读依据，且**成套切换前景**，不是只换底色：

- **浅场（默认）**：前景墨阶 `#111827 主 / #374151 正 / #6B7280 辅`；图表编码在浅底上用 §12 分类色。
- **深场（#0B1220 / #111827 级）**：前景 `#F3F4F6 主 / #D1D5DB 正 / #9CA3AF 辅`；图表系列须换成在深底上可辨的明度/彩度（浅底色板直接搬来会“沉下去”），图表标题/轴/网格用深场样式（`chart.style.dark`）。
- **判断**：远距离发布、沉浸结论、夜间用深场；长文深读、数据密用浅场。不要为“变化”而无逻辑切场；相邻页切场时核对页码、来源、图注在新底上的对比。
- **全出血图**：页面底色与角区明暗可能不同，按实际图像声明 `page_number_tone`，页码墨色随场走（policy `page_number.ink`）。

## 14. 整稿色彩节奏

色彩像乐谱一样需要节奏，不是每页同色同面积：

1. 锁定：主色相、语义色、字族墨阶、主要对齐轴——逐页稳定（识别来源）。
2. 放开：面积、明暗场、图像占比、密度——随本页叙事职责变化。
3. 递进：随论证推进，强调色可从“单一锚点”逐步放大到“结论高潮的全场强色”；转折页可用一次强撞色制造停顿。
4. 自检：缩略总览里，峰值页（最强色/最大数字）是否确实是内容最重要的一页；灰度下峰值与停顿是否仍可辨。

## 15. 色觉无障碍与灰度自检

- 文本对比以 WCAG 为技术下限（普通 4.5:1、大字 24pt+ 3:1），但这是“可辨”不是“好看”；图表内的小标记、细线要更宽余量。
- 不要只用色相区分关键信息；线型、标记形状、直接标签、位置都应承载含义。
- 投影/低亮度/老旧屏幕会压缩对比：高约束演示先实测，必要时降饱和、加描边或换墨色。
- 灰度自检不可替代完整无障碍审计，也不替代目标环境（G-TGT）实测。

## 16. 可直接套用的色板配方（按角色，不按风格）

| 配方 | 主视觉场 | 中性墨阶 | 强调/语义 | 适用 |
| --- | --- | --- | --- | --- |
| 精密蓝灰 | `#2F5597` 场 + `#EEF2F7` 浅底 | `#111827/#374151/#6B7280` | `#C55A11` 橙锚点 | 咨询/金融/战略 |
| 暖编辑 | `#8A5A2B` 赭 + `#FAF4EC` 暖白 | `#2B2118/#5A4A3A/#8A7B6B` | `#1E7A46` 绿（通过） | 人/食物/生活方式 |
| 深场发布 | `#0B1220` 深底 + `#111827` | `#F3F4F6/#D1D5DB/#9CA3AF` | `#E0533D` 珊瑚强调 | 发布/夜间/沉浸 |
| 多色生态 | 浅底 + 六色分类族 | 中性墨阶 | 状态三色 | 多类别/平台/机构 |
| 双互补撞 | `#1D3A5F` 深蓝 × `#E0A21A` 金 | `#1A1A1A/#444` | 撞色即强调 | 冲突/转折主张 |
| 冷数据 | `#0E2A3B` 深青场 + 顺序蓝 | `#E8F0F4` 浅字 | `#B23A3A` 发散端 | 数据密集报告 |
