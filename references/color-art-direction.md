# PPT 配色艺术指导规范

本文件是 `ppt-visual-art-director` 的条件性设计资源，仅在**整稿配色系统设计、品牌色/状态色冲突、复杂数据可视化编码及对比度无障碍验证**时按需读取一次。本规范不提供固定色卡，不按行业标签预设色系，而是指导 AI 建立职责清晰、明度稳健、语义一致且可验证的色彩秩序。

## 一、配色决策准则与冲突优先级

### 1.1 三项基本准则

1. **功能先于色相**：任何颜色进入调色板前，必须能说明承担什么功能、为何用该明度/对比关系表达、以及如何检验有效。
2. **明度先于色相**：先确定浅底/深底明度结构与前景文字可读性，再决定色相、冷暖与饱和度；明度接近时色相再协调也会导致阅读模糊与类别难辨。
3. **系统稳定，单页可变**：全篇锁定色彩角色与语义映射；单页的底色深浅、色块面积与对比强度随页面职责（开场、论证、数据、转折、收束）有据变化，不把同一配色比例机械套用到每一页。

### 1.2 冲突裁决优先级

当品牌要求、业务语义、画面表现与既有素材冲突时，严格按序裁决：

```
1. 硬性约束与基本可读性（合规要求、不可改品牌色值、前景背景可辨识度）
＞ 2. 内容语义与数据真实性（严禁颜色颠倒涨跌、风险或分类含义）
＞ 3. 视觉层级与阅读秩序（主结论、关键数据与辅助信息层次分明）
＞ 4. 跨页一致性与节奏（角色复用稳定，避免全篇高饱和视觉疲劳）
＞ 5. 审美张力与氛围表现（冷暖细腻度、情绪基调与材质质感）
```

## 二、七类功能色彩角色

以功能角色构建调色板，而非先挑几个颜色再随意涂抹（一个色值可兼任多角色，前提是不发生层级或语义冲突）：

| 角色 | 核心职责 | 使用边界 |
| --- | --- | --- |
| **Background** | 建立页面基础明度场，以连续场域承载信息与图像 | 大面积背景保持干净连续，避免用零碎浅灰/浅色卡片底块切碎背景场；高饱和底色仅限明确转折页 |
| **Neutral** | 承担正文、次级标题、发丝分割线、坐标轴与注释 | 整稿保持统一的冷暖灰阶；分割优先用低对比单向发丝线而非四边封闭描边 |
| **Primary** | 建立品牌或主题识别与核心结构锚点 | 用于关键结构与识别位，不把所有标题、边框、图标全部刷成主色 |
| **Secondary** | 辅助分区、次级对比系列或温和过渡 | 视觉权重严格服从 Primary 与 Accent，不抢夺主视线 |
| **Accent** | 聚焦唯一结论、关键指标、转折点或行动项 | **严格稀缺**；整页多处高亮等于无重点 |
| **Semantic** | 表达正向/增长、警示、风险/下降等业务状态 | 结合受众认知与行业约定确定（注意国内外金融涨跌红绿习惯差异），**全篇绝对稳定，严禁中途互换** |
| **Data** | 编码图表的分类、顺序、发散偏差与重点系列 | 服从数据结构，不用装饰性彩虹渐变掩盖真实数值关系 |

### 调色板推导与角色说明（复杂任务按需输出）

按 **视觉意图与场景约束 → 浅/深明度骨架 → 可解释的色相/对比关系 → 面积与邻接校验** 推导调色板。单页局部优化无需输出完整色卡表；整稿规范化或高约束协作任务可按需输出：`Role` ｜ `HEX` ｜ `Purpose` ｜ `Allowed Uses` ｜ `Restrictions` ｜ `Contrast Pair` ｜ `Semantic Mapping` ｜ `Notes`。

## 三、数据可视化配色规范

先判断数据的数学与业务关系，再选择编码方式，**且复杂或关键状态图表绝不单靠颜色唯一编码**（同步配合直接数值标注、线型、标记形状、排序或分组）：

- **分类数据（Categorical）**：区分无序独立类别。控制同时出现的高区分度色相数量；类别过多时优先排序合并为“关键项＋其他（中性灰）”或直接标注，不用难以分辨的相近色硬撑，并避开红绿纯色互混。
- **顺序数据（Sequential）**：表达由低到高、由弱到强的连续或分段量级。使用方向明确的明度阶梯（辅以适度饱和度变化），确保数值大小与视觉深浅严格同向。
- **发散数据（Diverging）**：表达围绕明确中心基准（如 `0%`、盈亏平衡线、行业均值）的正负偏离。中心值保持中性低饱和，向两端对称增强双色相/明度对比，绝不用于普通单向增长数据。
- **重点系列与状态突出**：在多系列图表中，仅给支持本页核心主张的目标系列或异常风险项赋予 Accent / Semantic 强色，其余对比系列一律退回稳健中性色阶，一眼锁定结论。

## 四、高发冲突场景处置

1. **受限品牌色可读性不足**（如白底上的亮黄、浅青品牌色）：**保留精确品牌 HEX 色值不擅改**，将其转为色条、局部底块、大号图形锚点，或置于深色背景上；正文与关键数字改用深色中性色承载。
2. **原始素材色彩强烈**（实景照片、产品截图、多色地图）：收敛页面其余装饰色，以中性色排版承接；叠字优先选图像低频区或加克制中性遮罩，不为强求色调统一而涂改纪实图片关键信息。
3. **深浅页面混排（Dark / Light 切换）**：切换必须有明确叙事节点（如开场封面、关键转折、核心产品发布页）。切换底色时同步重配文字灰阶、图表轴线、边框透明度与图标反白，严禁只换背景不改前景。
4. **渐变、透明度与阴影**：仅在确有空间分层或柔和遮罩需求时极克制使用，杜绝产生脏灰泥泞感或削弱文字边缘锐度。
5. **多约束不可兼得**：当品牌色、多状态语义、底图色彩与可读性无法完全两全时，优先保住可读性与语义准确，显式说明所采取的折中边界，不隐瞒潜在风险。

## 五、可读性验证与分级交付

### 1. 对比度参考与诚实声明

- 常规文本对比度参考 **WCAG AA ≥ 4.5:1**；大字号文本（通常 ≥18pt 常规或 ≥14pt 粗体）及关键非文本图形边界参考 **≥ 3:1**。
- 文字叠于渐变、半透明层或图片上时，按**文字落点处的最不利有效背景色**核算对比度，并考虑会议室投影机泛白衰减留足余量。
- **诚实边界**：仅当实际计算了 HEX 相对亮度比值时，才可报告具体对比度数值与通过结论；未计算或缺少实物投影检验时，必须如实注明需人工复核，严禁凭主观观感宣称“已通过无障碍技术检测”。

### 2. 缺陷定向修正顺序

发现配色问题时按根因逐级定向修复，不盲目推翻整套色板：

```
1. 语义错乱（状态/涨跌反色）→ 2. 可读性不足（前景背景明度差）→ 3. 层级失衡（强调色泛滥）
→ 4. 图表难辨（补非颜色编码/降级次要系列）→ 5. 跨页脱节（统一灰阶与语义）→ 6. 冷暖细节微调
```

### 3. 按复杂度分级交付

- **轻量任务（单页优化/局部纠偏）**：直接给出关键色值调整、角色分工与可读性修正，不堆砌冗长色卡文档。
- **标准任务（整稿设计）**：明确整体色彩基调、核心角色 HEX、图表主次色逻辑与深浅页切换规则。
- **高约束任务（严格品牌规范/高密数据汇报）**：补充品牌色约束边界、关键前景/背景对比度核算结果、复杂图表辅助编码与例外页说明。
