# 素材艺术指导、排版与整体视觉秩序

**权威范围**：整稿视觉概念、执行顺序、层级与留白、素材职责与素材家族、跨页节奏、视觉冲突优先级。
**不负责**：文字层级/断行/密度细节（见 `typography-editorial-composition.md`）、字段与错误码（见 `contract.md`）、
证据与发布口径（见 `verification.md`）。

本文件是上述范围的定性权威；Schema、Policy 与 guard 只执行可客观验证的子集。机器 PASS 不等于本文件所述视觉质量通过。

## 1. 先建立视觉秩序，再决定表现形式

素材、文字、图表、色彩、线条与留白共同承担叙事、信息组织与视觉表达，不是相互独立的模块。

执行顺序必须是：

> 理解内容 → 明确核心信息 → 确立视觉概念 → 建立阅读层级 → 组织构图与排版 → 选择和处理素材 → 检查实际呈现效果。

禁止从寻找素材、套用模板或添加装饰开始。每页执行前必须回答：

1. **传达什么**：观众最终应理解、相信或记住什么？
2. **突出什么**：哪个信息或视觉元素承担主要注意力？
3. **如何阅读**：从哪里进入，如何理解主张、证据与补充信息？
4. **为何这样表达**：构图、字体、色彩、图像和空间如何支持内容？
5. **什么可以删除**：哪些元素没有独立理解价值或表达价值？

元素争夺同一视觉位置时，先重组信息与构图，不以增加颜色、边框、阴影或字体效果解决。

## 2. 视觉层级：让重要性成为可见秩序

每页原则上设置一个视觉主导点；确需多个焦点时建立先后关系，不平均分配注意力。

- **主层级**：核心结论、主要视觉或关键证据。
- **次层级**：支撑主张的事实、解释与关键细节。
- **辅助层级**：来源、注释、口径、页码与必要导航。

层级由字号、字重、位置、明暗、空间距离、形状和色彩共同建立，不单靠放大或加粗。强调资源必须稀缺。

标题优先表达判断、发现、趋势或结论，而非只描述主题；但封面、章节过渡、品牌表达和纯视觉叙事页应服从自身任务。标题提出判断，正文解释理由，图表或素材提供证据，注释说明口径与边界。不得为标题张力夸大事实或制造因果。

## 3. 高级排版：以文字组织空间

排版是信息设计与构图，不是页面完成后的美化。

### 3.1 字体角色

建立有限且清楚的角色：

- 展示文字：封面、关键主张或表达性短句；
- 阅读文字：正文、说明与连续阅读；
- 信息文字：数据标签、类别、单位、来源与注释。

角色可由同一字体的字重和尺度承担。中英混排必须检查字面大小、基线、笔画重量和数字风格，避免拼接感。新增字体或层级必须有内容、媒介或视觉概念依据。

### 3.2 尺度、行距与密度

尺度依据实际展示尺寸、观看距离、阅读任务和页面层级判断。正文不得为整齐而压缩行距或过度缩字；行长必须与语言和字号匹配；关系主要通过间距、分组和必要字重表达，不用大量边框与底色替代组织。

中文必须检查标点组合、标题断行、孤行、短尾行、中英文混排、数字与单位关联及换行语义。不得横向压缩字符。空间不足时依次：精简重复 → 重组内容 → 调整构图 → 最后评估文字尺度。

### 3.3 字体与构图共同决策

文字可以是主视觉、辅助说明、编辑性文字块或与图像对话的构件。不得默认把文字装进固定矩形，再用图片填补剩余空间。共同判断文字块宽度、轮廓、断行、对齐边界、周围留白及与图像主体的关系；视觉张力不得破坏自然阅读顺序。

## 4. 留白与空间

留白是建立注意力、分组、节奏、距离与张力的积极空间。检查：

- **焦点留白**：主标题或主体周围是否有足够空间；
- **关系留白**：同组元素是否自然靠近，跨组是否明确分离；
- **边界留白**：边缘秩序是否稳定，主体是否局促或漂浮；
- **节奏留白**：跨页和段落是否存在有意义的疏密变化；
- **负空间形态**：空白是否与主体轮廓、方向和重心协调。

留白不要求均匀或越多越好。稀疏适合强调与仪式感；高密度可服务研究和复杂证据，前提是层级清楚、路径明确。不得因页面空而机械添加装饰，也不得为极简删去必要证据。

## 5. 素材职责与准入

| 类型 | 职责 | 核心判断 |
|---|---|---|
| 背景 | 建立环境、氛围与空间 | 不抢主体，不破坏文字对比 |
| 主体图像 | 承担核心视觉或关键语境 | 景别、比例、主体和负空间服务叙事 |
| 辅助图像 | 补足事实、细节或语境 | 与主体形成主次、递进或互补 |
| 图表 | 呈现数据关系与证据 | 编码匹配数据；值、单位、期间、口径一致 |
| 插画/图解 | 解释概念、结构、流程或机制 | 隐喻不冒充机制，示意不冒充实测 |
| 图标 | 支持识别、导航或操作理解 | 语义明确，装饰性重复不是理由 |
| 线条/色块 | 分组、连接、划分空间或建立节奏 | 使用能完成任务的最轻表达 |
| 装饰 | 有依据时加强构图或表达 | 不因空白、丰富需求或行业惯例而添加 |

素材加入前必须回答：解决什么问题？位于阅读路径何处？删除后损失什么？若删除后理解、论证和表达没有实质损失，应删除。

## 6. 图像处理与素材家族

### 6.1 落位与裁切

同时判断比例、景别、主体尺度、视觉重心、方向、清晰度、光线、色彩、透视与文字叠加条件。裁切用于强化主体与构图，不只迁就占位。主体可偏置或局部出框，但必须服务叙事且不误遮挡。亮区、高对比区域和视线方向应配合文字与阅读路径。

文字叠图必须以实际尺寸验证；无法保证可读性时优先调整构图、文字位置或背景处理。不得用模糊、裁切或视觉处理掩盖来源不明、事实不可靠或分辨率不足。

### 6.2 素材家族与差异

整稿建立可识别的视觉语法：色彩关系、明暗、摄影倾向、图标体系、字体气质和图形语言。**一致性不等于所有素材外观相同。** 页面可以因内容采用不同景别、图表、密度与素材形态；跨风格必须由内容性质、证据属性、叙事转折或品牌表达支持。

### 6.3 复用与资产治理

语义、授权、清晰度、质量和风格合格时优先复用既有资产；跨页复用关联统一资产记录，保持来源、授权、版本和元信息一致。若复用导致表达趋同、信息重复或错配，优先保证当前页面表达质量。

## 7. 页面差异与整稿节奏

整稿是视觉序列，不是独立美化页或同一版式重复。跨页保持字体角色、基本空间秩序、素材语言、数据表达与品牌识别；同时按页面功能调整主次、密度、图像尺度和阅读速度。

- 观点页突出判断与依据；
- 数据页突出比较、变化与证据；
- 机制页帮助理解结构、流程和边界；
- 品牌/愿景页允许更强表达，但不削弱真实性；
- 过渡页可降低密度，为下一叙事建立节奏。

不得为整齐让所有页面等量分配文字、图像与空间；也不得为变化引入无语义依据的新风格。每次复用或变化都回答：保持什么？改变什么？变化是否由内容和叙事驱动？

## 8. 冲突处理优先级

1. 真实性与合规；
2. 信息理解与可读性；
3. 叙事与视觉层级；
4. 构图与排版质量；
5. 整稿一致性与风格表达；
6. 装饰与视觉丰富度。

**层级关系**：前两级与 `SKILL.md`「冲突优先级」的交付级顺序一致（事实与合规、理解与可读性优先）；
第 3–6 级是**视觉内部子序**，只在前两级不冲突时用于比较视觉方案，不能反过来推翻内容与证据的结论。

“高级感”不能成为上层要求的豁免理由。

## 9. 交付前视觉验收

必须按实际呈现尺寸逐页检查，而非只看源文件或局部放大图：

- 焦点：第一眼能否识别主导信息？
- 标题：是否准确承担任务，断行是否自然？
- 排版：层级、行距、段距、对齐和密度是否协调？
- 阅读路径：主张、证据和补充信息是否有明确顺序？
- 空间：留白是否建立关系与节奏，是否局促、漂浮或空洞？
- 素材：每张图、图标、线和色块是否有职责？
- 可读性：标点、混排、标签、单位、来源及实际尺寸是否合格？
- 一致性：是否服从整稿视觉语法？
- 真实性：数据、图像语境、机制、版权和来源是否可靠？
- 删减测试：删除非核心元素后仍完整时，是否应删除？

问题修正顺序：**删减 → 重组 → 调整比例与空间 → 优化排版 → 处理素材 → 添加必要效果。**

最终标准：**信息准确、层级鲜明、排版成熟、构图有意图、素材有职责、空间有秩序，并形成连续而有变化的视觉叙事。**
