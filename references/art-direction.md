# 艺术指导：整稿、构图、中文、素材与信息

按任务分节读取。这里提供判断依据、成立条件和失效信号，不提供固定坐标或版式墙；字段形状、技术默认值与冲突顺序分别以 Schema、Policy、`SKILL.md` 为准。

## 1. 从任务推出整稿视觉概念

先理解观众已知与怀疑什么、离场后要理解或决定什么、内容是论证／对照／流程／场景中的哪种关系、观看距离与时长、品牌和素材约束。概念不是“科技感”“高级”，而是能约束后续选择的一句话，落到：**图像世界、明暗与色彩角色、空间组织母题、字族角色、跨页节奏**。五者相互约束，统一的是逻辑，不是每页长相。

- 董事会决策：时间短、要评估风险 → 结论先行，证据紧邻主张，图像只在能说明现场时出现。若改成会后深读，则给口径与细节更多空间。把“金融”直接映射为深蓝金边，不是推导。
- 大厅新品发布：远距离、强调记忆 → 有可信产品素材时让产品尺度成为高潮，卖点另安排节奏；若观众要核对结构，补可读的原生说明而非只保留氛围图。
- 专家评审机制：原生关系与已知证据优先；“发光大脑”不能补足缺失机制。

高级感来自明确取舍、可信材质、可读层级与有职责的空间，不等于黑金、少色或少字。

## 2. 整稿乐谱与节奏

为各页记录叙事职责与相对重量，必要时标明暗、图像占比、信息密度和情绪。决定哪里该积累、转折、停顿或收束；高潮数量取决于内容规模与决策节点，不预设配额。缩略总览中若所有页同重同构图，回到内容职责调整；相邻同构图若用于同轴比较，则不必为了变化而改变。

深浅场切换要有叙事或阅读依据，并同步调整前景墨阶、轴线与图表编码。字族角色、语义色和主要对齐轴应一致，图像占比、留白与密度可以因页面职责变化。页码、来源、口径与法定文字是功能性信息：在整体布局时预留位置，不因追求干净而丢失；页码技术契约见 `contract.md` §2。

## 3. 构图、空间张力与动势

### 3.1 先读内容关系

| 关系 | 成立的空间组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 让结论与支持信息形成明显的尺度、位置或明度差 | 所有内容同重；装饰争焦点 |
| 机制／流程 | 路径与间距反映已知顺序和关系 | 图标阵列或箭头暗示未经证实的因果 |
| 对照／并列 | 同一基线、可比尺度；确实等重时允许并列 | 为追求一个主角而偷换权重 |
| 同源数据 | 主张、图形与单位形成一条阅读路径 | 图表缩角落，正文复述所有数字 |
| 场景 | 图像承担空间或情绪，文字进入真实安静区 | 图像主角与标题互抢，或用重遮罩掩盖杂乱 |

`composition_rationale` 应说明关注点、建立层级的手段、次级阅读顺序与被放弃的方案。说不出这些，先重读内容，不靠增加零件。

### 3.2 张力如何成立

- **尺度与重心**：需要强调时拉开可感知差距，而不是叠加粗、加色和描边；不能仅从面积推断谁先被看见。非对称时让对侧以连续负空间、对齐轴、图像视线或必要的次级信息回秤。
- **边缘与留白**：贴边／出血可表达世界延展；内收可表达秩序。留白要保护焦点、分组、停顿或容纳视线，零碎空隙不等于连续空间。极空但主角没有分量，与有控制的克制不同。
- **轴线与密度**：先用邻近、对齐、间距分组，再考虑容器；无关轴线越多越散。把需要连读的信息组织成密度块，其余空间服务阅读，不把段落、卡片和空隙平均铺满。

### 3.3 动势必须有内容依据

有顺序时可用方向牵引；有主次时可用尺度或位置传递；内容确有累积才表达积聚；需要理解结论时可以停顿，行动点可以释放。**静态对照、严肃表格或真正并列也可以没有主导运动**。若使用动势，应回答“什么因何而动、向哪里、视线如何回到主张或证据”。斜线、透视和装饰曲线本身不构成动势。

例：时间序列用共同基线、按时间排序并只强调相关终点，标题说出可证实的变化；给每根柱斜加箭头会暗示不存在的因果。若四项是无先后关系的并列类别，应放弃时间方向和“增长”措辞。

## 4. 中文排版

- **角色**：论断写成论断；主标题、正文、数字、来源各有明确职责。字号、字重、墨色与位置组合建立层级；数字和单位同组、同基线，来源靠近所说明的对象。
- **语义断行**：先找分句和主张重心，不按字符数机械均分。比如“无糖是入场券，／口感才是复购的理由”；“2026 年第三季度／营收 13 亿元”，不把数字与单位、期间、正负号或专名拆开。末行孤字、行首收尾标点和行尾开括号在真实渲染中查。
- **行长与混排**：以观看距离下一眼扫完为准；长句优先一个可读场域，不为均分切成窄栏。中文正文可视内容两端对齐，西文多时注意字间空洞；中西间距与标点体例整稿一致。同行数字/西文需要不同字体或字重时用同一文本对象的 `runs`，避免拆框造成基线漂移。
- **字族与测量**：先按展示、阅读、信息职责选择，字重足够区分时无需强行多字体。编译器写西文与东亚字体；字体缺失后的预览只代表替代字体，目标环境另验。E010 是装载估算，不是真实字形测量。
- **装不下**：删重复 → 合并 → 按“论断 + 证据”改写 → 加宽或拆页；不得压缩重要限定、字距、行距来掩盖编辑问题。

## 5. 素材职责与路线

先问：它承担证据、结构、语境、情绪还是质感？删除后损失什么？它与整稿图像世界及最终裁切是否一致？答不出就不用图。

| 路线 | 何时使用 | 边界 |
| --- | --- | --- |
| 真实素材 | 具体产品、真实人物或现场、可核查证据 | 核实来源、授权、隐私和真实信息；不为配色涂改证据 |
| 原生图形 | 数值、结构、关系或流程本身是内容 | 只画已知关系，避免装饰冒充机制 |
| 生成图 | 可虚构的概念、氛围或理想化场景 | 登记真实生成记录；不证明真实对象、现场或数据 |
| 纯排版 | 合格图片无独特职责或合理成本内不存在 | 若事实需要具象证据，仍须报告素材缺口 |

先定最终框和文字落点，再选全出血叠字、图文分场或局部细节。叠字须有连续安静区；分场不必机械五五分；局部图要有独特信息。可复用同一素材的不同裁切，但每次检查主体和安静区。生成失败先定位结构、画幅、光或职责根因，再决定重试或换路线；不以重复抽图代替判断。具体简报与真实调用见 `image-prompt.md`。

## 6. 关系图形：从语义到视觉

先写清**实体、关系、方向与范围**，再问：是否有真实时间、可比数值、共同分母、节点归属、条件与证据？数据的精度和不确定性允许什么结论？选择最简单能保真、可阅读且可编辑的表达；必要时拆图、用表格／文字或明确标注假设。不要把图型名称、关键词或漂亮的连接线当作推理。

| 关系 | 选择和视觉语法 | 必查与诚实退路 |
| --- | --- | --- |
| **比较** | 柱/条强调绝对量与共同基线；点、哑铃或斜率适合成对差异；排名按明确口径排序，小多图保持可比尺度。对齐基准，突出真正重要的差值。 | 比较绝对量的柱/条须包含零点；点图若截轴须清楚标示；不把不同口径或缺失值画成可比数据。 |
| **时间** | 序列先后可用事件轴；日期间距有意义时按真实时间比例；持续期用甘特，路线图/里程碑区分已发生与计划。转折处可留空间承托说明。 | 流程先后不等于日期；日期、时区或工期未知不画伪比例。现成类别折线等间距，非均匀日期需另做真实比例轴或用表格。 |
| **组成／数量流** | 饼/环适合少量互斥部分与共同整体；堆叠、树图表达构成，瀑布解释可核对的增减，漏斗展示相同口径下的阶段留存。数量流可用按值定宽的带或条、清楚方向与去向。 | 先确认分母、单位、互斥、是否可加和输入输出的平衡；宽度表示数量时须一致且可核算。缺口标未分配；不具备关系或数值时用来源→去向表，不画假桑基。 |
| **分布／统计** | 散点看配对关系；气泡需说明面积/数量映射；直方图以真实分箱宽度组织；箱线、区间、热力或相关矩阵需可核对的统计定义。样本数与不确定性应靠近读数。 | 分布不等于均值；相关不等于因果；缺样本、分位数、区间或分箱边界不能臆造。复杂统计先用原始值、区间表或简化点列。 |
| **因果／风险** | 因果链、鱼骨、回路、影响图、故障树或蝴蝶结按已知机制、方向、条件与证据组织；区分观测、已确认路径与假设，未证路径有明确文字标识。 | 共现、相关和时间先后均不证明因果；故障树的“且/或”须有依据。机制未知先展示并列事实或假设表，不用箭头暗示已证实。 |
| **流程／决策** | 分支流程和决策树让方向、条件、出口可追；泳道交代责任，状态图交代触发与转换，旅程图区分阶段与体验。突出关键决策而非平均铺节点。 | 分支条件必须互不误读、必要出口完整；顺序不是持续时间，也不是因果。缺条件时列待确认而非补造路径。 |
| **结构／依赖** | 层级树与组织图表达归属，系统架构表达组件边界；数据流标方向与载荷，网络强调连接，实体关系标明基数，依赖图明确前置与被依赖方。 | 归属不是依赖，连接不是方向；未知边或基数不编造。关系过密时分层、局部放大或改清单。 |
| **战略／优先级** | 2×2、风险或优先级矩阵先写轴、方向、阈值与位置含义；帕累托先核对可加总与排序；依赖网络突出真正的约束。 | 象限和颜色不是证据；无阈值或影响概率时不要伪造精确位置，改用带状态的清单或表格。 |
| **简洁表达** | 一个关键数字、指标组、微趋势、原生表格或一句结论也可以是最合适的图形。 | 数字必须有单位、期间和来源；微趋势不能暗示不存在的精度；不为丰富版面加图。 |

**构图与绘制**：先确定观众从哪里读到哪里，再安排重心、主次尺度、密度块与连续负空间；真正等重的比较可以并列。以对齐和邻近建立分组，线、节点、边界、箭头、标记与颜色各有职责；能直标时减少远距离图例。分支标签贴近对应路径，避免线穿字、交叉难辨、重叠或无意义卡片；不要强迫元素等大、居中或平均铺开。色彩遵循 `color-art-direction.md`，不是用装饰替代关系。

**落地**：先选可编辑原生文字、形状、图表与表格；现成图型不支持所需语义时，不伪称系统自动支持。手工点位、条长、时间间距和箭头须可回算，修改数据或节点后重算并重渲染。专用图表类型、等距类别轴、手工箭头与可编辑性的限制以 `contract.md` 为准。

页题只说证据支持的结论；图题、单位、期间、分母、来源与限定要可见。类别少且读数重要可直标；只在直标足以读数时隐藏轴。程序仅筛查数值、单位、期间和部分方向，不证明来源、因果、共同分母或设计质量。

## 7. 诊断与人工验收

| 症状 | 先查根因与处理 | 不要 |
| --- | --- | --- |
| 不知先看什么／像模板 | 明确阅读重点，删去不承担关系的容器，保留功能信息 | 给配角一起加粗加色 |
| 发空／非对称不稳 | 检查主角分量、连续负空间与对侧回秤 | 用图标填满空白 |
| 拥挤／断行难看 | 编辑、扩框或拆页；按语义调整断点 | 缩字号、压行距、用空格硬推 |
| 图一裁就废／叠字难读 | 按落位框重选画幅或移动文字，检查真实字形落点 | 以居中裁切或浓遮罩碰运气 |
| 读不出数据／翻页疲劳 | 回到口径、主张与乐谱，调整直标和密度 | 改装饰或随机换版式 |

### 设计复核：逐项给 PASS / BLOCK / NOT VERIFIED

| 维度 | 看什么 |
| --- | --- |
| 语义准确性 | 关系、方向、条件、口径、时间与证据是否真实；是否把相关或假设画成因果？ |
| 信息层级 | 主张、重点、限定和来源能否按预期顺序读到；并列是否被错误拉开？ |
| 构图与空间 | 主次比例、重心、留白、分组与相邻页节奏是否服务内容，而非模板化？ |
| 图形表达 | 基线、节点、线、箭头、带宽及统计编码是否各有职责，能否回算？ |
| 排版 | 中文断行、标点、标签、数字单位、字号与观看距离是否合理？ |
| 色彩 | 类别、状态与证据的编码是否一致、可辨且融入整稿？ |
| 关系可读性 | 路径、分支条件、依赖、图例、交叉及注释是否可追踪且不遮挡？ |
| 渲染与交付 | 实际 PPTX 对象是否按需可编辑，真实渲染有无裁切、错位、替字及目标环境风险？ |

**否决项不可抵消**：语义错误、数据失真、无证因果和关键内容不可读须先修复；不能由其他维度表现或加总分数掩盖。缺证据或未执行的项标 `NOT VERIFIED`。G-DECK 须看每页、缩略总览、相邻页和完整叙事，逐项核对 `focus_human_required` / `limitations`；机器通过不等于审美通过。发现问题回到根因修改，重渲染后再判断。
