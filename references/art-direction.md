# 排版、视觉秩序与图文协同艺术指导

仅在复杂排版、中西文字体搭配、多元素图文冲突、跨页节奏诊断或视觉缺陷修正时读取。继承 `SKILL.md` 的事实边界与决策主线；本文件提供专项取舍，不提供固定模板或另一套机器阈值。

## 一、多个可行方案如何取舍

先排除事实失真、关键信息缺失和不可读方案，再比较：

1. **任务适配**：哪个最直接成立核心主张、关键证据和页面职责？
2. **理解效率**：哪个无需额外装饰就能建立第一入口、阅读路径和归属？
3. **表达张力**：哪个通过有意义的尺度、明暗、疏密或图文关系形成记忆点？
4. **整稿价值**：哪个延续视觉语法，同时与前后页形成有依据的密度和重心变化？
5. **渲染稳健性**：哪个在字体回落、换行波动和实际阅读距离下更不易失效？

仅在目标冲突、方案确有竞争或初稿失效时展开比较，不机械输出打分表。机器可读性阈值以 `scripts/policy.json` 为准；阈值通过不等于构图成立。

## 二、视觉主导点与阅读路径

主导点可以是结论句、决定性数字、主体图像，或标题与关键证据构成的紧耦合整体。双方案对比允许双焦点，但必须有对照轴和明确主次；多个高刺激元素同时抢第一注意力时，先判断谁应降级，而不是继续加强主角。

- **主层级**：承载唯一主张或叙事转折，获得最强尺度/空间对比和焦点保护。
- **支撑层级**：提供论据、机制和比较，保持可读但不争夺第一入口。
- **辅助层级**：交代口径、期间、来源和导航，稳定退到安静区，不能弱到无法辨认。

中文汉字笔画密、字面满，与同字号拉丁字母和数字的视觉重量不同。判断层级要看字面面积、字重、墨色、位置与周围留白，而不是只比较 pt 数值。

## 三、中文排版与文本职责

建立有限的展示、阅读和信息字体角色，可由同一字族的不同字重完成。展示角色服务封面、转折和核心主张；阅读角色优先保证多行理解的稳定；信息角色保证数字、刻度和来源清晰。中西文混排需核对基线、字面比例与笔画粗细。

- **标题**：优先一句说清结论或篇章任务；按语义词组断行，不拆专名和核心谓宾，避免末行孤字。
- **正文**：保持完整论述和必要限定；并列要点与连续逻辑采用不同组织，不把长段机械切成碎卡片。
- **关键数字**：数字、单位、百分号、货币和正负号作为不可拆分语义组；同时交代比较基准或期间。
- **注释与来源**：明确退居辅助层，但保留样本、口径和出处所需信息，不为“干净”删掉事实条件。

中文避头尾要检查真实渲染：句号、逗号、顿号、百分号和右括号不居行首，前引号、左括号和货币符号不居行尾。文本装不下时先编辑删减、调整栏宽/断行或重构页面；不以压缩字距、极细字重或过密行距掩盖问题。预测文本框、行框与真实字形墨迹不是同一证据，目标环境仍需复核。

## 四、空间、对齐与构图

优先使用场域、对齐和间距建立秩序，再考虑线条或容器。拆掉容器后归属与阅读路径仍成立，说明容器本来就不是必需。

- **并列要点/履历/层级**：共享基准轴、拉开组间距，以字重和墨色区分层次。
- **矩阵/象限/演进**：用轴线、方位和阅读顺序表达关系；原文没有的方向和连接不能补画。
- **表格/图表**：透明场域、文本与数字按性质对齐、必要水平分隔；避免厚外框、斑马纹和无意义竖线。
- **底图叠字**：文字落在自然低频区；确需遮罩时，容器承担明确可读性职责，而非装饰。

逐页检查六种空间职责：焦点是否受保护；组内距是否小于组间距；边界是否稳定；栏宽和段距是否顺应阅读；负空间是否连续而非碎缝；相邻页密度是否形成有依据的呼吸。

内容形态是构图依据，不是模板标签：单一论断可集中聚焦，机制与阶段顺应流向，双边权衡共享比较维度，多维同源证据由主结论统领分区，场景叙事可让主体图像与安静落字区共同成立。

## 五、素材与图文协同

素材必须先有表达职责，再决定来源、景别、裁切、比例和落位。主体图像承担核心场景或产品叙事；辅助图像补足局部信息并主动降级；插画解释概念但不能冒充实测结构；图标只有降低识别成本时才保留。

面向中文受众时，人物、空间和行业细节应符合实际语境，避免用陈旧图库隐喻替代内容。跨页复用素材时沿用统一资产记录和授权状态；跨风格混排必须有内容或叙事理由。

裁切要保护主体关键部位、视线和负空间，不拉伸变形。文字叠图需在最不利背景下检查识别度；生成图像只承担声明的概念/氛围职责，不能成为事实证据。

## 六、整稿复核与定向修复

整稿保持字体角色、色彩语义、对齐逻辑和素材家族稳定；主导元素类型、构图重心、栏数、信息密度和明暗场随页面职责有据变化。关键页应最强，过渡页应克制，重复只有产生对比、回顾或新解释时才有价值。

| 观察到的现象 | 优先检查的根因 | 定向修正 |
| --- | --- | --- |
| 第一眼不知看哪里 | 主张、数字、图像和装饰权重接近 | 重建主次，不继续平均加强 |
| 工整但像模板 | 用容器替代关系判断，连续复制同一构图 | 回到场域、对齐和页面职责 |
| 页面拥挤 | 未经编辑堆入原文，组间距失效 | 先删并改写，再重排或拆页 |
| 精致但投影难读 | 明度差不足、字重过细、背景干扰 | 先恢复可读性，再谈氛围 |
| 连翻多页疲劳 | 焦点、密度和视觉重量没有叙事变化 | 调整整稿节奏，而非随机换样式 |
| 编译后破句或溢出 | 字体度量、断行或框体假设失效 | 对照实际渲染定向修正并复验 |

若实际结果偏离 plan，先区分原始判断不合理还是 BUILD 执行偏差，再决定回到 THINK 或只修受影响元素。
