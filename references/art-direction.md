# 艺术指导：整稿、构图、中文、素材与信息

按任务分节读取。这里提供判断依据、成立条件和失效信号，不提供固定坐标或版式墙；字段形状、技术默认值与冲突顺序分别以 Schema、Policy、`SKILL.md` 为准。

## 1. 从任务推出整稿视觉概念

先理解观众已知与怀疑什么、离场后要理解或决定什么、内容是论证／对照／流程／场景中的哪种关系、观看距离与时长、品牌和素材约束。概念不是“科技感”“高级”，而是能约束后续选择的一句话，落到：**图像世界、明暗与色彩角色、空间组织母题、字族角色、跨页节奏**。五者相互约束，统一的是逻辑，不是每页长相。

- 董事会决策：时间短、要评估风险 → 结论先行，证据紧邻主张，图像只在能说明现场时出现。若改成会后深读，则给口径与细节更多空间。把“金融”直接映射为深蓝金边，不是推导。
- 大厅新品发布：远距离、强调记忆 → 有可信产品素材时让产品尺度成为高潮，卖点另安排节奏；若观众要核对结构，补可读的原生说明而非只保留氛围图。
- 专家评审机制：原生关系与已知证据优先；“发光大脑”不能补足缺失机制。

高级感来自明确取舍、可信材质、可读层级与有职责的空间，不等于黑金、少色或少字。

### 1.1 概念怎样推出来：洞察 → 概念 → 约束

1. **写洞察句**：观众原本怎么想、证据说明了什么、差距或张力在哪里（“他们以为问题在获客，数据显示问题在留存”）。写不出洞察句，说明内容还没读透，先回到主张与证据，不要先选风格。
2. **由洞察推概念**：概念回答“用什么视觉关系让这个洞察被看见”。可来自尺度对比、材质、空间关系、观看视角或叙事结构；不是形容词（“科技感”）、不是行业符号，也不必是比喻。
3. **转成约束**：概念必须能落到图像世界、明暗与色彩角色、空间母题、字族角色、跨页节奏，并能**否决**具体选择（“这张图与概念无关，删”）。
4. **四项自检**：
   - 来源：能追溯到哪条洞察或证据？追溯不到就是装饰。
   - 约束：能否据此否决一个具体的图、色、版式？不能否决任何东西的概念没有指导力。
   - 替换：把行业或主题换掉，概念还成立吗？成立，说明是通用风格而非本稿概念。
   - 辨识：隔着缩略图能否认出它是这一套，而不是任何一套？

行业、品牌调性和受众习惯是**约束输入**，不是答案：它们决定哪些做法不可行，不决定概念本身。

### 1.2 整稿视觉识别：锁定什么，放开什么

识别来自少数被锁定的逻辑，而不是每页相似。**锁定**：字族角色与字重分工、墨阶与语义色、主要对齐轴与留白逻辑、图像世界（媒介、光、色域、材质）、图形语言（线、点、块的统一用法）。**放开**：构图、尺度、密度、明暗场、图像占比、有无主角——由本页叙事职责决定。若放开的东西也被锁死，整稿单调；若锁定的东西逐页变化，整稿失去识别。

## 2. 整稿乐谱与节奏

为各页记录叙事职责与相对重量，必要时标明暗、图像占比、信息密度和情绪。决定哪里该积累、转折、停顿或收束；高潮数量取决于内容规模与决策节点，不预设配额。缩略总览中若所有页同重同构图，回到内容职责调整；相邻同构图若用于同轴比较，则不必为了变化而改变。

深浅场切换要有叙事或阅读依据，并同步调整前景墨阶、轴线与图表编码。字族角色、语义色和主要对齐轴应一致，图像占比、留白与密度可以因页面职责变化。页码、来源、口径与法定文字是功能性信息：在整体布局时预留位置，不因追求干净而丢失；页码技术契约见 `contract.md` §2。

### 2.1 节奏语汇与整稿检查

plan 的页面 `role` 取 `open / build / breathe / turn / hold / close`，对应叙事动作：**开场**建立世界与问题；**递进**积累证据、逐层加重；**转折**改变视角或结论方向，通常伴随尺度、明暗或构图的明显变化；**停顿**（`breathe` / `hold`）让读者消化关键结论，可以更空、更慢，而不是凑数的过渡；**高潮**是最强的一次集中（最大的数字、最关键的证据、最有力的图像），数量由内容决定；**收束**落到决定、下一步或要带走的一句话。`role` 是叙事职责，不是视觉模板——两页同为 `build`，构图可以完全不同。

整稿一致性检查（对照缩略总览）：① 只看轮廓与明暗，能否读出开场—推进—转折—收束；② 相邻页的变化有无叙事理由，没有理由的变化是噪声，没有变化的同构图若用于同轴比较则成立；③ 锁定项（§1.2）是否逐页稳定；④ 最重的一页是否确实是内容最重要的一页。

## 3. 构图、空间张力与动势

### 3.1 先读内容关系

| 关系 | 成立的空间组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 让结论与支持信息形成明显的尺度、位置或明度差 | 所有内容同重；装饰争焦点 |
| 机制／流程 | 路径与间距反映已知顺序和关系 | 图标阵列或箭头暗示未经证实的因果 |
| 对照／并列 | 同一基线、可比尺度；确实等重时允许并列 | 为追求一个主角而偷换权重 |
| 同源数据 | 主张、图形与单位形成一条阅读路径 | 图表缩角落，正文复述所有数字 |
| 场景 | 图像承担空间或情绪，文字进入真实安静区 | 图像主角与标题互抢，或用重遮罩掩盖杂乱 |

`composition_rationale` 应说明关注点、建立层级的手段、次级阅读顺序与被放弃的方案。说不出这些，先重读内容，不靠增加零件。

### 3.2 张力如何成立

- **尺度与重心**：需要强调时拉开可感知差距，而不是叠加粗、加色和描边；不能仅从面积推断谁先被看见。非对称时让对侧以连续负空间、对齐轴、图像视线或必要的次级信息回秤。
- **边缘与留白**：贴边／出血可表达世界延展；内收可表达秩序。留白要保护焦点、分组、停顿或容纳视线，零碎空隙不等于连续空间。极空但主角没有分量，与有控制的克制不同。
- **轴线与密度**：先用邻近、对齐、间距分组，再考虑容器；无关轴线越多越散。把需要连读的信息组织成密度块，其余空间服务阅读，不把段落、卡片和空隙平均铺满。

### 3.3 动势必须有内容依据

有顺序时可用方向牵引；有主次时可用尺度或位置传递；内容确有累积才表达积聚；需要理解结论时可以停顿，行动点可以释放。**静态对照、严肃表格或真正并列也可以没有主导运动**。若使用动势，应回答“什么因何而动、向哪里、视线如何回到主张或证据”。斜线、透视和装饰曲线本身不构成动势。

例：时间序列用共同基线、按时间排序并只强调相关终点，标题说出可证实的变化；给每根柱斜加箭头会暗示不存在的因果。若四项是无先后关系的并列类别，应放弃时间方向和“增长”措辞。

## 4. 中文排版

- **角色**：论断写成论断；主标题、正文、数字、来源各有明确职责。字号、字重、墨色与位置组合建立层级；数字和单位同组、同基线，来源靠近所说明的对象。
- **语义断行**：先找分句和主张重心，不按字符数机械均分。比如“无糖是入场券，／口感才是复购的理由”；“2026 年第三季度／营收 13 亿元”，不把数字与单位、期间、正负号或专名拆开。末行孤字、行首收尾标点和行尾开括号在真实渲染中查。
- **行长与混排**：以观看距离下一眼扫完为准；长句优先一个可读场域，不为均分切成窄栏。中文正文可视内容两端对齐，西文多时注意字间空洞；中西间距与标点体例整稿一致。同行数字/西文需要不同字体或字重时用同一文本对象的 `runs`，避免拆框造成基线漂移。
- **字族与测量**：先按展示、阅读、信息职责选择，字重足够区分时无需强行多字体。编译器写西文与东亚字体**名称**，不嵌入字体文件；字体缺失后的预览只代表替代字体，目标环境另验。E010 是装载估算，不是真实字形测量。
- **跨平台字体**：字体名只有在观看机器上存在才生效，缺失时 PowerPoint 会静默替换并改变宽度与断行。默认“微软雅黑”是 Windows 常见字体，不能假定 macOS 或 Linux 上存在；苹方只在苹果系统；思源黑体／Noto Sans CJK SC 为开源可商用（SIL OFL），但需目标机安装或随稿提供。已知要在多平台放映时，选目标机实测可用的字体并写入 plan 的 `fonts`，或把可用字体作为交付说明的一部分；方正、汉仪等商业字体须确认授权。字重只用目标字体真实存在的档位，避免依赖合成粗体或细体投影后发虚。
- **装不下**：删重复 → 合并 → 按“论断 + 证据”改写 → 加宽或拆页；不得压缩重要限定、字距、行距来掩盖编辑问题。

## 5. 素材职责与路线

先问：它承担证据、结构、语境、情绪还是质感？删除后损失什么？它与整稿图像世界及最终裁切是否一致？答不出就不用图。

| 路线 | 何时使用 | 边界 |
| --- | --- | --- |
| 真实素材 | 具体产品、真实人物或现场、可核查证据 | 核实来源、授权、隐私和真实信息；不为配色涂改证据 |
| 原生图形 | 数值、结构、关系或流程本身是内容 | 只画已知关系，避免装饰冒充机制 |
| 生成图 | 可虚构的概念、氛围或理想化场景 | 登记真实生成记录；不证明真实对象、现场或数据 |
| 纯排版 | 合格图片无独特职责或合理成本内不存在 | 若事实需要具象证据，仍须报告素材缺口 |

先定最终框和文字落点，再选全出血叠字、图文分场或局部细节。叠字须有连续安静区；分场不必机械五五分；局部图要有独特信息。可复用同一素材的不同裁切，但每次检查主体和安静区。生成失败先定位结构、画幅、光或职责根因，再决定重试或换路线；不以重复抽图代替判断。具体简报与真实调用见 `image-prompt.md`。

## 6. 关系图形：从语义到视觉

先写清**实体、关系、方向与范围**，再问：是否有真实时间、可比数值、共同分母、节点归属、条件与证据？数据的精度和不确定性允许什么结论？选择最简单能保真、可阅读且可编辑的表达；必要时拆图、用表格／文字或明确标注假设。不要把图型名称、关键词或漂亮的连接线当作推理。

| 关系 | 选择和视觉语法 | 必查与诚实退路 |
| --- | --- | --- |
| **比较** | 柱/条强调绝对量与共同基线；点、哑铃或斜率适合成对差异；排名按明确口径排序，小多图保持可比尺度。对齐基准，突出真正重要的差值。 | 比较绝对量的柱/条须包含零点；点图若截轴须清楚标示；不把不同口径或缺失值画成可比数据。 |
| **时间** | 序列先后可用事件轴；日期间距有意义时按真实时间比例；持续期用甘特，路线图/里程碑区分已发生与计划。转折处可留空间承托说明。 | 流程先后不等于日期；日期、时区或工期未知不画伪比例。现成类别折线等间距，非均匀日期需另做真实比例轴或用表格。 |
| **组成／数量流** | 饼/环适合少量互斥部分与共同整体；堆叠、树图表达构成，瀑布解释可核对的增减，漏斗展示相同口径下的阶段留存。数量流可用按值定宽的带或条、清楚方向与去向。 | 先确认分母、单位、互斥、是否可加和输入输出的平衡；宽度表示数量时须一致且可核算。缺口标未分配；不具备关系或数值时用来源→去向表，不画假桑基。 |
| **分布／统计** | 散点看配对关系；气泡需说明面积/数量映射；直方图以真实分箱宽度组织；箱线、区间、热力或相关矩阵需可核对的统计定义。样本数与不确定性应靠近读数。 | 分布不等于均值；相关不等于因果；缺样本、分位数、区间或分箱边界不能臆造。复杂统计先用原始值、区间表或简化点列。 |
| **因果／风险** | 因果链、鱼骨、回路、影响图、故障树或蝴蝶结按已知机制、方向、条件与证据组织；区分观测、已确认路径与假设，未证路径有明确文字标识。 | 共现、相关和时间先后均不证明因果；故障树的“且/或”须有依据。机制未知先展示并列事实或假设表，不用箭头暗示已证实。 |
| **流程／决策** | 分支流程和决策树让方向、条件、出口可追；泳道交代责任，状态图交代触发与转换，旅程图区分阶段与体验。突出关键决策而非平均铺节点。 | 分支条件必须互不误读、必要出口完整；顺序不是持续时间，也不是因果。缺条件时列待确认而非补造路径。 |
| **结构／依赖** | 层级树与组织图表达归属，系统架构表达组件边界；数据流标方向与载荷，网络强调连接，实体关系标明基数，依赖图明确前置与被依赖方。 | 归属不是依赖，连接不是方向；未知边或基数不编造。关系过密时分层、局部放大或改清单。 |
| **战略／优先级** | 2×2、风险或优先级矩阵先写轴、方向、阈值与位置含义；帕累托先核对可加总与排序；依赖网络突出真正的约束。 | 象限和颜色不是证据；无阈值或影响概率时不要伪造精确位置，改用带状态的清单或表格。 |
| **简洁表达** | 一个关键数字、指标组、微趋势、原生表格或一句结论也可以是最合适的图形。 | 数字必须有单位、期间和来源；微趋势不能暗示不存在的精度；不为丰富版面加图。 |

**构图与绘制**：先确定观众从哪里读到哪里，再安排重心、主次尺度、密度块与连续负空间；真正等重的比较可以并列。以对齐和邻近建立分组，线、节点、边界、箭头、标记与颜色各有职责；能直标时减少远距离图例。分支标签贴近对应路径，避免线穿字、交叉难辨、重叠或无意义卡片；不要强迫元素等大、居中或平均铺开。色彩遵循 `color-art-direction.md`，不是用装饰替代关系。

**落地**：先选可编辑原生文字、形状、图表与表格；现成图型不支持所需语义时，不伪称系统自动支持。手工点位、条长、时间间距和箭头须可回算，修改数据或节点后重算并重渲染。专用图表类型、等距类别轴、手工箭头与可编辑性的限制以 `contract.md` 为准。

页题只说证据支持的结论；图题、单位、期间、分母、来源与限定要可见。类别少且读数重要可直标；只在直标足以读数时隐藏轴。程序仅筛查数值、单位、期间和部分方向，不证明来源、因果、共同分母或设计质量。

## 7. 诊断与人工验收

| 症状 | 先查根因与处理 | 不要 |
| --- | --- | --- |
| 不知先看什么／像模板 | 明确阅读重点，删去不承担关系的容器，保留功能信息 | 给配角一起加粗加色 |
| 发空／非对称不稳 | 检查主角分量、连续负空间与对侧回秤 | 用图标填满空白 |
| 拥挤／断行难看 | 编辑、扩框或拆页；按语义调整断点 | 缩字号、压行距、用空格硬推 |
| 图一裁就废／叠字难读 | 按落位框重选画幅或移动文字，检查真实字形落点 | 以居中裁切或浓遮罩碰运气 |
| 读不出数据／翻页疲劳 | 回到口径、主张与乐谱，调整直标和密度 | 改装饰或随机换版式 |

症状只是入口：先按 `review-protocol.md` §4.2 归入根因类别（内容与事实 → 信息架构 → 视觉概念 → 构图与层级 → 字体排版 → 色彩图像 → 机器执行 → 渲染环境），上游优先，每轮只改一个因果相关的变量组，改后重新渲染比较。

### 设计复核：十一个维度，逐项给 PASS / BLOCK / NOT VERIFIED

前八项检查表达是否成立，后三项检查判断是否成立。每项必须写**实际依据**（机器事实、看过的渲染页面或 plan 声明）；没有依据的项记 `NOT VERIFIED`。

| 维度 | PASS 需要看到 | 典型 BLOCK 信号 |
| --- | --- | --- |
| 1 语义准确性 | 关系、方向、条件、口径、时间与证据真实；相关、假设未被画成因果 | 无证因果、口径混画、数据与文字矛盾 |
| 2 信息层级 | 主张、重点、限定和来源按预期顺序被读到；并列没有被错误拉开 | 一眼先看到的不是主张；配角与主角同重 |
| 3 构图与空间 | 主次比例、重心、连续留白、分组、相邻页节奏服务内容 | 发空或拥挤；重心无回秤；零碎缝隙冒充留白 |
| 4 图形表达 | 基线、节点、线、箭头、带宽及统计编码各有职责且可回算 | 装饰线条暗示不存在的关系；截轴未标 |
| 5 中文排版 | 断行贴合语义，数字单位同组，标点、字号与观看距离合理，实际字体与计划一致 | 数字与单位拆行、末行孤字、行首标点、替换字体后溢出 |
| 6 色彩系统 | 类别、状态与证据的编码一致、可辨，前景墨阶随明暗场成套切换 | 强调处处有、深浅切换后前景不对、仅靠颜色区分关键状态 |
| 7 关系可读性 | 路径、分支条件、依赖、图例、交叉及注释可追踪且不遮挡 | 线穿字、图例远离对象、关系需要猜 |
| 8 渲染与交付 | 实际 PPTX 对象按需可编辑，真实渲染无裁切、错位、替字，目标环境风险已说明 | 关键内容被裁、对象与 plan 不一致、未渲染却声称已预览 |
| 9 **概念成立** | 视觉概念可追溯到内容洞察（§1.1），有辨识度，并实际约束了图像、色彩、构图与字体的选择 | 换行业仍成立；概念只出现在 `visual_concept` 字段而页面没有体现；套用行业风格 |
| 10 **整稿成立** | 各页构成完整叙事，锁定项稳定、变化有理由（§1.2、§2.1），高潮与停顿可辨 | 缩略总览像同一模板复制；或像几套不同的稿子拼接；叙事断裂 |
| 11 **设计效率** | 每个元素说得出职责，删掉任何一个都有损失；信息不重复，表达与内容复杂度相称 | 装饰条、重复数字、无关图标、卡片套卡片、为“丰满”而加的图 |

**否决项不可抵消**：语义错误、数据失真、无证因果和关键内容不可读（S1）须先修复；它们不能由其他维度表现、加总分数或机器检查通过率掩盖。**概念成立 / 整稿成立 / 设计效率**不是检查表项：不能用单一总分替代，也不能由机器检查回答，必须看图并写出依据。

G-DECK 须看每页、缩略总览、相邻页和完整叙事，逐项核对 `focus_human_required` / `limitations`；机器通过不等于审美通过。发现问题按 `review-protocol.md` §4.2 找根因、定点修改，重新渲染后再判断。

## 8. 模板味与“AI 味”信号

这些是**症状**，不是禁令：只要能说出它在本页承担的职责，就可以保留。判断标准仍是“删掉它损失什么”。

| 信号 | 常见根因 | 改法 |
| --- | --- | --- |
| 每页都是“标题＋三栏卡片” | 没有按内容关系选组织方式 | 回到 §3.1：单论断、对照、流程、同源数据各用不同的空间组织 |
| 每条信息一个圆角卡片、卡片套卡片 | 用容器代替对齐与邻近 | 先用间距和对齐分组，容器只在需要承托或区分层面时出现 |
| 图标阵列代替论证 | 缺少真实关系，拿装饰填充 | 写出实体与关系；没有关系就用一句话或一个数字 |
| 渐变、发光、玻璃拟态等同于“科技感” | 把行业关键词直接映射成风格 | 回到 §1：图像世界、明暗与材质由受众与证据推出 |
| 页标题是话题（“市场分析”“总结”） | 没有主张 | 改写成证据支持的论断；写不出就是未决，标 `open_questions` |
| 正文把图表里的数字再念一遍 | 图与文没有分工 | 图承担读数，文字只写结论与限定 |
| 强调色处处都有、标题下都有装饰条 | 强调不按职责稀缺 | 回到 `color-art-direction.md` §3：只保留指向结论或行动的强调 |
| 一切居中、上下对称堆叠 | 回避取舍 | 找出本页的主角，用尺度与连续负空间建立不对称的平衡 |
| 无来源的“权威”数字、占位 Logo、假头像 | 为显得完整而补造 | 删除或标未决；示例数据须在页面上明示“示例” |
| 无功能的英文装饰标签（OVERVIEW、KEY TAKEAWAYS） | 套用模板气质 | 删除；若是导航或语言需要，保持整稿一致 |
| 概念能整体搬到另一个行业而不变 | 概念由行业关键词推出，不是由洞察推出 | 回到 §1.1：重写洞察句，再推概念 |
| 缩略总览里每页同重同构图，或前后像两套稿 | 没有按叙事职责安排节奏，或锁定项失守 | 回到 §2.1：先定哪页是高潮与停顿，再调整构图；锁定项统一 |
| 删掉一个元素没有任何损失 | 为“丰满”而加；缺少设计效率判断 | 删；若删后显得空，检查主角是否有分量，而不是补装饰 |
| 结尾只有“谢谢／Q&A” | 没有收束职责 | 收在决定、下一步或要带走的一句话；确需致谢则缩小其重量 |

自检顺序：缩略总览是否像同一模板复制 → 每页能否一句话说出主角 → 删掉任一装饰后信息是否受损。

## 9. 视觉概念生成工作坊：从洞察到可否决的概念

当 §1.1 的洞察句写不出来时，用以下五种“生成器”逼出概念。**每种都给出可落到版面的约束，而不是形容词**。选一种为主、必要时混用，但整稿只能用一套逻辑。

| 生成器 | 触发 | 概念形态 | 示例 |
| --- | --- | --- | --- |
| 尺度隐喻 | 内容本身有强烈的大小/数量对比 | 用尺度落差承载洞察 | “用户增长靠留存而非获客”→ 大数字（留存）压住小数字（获客） |
| 材质世界 | 主题有可被触摸的材质语义 | 建立可信材质与光 | 精密制造 → 金属/磨砂/冷光；食物 → 暖光/湿润/纹理 |
| 空间视点 | 内容需要“换个角度看” | 用机位/视角制造反转 | 风险被低估 → 从“地面”俯视到“系统”俯瞰 |
| 编辑装置 | 论证靠节奏与证据推进 | 用版面装置制造阅读节拍 | 连续基线、留白停顿、断行重音 |
| 字体姿态 | 标题本身就是论点 | 用字重/字号对比说话 | 主张与反主张用同版不同字重对冲 |

概念必须能**否决**具体选择（删掉一张与概念无关的图、一个不服务结论的色）。写不出否决条件的，回到内容重读。

## 10. 版式语法库（layout grammars）：按信息任务选结构

这些是可调用的设计语言，不是模板；同一语法在不同页按叙事职责变体。先判本页的信息关系与叙事职责，再选语法。

| 语法 | 何时用 | 关键手法 | 危险 |
| --- | --- | --- | --- |
| Swiss Grid | 多信息、需严谨层级 | 严格列网格、左对齐轴、留白节奏 | 变成无主角的方格墙 |
| Editorial | 故事、人物、观点 | 大标题跨栏、导语、图文分场 | 装饰压过论证 |
| Asymmetric | 需要张力与方向 | 偏轴、重轻对比、连续负空间回秤 | 失衡、无回秤 |
| Typographic | 标题即主张 | 字号尺度、断行重音、字重对冲 | 可读性牺牲 |
| Image-led | 图像承担叙事/情绪 | 全出血、安静区叠字、主体占位 | 主体与文字互抢 |
| Data-led | 证据即结论 | 大数字、直标、图表占主 | 数据淹没文字结论 |
| Diagram-led | 机制/流程/结构 | 基线、分支、层级、数量编码 | 装饰线暗示不存在的关系 |
| Modular | 复杂信息分组 | 模块网格、对齐分组 | 平均铺满、容器套容器 |
| Full-bleed | 沉浸、情绪高峰 | 大画面、最少文字 | 文字落点无安静区 |
| Expressive | 强个性/强视觉主题 | 破格构图、强色、动态张力 | 为表现牺牲信息秩序 |

**从角色到语法**：`open` 用 Image-led/Editorial/Typographic 建立世界；`build` 依关系在 Swiss/Data/Diagram 间选；`turn` 用 Asymmetric/Expressive 制造反转；`breathe/hold` 用大量留白与单一焦点；`close` 用 Typographic/Editorial 收回一句结论。相邻页若用同语法需有同轴比较理由，否则换语法制造节奏。

## 11. 中英文混排细则（concrete）

中文为主时，下列是可直接执行的规则，不是“注意混排”四个字：

- **间距**：中文与西文/数字之间按字体留 1/4–1/2 字宽空格或靠字体原生字距；同一文本对象内用 `runs` 统一基线，避免拆框导致漂移。`letter_spacing_pt` 只用于标题重音，正文慎用（破坏阅读节奏）。
- **标点**：中文用全角标点；西文 intra-word 用半角；引号/括号层级一致；行首禁放 `，。、）】` 等，行尾禁放 `（「『` 等（真实渲染查）。
- **数字与单位**：数字、单位、期间、正负号、专名保持同一语义组，不跨行拆开；`2026 Q3 / 营收 13 亿元` 不把数字与单位、期间拆行。大数字与其单位同组，单位用小一号或 `runs`，同基线。
- **字重**：同一字体字重足够区分时，不强行换字体；标题用重字重、正文用常规，强调用色或字号而非合成粗体（投影发虚）。
- **基线对齐**：同行中英数字混排时，数字/西文用同一字体族或设定好的替代字体，避免中文黑体配西文衬线造成的基线错落。
- **断行**：按语义断，不按字符数均分；末行不孤字，标题断在分句或主张重心处。手动换行用 `\\n`。

## 12. 整稿视觉叙事与情绪控制

把整套当成一部有开头、推进、转折、停顿、高潮、收束的作品，而不是独立页面的集合：

1. **开场（open）**：建立世界与问题，识别度优先；可 Image-led 或 Typographic，少字、强第一印象。
2. **推进（build）**：逐层加重证据；关系决定语法（Swiss/Data/Diagram）。
3. **转折（turn）**：换视角或结论方向，通常伴随尺度/明暗/构图的明显变化（Asymmetric/Expressive）。
4. **停顿（breathe/hold）**：让读者消化关键结论，可以更空、更慢——不是凑数过渡页。
5. **高潮（close 前的最强集中）**：最大的数字、最关键的证据、最有力的图像；数量由内容决定，不预设配额。
6. **收束（close）**：落到决定、下一步或要带走的一句话；避免只剩“谢谢/Q&A”。

**情绪曲线**由内容决定，不由模板决定：危机叙事需要前置张力，方案叙事需要后置释放。缩略总览必须能读出这条曲线；若所有页同重同构图，回到 §2.1 与 §1.2 重排节奏与锁定项。
