# 排版、视觉秩序与图文协同艺术指导

本文件是 `ppt-visual-art-director` 的条件性设计资源，仅在**复杂排版、中西文字体搭配、多元素图文冲突、跨页节奏诊断与视觉缺陷修正**时按需读取一次。全局优先级与决策主线继承 `SKILL.md §1–4`，本文件提供专项判断深度，不规定固定模板或强制参数。

## 一、方案冲突与取舍准则

排除违反 `SKILL.md §1` 高优先级底线（事实失真、关键信息缺失、不可读）的方案后，当多个可行构图竞争时依次比较：

1. **任务适配**：哪个方案最直接地成立核心主张、关键证据与本页叙事职责？
2. **理解效率**：哪个方案无需额外装饰即可建立第一视觉入口、阅读路径与分组关系？
3. **表达张力**：哪个方案通过有意义的尺度、明暗、疏密或图文关系强化记忆点，而非平均摆满？
4. **整稿价值**：哪个方案延续整稿视觉语法，同时与前后页形成合理的密度与重心变化？
5. **渲染稳健性**：哪个方案在真实字体回落、投影距离与文本自动换行波动下最不易溢出或错位？

仅在目标实质冲突、多方案确有竞争或初稿失效时展开比较，不机械输出打分表。

## 二、视觉主导点与三层权重

### 1. 主导点组织

- 每页建立清晰的视觉第一入口。复杂论证、前后对照或双方案权衡允许双焦点，但必须明确主次或左右对照轴，严禁全页元素等大等重。
- 主导点由内容形态决定，不必总是标题：可以是**结论句**、**决定性数字/对比差值**、**叙事主体图像**，或**标题＋核心指标构成的紧耦合整体**。

### 2. 三层级权重分配

- **主层级**：唯一主张、决定性指标或主体视觉。集中占用最大尺度对比、最优视线位置与焦点保护留白。
- **支撑层级**：论据、对比项、图表主体与关键说明。保持清晰可读但主动让出第一视觉冲击。
- **辅助层级**：口径限定、数据来源、单位期间、页脚与章节索引。字号与对比度明显降级（投影环境下中文辅助注释一般 `12–15pt`），稳定落位于边缘安静区。

中文汉字笔画密、字面满，与同字号西文/阿拉伯数字混排时视觉重量不同：判断层级必须看**字面面积、字重、墨色深度与周围留白**的综合重量，不能只看名义 pt 数值。

## 三、字体、文本职责与中文断行

### 1. 字体角色与中西文气质

建立克制、稳定的三类功能角色（可由同一字族的字重/字号变化完成，不必堆砌多款字体）：

- **展示角色**：封面、章节转折、核心主张或大号指标。品牌、文化、私行、人文主题可选宋体/衬线建立典雅克制气质；科技、战略、经营分析可选稳健无衬线建立利落秩序。
- **阅读角色**：多行论据、机制解释。优先保证字怀开阔、中宫稳健、投影距离不糊笔。
- **信息角色**：图表刻度、表格数字、单位期间、来源注释。优先清晰中性，数字对齐规整。

中西文与数字混排时检查基线、字面比例与笔画粗细匹配；避免花哨装饰字，不靠生硬拉大字距（letter-spacing）或使用极细字重伪造“高级感”。

### 2. 四类文本元素的排版职责

| 文本类型 | 核心职责 | 排版与断行控制要点 |
| --- | --- | --- |
| **标题（Title）** | 传递本页判断或建立篇章语境 | 优先一句话说清结论（`28pt+`）；按语义词组断行，严禁拆破专名与核心谓宾，严禁末行仅剩 1–2 个孤字；行距略紧（约 `1.1–1.2` 倍）形成整体块面。 |
| **正文（Body）** | 展开论据、因果与必要条件 | 投影阅读一般 `18–22pt`，行距适度舒展（约 `1.25–1.4` 倍），控制单栏行长避免视线横跨全屏疲劳；连续逻辑莫强拆成碎卡片，并列要点莫挤成整页长段。 |
| **关键数字（Number）** | 强化决定性量级、涨跌幅或对比 | 数字与单位、百分号、货币符号、正负号紧邻或成组排布，**严禁拆行**（如 `1.2 亿元`、`+25%`、`56万`）；必须交代比较基准或期间，杜绝无口径裸数。 |
| **注释与来源（Caption/Footer）** | 交代口径、期间、样本与出处 | 字号明确小于正文（`12–15pt`），弱化明度但保持可辨；固定在图表下方或页面底边基准线，不穿插干扰主阅读流。 |

### 3. 中文断行与空间压缩禁令

- 中文避头尾：句号、逗号、顿号、百分号、右括号不居行首；前引号、左括号、货币符号不居行尾。
- 文本溢出或拥挤时，严格执行 **删重复 → 并相近 → 缩冗词 → 调栏宽与构图 → 必要时拆页**，不得把正文字号缩至可读底线以下或把行距压死来硬塞原文。

## 四、空间、对齐与构图选择

### 1. 结构优先于组件：五级分组阶梯

严格遵循分组成本递增序 **`场域 > 对齐 > 发丝线 > 字体层级 > 容器`**，低成本结构手段足以区分归属时绝不升级：

1. **场域（零笔画成本）**：用整块连续负空间、组间距离显著大于组内距离（亲密性）、或页面深浅分区切分模块。
2. **对齐（零笔画成本）**：用共享左/顶基准轴、栏序网格与数值右对齐锁住隐形骨架，无需画框即可建立秩序。
3. **发丝线（单维轻成本）**：空间与对齐仍需显式切分时，仅用极细单向线条（栏目顶线、行间横线、十字坐标轴），不封四边。
4. **字体层级（局部权重成本）**：组内靠字号跨度、衬线/无衬线角色、字重与墨色灰阶区分眉标、主标、正文与注释，不给标题套色带或胶囊框。
5. **容器（最高视觉成本，最后手段）**：封闭色块、描边卡片、圆角面板会切割负空间、制造等重“组件墙”，仅用于底图叠字遮罩、复杂异构信息物理隔离或全页唯一高潮锚点。

常见场景的去容器化落地：
- **并列要点 / 产品层级 / 团队履历**：共享左基准线 ＋ 组间距拉开场域 ＋ 极细顶/间发丝线 ＋ 字重色阶，禁画等高描边卡片。
- **二维矩阵 / 象限 / 演进时间轴**：十字发丝轴或贯穿基准线 ＋ 空间方位落位 ＋ 目标项字重与强调色聚焦，不套外围大边框。
- **数据表格与图表**：透明无底场域 ＋ 列对齐（文本左、数值右）＋ 表头底线与行间微弱水平发丝线，摒弃厚重深色表头块、斑马色带、竖向网格线与图表外框。

### 2. 六维空间职责检查

1. **焦点空间**：主导元素周围是否有不被挤压的视觉呼吸区？
2. **关系空间**：同组内间距是否显著小于组间距，无需画框也能看出归属？
3. **边界空间**：元素距页面四边留有稳定安全边距（全出血图片/色块除外），不贴边局促、不悬空漂移。
4. **阅读空间**：栏宽、段距与图表留白是否顺应视线流向？
5. **负空间形态**：留白是否聚合成整洁连续的场域，而非被卡片框切割成零碎缝隙？
6. **跨页空间**：高密度论证页之后是否安排了适当的视觉舒展页调节阅读疲劳？

### 3. 由内容形态选择构图

拒绝把“左文右图”“等宽三卡片”“居中标题＋四宫格”当作万能默认：

- **单一核心论断 / 决定性指标**：集中焦点构图，大面积负空间定向托举主角。
- **因果链 / 阶段演进**：顺应阅读方向的线性或阶梯流向，用位置先后替代多余箭头。
- **双边权衡 / 前后对比**：非对称或双栏对照，共享明确比较维度，突出关键差值。
- **多维同源证据 / 机制拆解**：主结论统领下的分区网格或主次分栏（图表占主视觉、关键解读紧随其侧）。
- **场景与品牌叙事**：大幅出血图像或深浅场切换，文字集中落于图像低频安静区。

## 五、素材职责、语境适配与图文协同

### 1. 八类素材准入标准

引入任何非文字元素前先确认“删掉损失什么”；无实质损失即删除：

| 素材类型 | 法定职责 | 准入与排除边界 |
| --- | --- | --- |
| **背景** | 建立明度环境、品牌氛围与层次 | 低干扰托底，绝不抢夺前景文字与数据对比度 |
| **主体图像** | 承担核心场景、产品或人物叙事 | 景别、视线方向与负空间主动配合版面落字 |
| **辅助图像** | 补充局部证据、对比细节或实景 | 尺度与对比度明确服从主体，不并列争抢 |
| **图表 / 表格** | 诚实呈现数值关系、结构或对比 | 同单位同基准画图；异单位/多口径用原生表格 |
| **插画 / 图解** | 抽象机制、架构关系与空间示意 | 严禁以概念示意冒充实测曲线或真实产品界面 |
| **图标** | 辅助快速识别类别或状态导航 | 仅在确有助益时极简使用，删除“每段必配一图标”的装饰习惯 |
| **线条 / 色块** | 辅助分组、分割场域或承载叠字遮罩 | 服从 `场域 > 对齐 > 发丝线 > 字体层级 > 容器`：空间与对齐足够时不加线，发丝线与字重足够时绝不画封闭容器框 |
| **纯装饰元素** | 极少数品牌识别延展或篇章仪式感 | 无明确品牌/叙事依据一律拒绝 |

### 2. 语境真实性与裁切落位

- **中文与行业语境适配**：面向中国受众的场景摄影优先东亚人物面孔、自然神态与符合本土审美的现代/东方空间；坚决剔除西装握手、振臂握拳、金币堆叠、悬浮全息折线等廉价图库隐喻。缺少契合素材时，宁用纯排版构图或带明确说明的占位框，绝不凑图。
- **非变形裁切与叠字纪律**：图片框比例与原图不同时必须等比裁切（保留主体关键部位与视线方向），**严禁横向压扁或纵向拉长**。文字叠图必须落在自然低频暗部/亮部或加克制局部遮罩，确保投影下清晰可辨。

## 六、整稿视觉连续性与常见缺陷诊断

### 1. 统一与变化的边界

- **整稿保持恒定**：核心字体角色、主色与状态色语义、对齐基准逻辑、摄影光影与插画笔触体系。
- **跨页有据变化**：主导元素类型（大数字页、图表页、观点页、场景页）、构图重心、栏数、信息密度与明暗场节奏。

### 2. 常见缺陷快速诊断表

| 观察到的表象问题 | 真正根因 | 优先修正动作 |
| --- | --- | --- |
| 第一眼不知看哪里 | 标题、卡片、图标、数字权重接近 | 确立唯一主角并放大尺度/空间对比，果断降级其余元素 |
| 版面工整但平庸像模板 | 违背 `场域 > 对齐 > 发丝线 > 字体层级 > 容器`，并列内容一律套描边色块卡片 | 拆掉多余容器框与底带，退回场域留白、对齐基准、发丝线与字体层级组织 |
| 页面拥挤喘不过气 | 未经编辑直接堆砌原文，组间距失效 | 先删改合并文案，拉开组间留白，必要时拆分为两页 |
| 看似精致但投影看不清 | 浅灰小字、极细字重或高噪点背景叠字 | 提升前景背景明度差，恢复正文字重与可读字号 |
| 多页翻下来审美疲劳 | 连续页面使用同一构图、密度与高饱和色块 | 按叙事阶段插入舒展过渡页或切换主焦点形态，收敛强调色面积 |
| 编译后文字换行破句或溢出 | 实际字体宽度超出文本框预期 | 改写精简短句、调整断行与文本框宽高，在渲染图中复核 |
