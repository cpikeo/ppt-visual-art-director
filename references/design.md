# 设计判断

为什么这样做，什么时候不成立。字段见 `plan.schema.json` `elements.md`，流程与原则见 `SKILL.md`，诊断与复核见 `review.md`。这里不给模板，只给判断框架。

共同点（取其方法，不取外观）：**先有可说清的想法；系统让整套作品一致；每个细节都能回答“为什么”。**

## 零、八条原则

上游优先：内容 → 主导关系与构图 → 空间节奏 → 排印 → 图像色彩 → 工艺；上层问题不能用下层装饰修补。

1. 概念先于风格；原创是只属于这份内容的尺度、裁切、并置或读法，换配色字体只是表皮。
2. 关系先于版式：先判比较、时间、因果、流程、组成还是层级；相关与先后都不是因果。
3. 主次先于均衡：每页一个视觉主导，灰度下也成立；固定位置的重复装饰不是母题。
4. 编辑先于缩放：装不下就删、合并、改写、拆页，不压字号。
5. 色彩是关系系统：先定明度与职责；强调色只指向结论；同一对象跨页同色。
6. 真实先于完整：没证据的页宁可留白；生成图只承担氛围；缺的数字进 `open_questions`，不补造。
7. 判断先于规则：尺度、裁切或留白本身是论据时可破格，在 `composition_rationale` 写明破了哪条、换来什么、谁承担代价；整稿只破少数几次。
8. 停止先于完美：系统成立即停；两轮无实质改善，交给人决策。

## 一、概念

**洞察句**：观众原以为什么 → 证据说明什么 → 差距在哪。“他们以为问题在获客，数据显示在留存”是洞察；“增长遇到瓶颈”不是。

**概念由洞察推出**，可来自尺度、材质、空间、视角或叙事结构；不必是比喻，但要具体到能指导选择；整稿一套生成逻辑。行业、品牌、受众是**约束**（决定哪些做法不可行），不是答案。

| 生成器 | 触发 | 做法 |
| --- | --- | --- |
| 尺度隐喻 | 内容有强烈的大小、数量落差 | 用一个数字压住另一个，让落差说话 |
| 材质世界 | 主题有可触摸的材质语义 | 可信的材质与光：金属的冷、纸的纤维 |
| 空间视点 | 需要“换个角度看” | 平视切俯瞰，局部拉到系统，视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、停顿、断行重音，版面本身是论据 |

概念必须落到五件事，否则只是形容词：**图像世界**（媒介、光、色域、材质）、**明暗与色彩角色**、**空间母题**（重心、留白逻辑）、**字族角色**（谁大声、谁解释）、**跨页节奏**（哪页最重、在哪停顿）。

**编辑取舍**（落版面之前先做）：**放大**（支撑主张的一两样，用尺度、位置、明度推到前景）、**退隐**（必须在场但不抢戏：灰阶、小字、边缘、附录）、**删除**（与主张无关的荣誉、功能墙、第二条故事线）。记忆点来自**一处够强的对比**——尺度（200pt 对 72pt）、明度（暗场插在浅场里）、密度（极密后接极空）、位置（唯一一次破网格）；每份稿先选一个主对比，其余页为它让路。风格词只是结果描述：先写“让什么压住什么”。

**原创长在哪**：每条原创都能指到内容独有的关系——只有这份数据才有的落差、只有这个对象才成立的裁切、两条证据并置才有的读法。指不到，就还是外观差异。

## 二、艺术指导

概念回答“用什么关系”，艺术指导回答“看起来是什么世界”。先定五个参数，整稿照此执行；换页只允许变一个（通常是景别或光向）。

| 参数 | 要定什么 | 常见错误 |
| --- | --- | --- |
| 光 | 硬或柔、方向、色温（暖约 3200K，冷约 5600K） | 每页光向不同，像拼贴 |
| 视角与景别 | 平视、俯视、微距；全景、中景、特写 | 一页一视角，像素材库 |
| 材质 | 石、纸、金属、织物、液体；哑或亮 | 材质与主题无关 |
| 色域 | 主色相范围、饱和上限、能否用纯黑纯白 | 一页鲜艳一页灰 |
| 颗粒与镜头 | 干净数码、细颗粒、浅景深、长焦压缩 | 颗粒通篇叠加当“质感” |

图像世界选一类为主：**记录**（现场、人物、实拍，保留在场感）；**静物**（可控台面，单光源加接触阴影，主体偏置留安静区）；**结构**（抽象、几何，极简强对比，不冒充真实对象）。光影与材质是同一种语言：一份稿一种主光、一种材质逻辑；玻璃、金属、石、纸、木都要有可被反射或透过的环境，否则假；原生图形里的投影、发光、玻璃拟态没有光源依据就不用。

**一致性检查**：把整稿的图排在一起——光向连得成线吗？色温同一个世界吗？主体尺度在跳吗？图不对时先改简报，不改形容词（镜头单、简报与提示词见 `imagery.md`）。

## 三、叙事

整稿是有开头、推进、转折、停顿、高潮、收束的作品，不是页面的集合。

| `role` | 叙事动作 | 判断要点 |
| --- | --- | --- |
| `open` | 建立世界与问题 | 识别度优先，字少，让人想知道后面 |
| `build` | 积累证据，逐层加重 | 同类证据用同一讲法 |
| `turn` | 换视角或结论方向 | 必须伴随尺度、明暗或构图的明显变化 |
| `breathe` / `hold` | 让人消化关键结论 | 更空、更慢、单一焦点；不是凑数的过渡页 |
| `close` | 落到决定、下一步或要带走的一句话 | 求可执行的落点，不求完整收尾 |

弧线按内容选：论证型（主张→证据→反证→结论）、发现型（现状→异常→解释→行动）、提案型（问题→方案→代价→请求）。**高潮**是最强的一次集中（最大数字、最关键证据、最有力图像），数量由内容决定：一页都不给整稿就平，页页都是就没有高潮。**母题**带来辨识度，不靠每页长得像：一到两个反复出现的装置（同一基线位置、色带、编号体系、裁切比例、留白缺口）。`rhythm` 每页一句，用动词与分量词。

**整稿检查**（对着缩略总览，只看轮廓与明暗）：读得出开场、推进、转折、收束吗？相邻页变化有理由吗？最重的一页是最重要的一页吗？标题连起来是一段话，还是五个话题？

## 四、空间构成

**锁定与放开**。锁定：字族角色、墨阶与语义色、对齐轴与留白逻辑、图像世界、图形语言。放开：构图、尺度、密度、明暗场、图像占比，由本页职责决定。锁定的逐页变化则整稿散；放开的全被锁死则整稿单调。

**网格是选的，不是给的**。多栏对照、表格与图表要稳定行列（12 栏、模块网格）；一句论断与一个数字适合少栏大留白（5、8 栏，左边多空两栏）；整幅图、整页色场、巨型数字在网格之外建立秩序，靠一条贯穿的边、基线或裁切站住。换网格要有理由（密度、角色变了），不为避免重复。破网格的检验：关掉装饰，重心与阅读顺序还说得清吗。

| 内容关系 | 成立的组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 结论与支持信息有明显尺度或明度差 | 所有内容同重 |
| 机制、流程 | 路径与间距反映已知顺序 | 箭头暗示未经证实的因果 |
| 对照、并列 | 同一基线、可比尺度；确实等重才并列 | 为造主角偷换权重 |
| 同源数据 | 主张、图形、单位形成一条阅读路径 | 图表缩在角落，正文重念数字 |
| 场景 | 图像承担空间与情绪，文字进入安静区 | 图文互抢，靠浓遮罩掩盖杂乱 |

`composition_rationale` 说清：先看到什么，用什么手段建立层级，次级顺序，放弃了哪个方案。说不出就回去重读内容。

**比例与重心**：等分给秩序，三分、四分给稳定，黄金位给紧张；5:7 是“字少图大”，7:5 是“图为主、字压边”，由内容决定。主体重心低于画布一半显压、稳，高于一半显轻、待发生；占三分之一是陈述，一半是主张，满幅是宣告。非对称时用对侧连续负空间、对齐轴、视线拉回；补一块同重色块是廉价解法。

**纵深**靠尺度差、遮挡、明度后退、边缘处理，不靠阴影堆和伪透视：前景（出血大字、裁切主体）、中景（主信息）、背景（场与纹理）各做一件事，明度依次后退，跨页保持方向一致。出血表示“世界还在画布外”，内收表示“这是一张图”。

**留白**保护焦点、分组、停顿、视线。极空而主角没分量不是克制，是没做完；零碎缝隙冒充留白最常见。先用邻近、对齐、间距分组，再考虑容器。

**空间气质**（`composition.temperament`；由尺度、密度、边界、对比共同建立，风格词不算）：`open` 大主体宽空｜`immersive` 满版包围、文字进图内安静区｜`editorial` 非对称、错位、比例变化｜`architectural` 网格与轴线｜`museum` 主体独立、精确边界｜`dense` 紧凑分组、精确对齐｜`dramatic` 尺度或明暗反差（`hero_ratio` 声明主角对最强配角的最低倍数）。`negative_space.role` 写明空白的功能：`focus` 围主角｜`group` 分组｜`pause` 停顿｜`direction` 引导｜`image_text` 图文安静区。`verify.py` 量测真实渲染的占用率、最大连续空白与跨页版面签名：未声明功能的整页过疏或大块空白、声明与量测不符、连续 3 页分区占用几乎相同，给 `V-SPACE` `V-RHYTHM`。量测只证明“声明被兑现”，不证明好看；相邻页重复同一版式语法须有同轴比较的理由。张力选一个主手段：尺度反差、明暗反转、方向对冲、密度断层、切边出血、单一破例，破格写理由。

信息设计、排版、色彩见 `craft.md`。

**跨页节奏的词汇**（不是新字段）：秩序页＝`architectural｜dense`；张力页＝`dramatic`＋`hero_ratio`；沉浸页＝`immersive`＋`image_text`；细节页＝`crop_zoom` 局部（整稿最多两三次）；转场页＝`role: turn｜breathe`，尺度或明暗必须变。排布由内容决定，不套固定顺序；整稿统一来自锁定的字族、墨阶、图像世界与母题。

**16:9 画布的尺度语法**（1280×720 px；plan 仍写英寸，px = in × 96）。16:9 是一条横带：视线主要沿水平方向移动，纵向层级的空间只有 720 px，所以层级靠**尺度差与明度差**而不是靠纵向堆叠。判断要点：
- **边与角有分工**：左上是入口（页题、母题），右下是页码保留区（x ≥ 1151 px、y ≥ 651 px，别放信息）；`footer_top` 以下只放口径与来源。
- **分割线不是模板**：5/12（≈533 px）给“字少图大”，黄金线 ≈ 791 px 给紧张，三分线 ≈ 427/853 px 给稳定；选哪条要能回答“它在论证什么”。有意出血的元素必须越过画布边（超出 ≥ 0.1 in），距边 1–10 px 的“差一点出血”几乎总是事故。
- **负空间要连续**：一块 ≥ 1/4 页宽、整高的连续空白，比四处各 40 px 的缝隙有力得多；非对称构图的另一侧必须有它（或一道贯穿的对齐轴）。
- **字号看 px 才直观**：14 pt ≈ 19 px 是会议室后排的下限；标题 ≥ 24 pt ≈ 32 px；巨型数字用图形尺度（≥ 200 px 字高）做承载层，而不是更大的正文。
- **跨页的“同一条线”**：整稿选一条贯穿的基线、一条出血边或一个切口（母题），跨页位置固定、尺度变化；位置每页都变就不是母题。

## 五、不规则构成与图像融合

先写一句**页面视觉概念**（`page.concept`：这页的尺度、视角或裁切在论证什么），再选构图；不是先套版式再填图。构图词（`composition.strategy`）：`layered` 层叠穿插、`diagonal` 对角牵引、`interlock` 图文互锁、`bleed` 出血穿越，另有 `free`。破格必须有依据：删掉斜边、重叠或裁切，页面的重心与阅读顺序还说得清吗？说不清就是装饰。

六种关系各管一件事：**尺度**（主图压过配图至少一档，等重是四宫格）；**位置**（重心偏向一侧，对侧留连续负空间给字）；**边界**（出血表示世界在画外；斜切、圆形、柔边只用在需要“切开”或“连成一个场”的地方，整页同一种蒙版就是滤镜）；**遮挡**（前景压住背景是纵深，压住信息是事故）；**色彩**（同页图的明度、冷暖、色度归一；有意的差异写进 `composition.exception`）；**空间**（文字落在图的安静区，不靠遮罩）。

**局部放大**（`crop_zoom` 1–8，围绕 `crop_focus` 在 cover 窗内等比放大，原生 `srcRect`，可在 PowerPoint 里继续调裁切）：同一素材既做整体（尺度、场景）、又做局部（釉面、纹理、细节）时，局部必须来自同一张图或同一光向的图，才算“远近关系”而不是拼贴；放大后有效 ppi 仍须 ≥ 72（`W-PPI`），故意放大不再报 `W-CROP`。局部压住大图边界时，圆形或斜切蒙版只用这一处，且不得压字（文字框被图擦边遮挡同样 `E-OVERLAP`）。

每张图一个职责：主图（`hero`）建立焦点，环境图（`background`）承载空间，辅助图（`subject`）推进叙事，细节图（`detail`）给证据与质感；删掉它页面不受损就删。多图的视角、光向、景别要成体系：从特写到全景的递进是叙事，随机拼贴不是。

**图像融合的决策顺序**（先问职责，再动手）：①这张图在页里是**场**（承载空间与光）、**证据**还是**局部**？场的图让位给字，证据的图不得被遮罩改色，局部必须与场同源；②背景与主体共用同一个明度结构——背景最暗/最亮处靠近主体的一侧，另一侧留给字；③边界用一种语言（出血、斜切、柔边三选一为主，另一种最多出现一次）；④融合不够时先改裁切与 `crop_focus`，再改 `duotone`，最后才重做图，**不靠遮罩与阴影**；⑤同页出现第二张图，必须说得出它与第一张的“远近、前后或证据关系”。

验收顺序与修正顺序见 `review.md`（删除 → 合并 → 简化 → 调整 → 新增）。`W-FUSION` 只量明度/冷暖/色度，**不代表好看**。

## 六、整页空间合成：图像、背景、字共同建立一个场

图不是贴在页上的块，而是页面空间、色彩、光与材质的一部分。动手前先回答四个问题，答不出就回到 `page.concept`：**这一页的“场”是什么**（一块材料的远近、一个尺度落差、两种材质的交界）？**哪一层承担空间**（背景/环境图）、**哪一层承担证据**（主体/细节图）、**哪一层承担读法**（字）？**视线怎么走**（入口、转折、落点，写进 `composition.reading_path`）？**哪里必须空**（给字、给停顿、给方向，写进 `negative_space`）？

方法是工具箱，不是配方；每种只在对应的内容关系下成立，整稿同一种手法最多出现两三次：

| 手法 | 成立的内容关系 | 失败信号 |
| --- | --- | --- |
| 尺度对照（整体＋局部来自同一素材，`crop_zoom`） | 论点是“远看与近看不同” | 局部来自另一张图，只是拼贴 |
| 边界穿插（局部压住大图边界一次，圆形或斜切只此一处） | 两个距离、两种材质需要缝成一个空间 | 每张图都有蒙版；局部压到文字或信息 |
| 出血与裁切（`bleed`） | “世界还在画布外”、数字或图作为承载层 | 出血的是信息，被裁掉的是单位或口径 |
| 对角牵引（斜切边、`diagonal`） | 两个对象间有真实的转换或交界 | 斜线与阅读顺序、重心无关 |
| 虚实交错（柔边 `soft_edge_pt`、景深差） | 需要把前景从场里“托”出来 | 全页模糊当氛围，主体不清 |
| 疏密对比（极密后接极空，局部留白） | 需要停顿或强调一个转折 | 留白里没有主角，只是没做完 |
| 文字承载（字落在图的安静区或做承载层的巨型数字上） | 图文同源 | 靠浓遮罩救字；字压在高纹理区 |

**合成检查**：交付前四问见 `SKILL.md`；另看两点——同页图的光向、色温、色度是否同一世界（`I-FUSION` 只量这三项，有意差异写 `composition.exception`）；图与相邻色块的衔接是否有意（突兀亮边、同明度并排、两块各自独立的暗场是常见败笔）。同一张图在两页出现须承担不同职责（整体 vs 局部、前景 vs 背景），否则换图或删页。机器只指出差异在哪，**不能判断好看**，由看图的人签收。
