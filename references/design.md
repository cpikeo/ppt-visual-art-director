# 设计判断

为什么这样做，什么时候不成立。字段见 `build.md` `elements.md`，流程与原则见 `SKILL.md`，诊断与复核见 `review.md`。这里不给模板，只给判断框架。

共同点（取其方法，不取外观）：**先有可说清的想法；系统让整套作品一致；每个细节都能回答“为什么”。**

## 零、原则

上游优先：内容 → 主导关系与构图 → 空间节奏 → 排印 → 图像色彩 → 工艺；上层问题不用下层装饰修补。概念先于风格（原创是这份内容独有的尺度、裁切、并置或读法）；关系先于版式；主次先于均衡（每页一个视觉主导，灰度下也成立）；编辑先于缩放（装不下就删、合并、拆页，不压字号）；色彩是关系系统（强调色只指向结论，同一对象跨页同色）；真实先于完整（没证据的页宁可留白，缺的数字进 `open_questions`）；判断先于规则（破格在 `composition_rationale` 写明破了哪条、换来什么，整稿只破少数几次）；停止先于完美（系统成立即停，两轮无实质改善交给人）。

## 一、概念

**洞察句**：观众原以为什么 → 证据说明什么 → 差距在哪。“他们以为问题在获客，数据显示在留存”是洞察；“增长遇到瓶颈”不是。

**概念由洞察推出**，可来自尺度、材质、空间、视角或叙事结构；不必是比喻，但要具体到能指导选择；整稿一套生成逻辑。行业、品牌、受众是**约束**（决定哪些做法不可行），不是答案。

| 生成器 | 触发 | 做法 |
| --- | --- | --- |
| 尺度隐喻 | 内容有强烈的大小、数量落差 | 用一个数字压住另一个，让落差说话 |
| 材质世界 | 主题有可触摸的材质语义 | 可信的材质与光：金属的冷、纸的纤维 |
| 空间视点 | 需要“换个角度看” | 平视切俯瞰，局部拉到系统，视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、停顿、断行重音，版面本身是论据 |

概念必须落到五件事，否则只是形容词：**图像世界**（媒介、光、色域、材质）、**明暗与色彩角色**、**空间母题**（重心、留白逻辑）、**字族角色**（谁大声、谁解释）、**跨页节奏**（哪页最重、在哪停顿）。

**编辑取舍**（落版面之前先做）：**放大**（支撑主张的一两样，用尺度、位置、明度推到前景）、**退隐**（必须在场但不抢戏：灰阶、小字、边缘、附录）、**删除**（与主张无关的荣誉、功能墙、第二条故事线）。记忆点来自**一处够强的对比**——尺度（200pt 对 72pt）、明度（暗场插在浅场里）、密度（极密后接极空）、位置（唯一一次破网格）；每份稿先选一个主对比，其余页为它让路。风格词只是结果描述：先写“让什么压住什么”。

**原创长在哪**：每条原创都能指到内容独有的关系——只有这份数据才有的落差、只有这个对象才成立的裁切、两条证据并置才有的读法。指不到，就还是外观差异。

## 二、艺术指导

概念回答“用什么关系”，艺术指导回答“看起来是什么世界”。先定五个参数（`brief.art`：`light` `lens` `material` `gamut` `grain`），整稿照此执行，换页只允许变一个（通常是景别或光向）：**光**（硬柔、方向、色温，暖约 3200K、冷约 5600K）、**视角与景别**（平视、俯视、微距；全景、中景、特写）、**材质**（石、纸、金属、织物、液体；哑或亮）、**色域**（主色相范围、饱和上限、能否用纯黑纯白）、**颗粒与镜头**（干净数码、细颗粒、浅景深；颗粒不通篇叠加当质感）。图像世界选一类为主：**记录**（现场、人物，保留在场感）、**静物**（可控台面，单光源加接触阴影，主体偏置留安静区）、**结构**（抽象、几何，不冒充真实对象）。玻璃、金属、石、纸、木都要有可被反射或透过的环境，否则假；原生图形的投影、发光、玻璃拟态没有光源依据就不用。

**一致性检查**：把整稿的图排在一起，光向连得成线吗、色温同一个世界吗、主体尺度在跳吗？图不对时先改简报，不改形容词（简报与提示词见 `imagery.md`）。

## 三、叙事

整稿有开头、推进、转折、停顿、高潮、收束。`role` 是叙事动作：`open` 建立世界与问题（识别度优先，字少）｜`build` 积累证据（同类证据同一讲法）｜`turn` 换视角或结论方向（必须伴随尺度、明暗或构图的明显变化）｜`breathe`/`hold` 让人消化结论（更空、更慢、单一焦点，不是凑数过渡页）｜`close` 落到决定、下一步或要带走的一句话。弧线按内容选：论证型（主张→证据→反证→结论）、发现型（现状→异常→解释→行动）、提案型（问题→方案→代价→请求）。**高潮**是最强的一次集中（最大数字、最关键证据、最有力图像），一页都不给整稿就平，页页都是就没有高潮。**母题**带来辨识度，不靠每页长得像：一到两个反复出现的装置（同一基线位置、色带、编号体系、裁切比例）。`rhythm` 每页一句，用动词与分量词。整稿检查（对着缩略总览只看轮廓与明暗）：读得出开场、推进、转折、收束吗？最重的一页是最重要的一页吗？标题连起来是一段话，还是五个话题？

## 四、空间构成

空间不是装饰，是组织内容的结构。**不追求填满，也不追求留空**：每个元素的位置、尺度、关系都要有表达理由。先定内容与主体，再定空间与构图；先定比例与层级，再处理图像、光影、材质；先保证单页，再编排整稿。

**空间气质**（`composition.atmosphere`，每页自选，整稿语言一致）：`open` 开阔（大主体、低密度：封面、核心观点）｜`immersive` 沉浸（满版图、前后景：产品、电影化叙事）｜`editorial` 编辑（非对称、错位、比例变化：品牌故事）｜`architectural` 建筑（网格、轴线、几何：战略、研究）｜`museum` 博物馆（主体独立、克制背景：文化、艺术、高端）｜`dense` 高密度秩序（紧凑分组、精确对齐：数据、财务）｜`dramatic` 戏剧（尺度反差、明暗对比、局部聚焦：转折与结论）。

**三级主次**：主体 Hero（本页最重要的观点、数字、对象）、辅助 Support（解释、对照）、环境 Atmosphere（背景、图、材质、光影）。三级必须有明确的视觉权重差，不能同时争夺注意力。重心按表达选：中心＝稳、偏心＝张力、轴线＝权威、对角＝动势、上下分层＝叙事、满版＝宣告；非对称用对侧连续负空间、对齐轴或视线拉回，补一块同重色块是廉价解法。主体占三分之一是陈述，一半是主张，满幅是宣告；重心低于一半显压稳，高于一半显轻。

**尺度与比例**：张力来自大小、近远、粗细、虚实、疏密的反差；主体可以巨大也可以极小，图文比例由内容重要性定，不设模板。禁止为留白而无理由缩小主体，禁止所有元素尺寸与权重相近。

**负空间**按功能分四类：外围（边界与气质）、主体（释放焦点）、图文（呼吸）、结构（分组与节奏）。留白不必平均，必须有作用；极空而主角没分量不是克制，是没做完；先用邻近、对齐、间距分组，再考虑容器。重要元素可靠边或出血，但关键信息不被切、安全边距要在。

**网格是选的**：多栏对照、表格、图表要稳定行列；一句论断加一个数字用少栏大留白；整幅图、整页色场、巨型数字在网格外建立秩序，靠一条贯穿的边、基线或裁切站住。换网格要有理由。破网格的检验：关掉装饰，重心与阅读顺序还说得清吗。

**图像**是构图材料，不是占位框：先定主图与辅图（单张主视觉、双图对照、多图叙事、大小组合、满版加局部细节），不做等尺寸阵列。裁切由主体位置、取景距离、视线方向、透视、文字安全区决定，不由图框决定；图的边界（出血、硬边、统一边距、局部遮挡）是构图的一部分，不默认圆角卡片与装饰边框。图的明度分布决定文字落点：把标题放进图自带的连续低纹理区，不靠遮罩。

**纵深**靠前景（出血大字、裁切主体）、中景（主信息）、背景（场与纹理）的尺度差、遮挡与明度后退建立，跨页方向一致；材质与光影须有可被反射或透过的环境，否则不用。出血表示“世界还在画布外”，内收表示“这是一张图”。

**页面任务与整稿节奏**：封面建立鲜明主体与识别｜章节页收敛、释放空间｜观点页放大标题与主体｜叙事页靠图文位置与层次推进｜数据页控密度、保证比较｜案例页以图为主、整体加局部｜对比页靠分区、镜像、明暗｜总结页收敛｜结尾页留记忆点。整稿要有疏密、强弱、快慢、开合与重心的变化：**锁定**字族角色、墨阶与语义色、对齐轴、图像世界、图形语言；**放开**构图、尺度、密度、明暗场、图像占比。锁定的逐页变化则整稿散，放开的全被锁死则整稿单调。相邻页重复同一版式语法须有同轴比较的理由。

**每页判断顺序**（不从模板反推内容）：本页任务 → 主体 → 气质 → 主次与重心 → 尺度 → 负空间与阅读路径 → 图像 → 层次 → 与前后页的节奏。写进 `focus`、`composition_rationale`：先看到什么、用什么手段建立层级、次级顺序、放弃了哪个方案；说不出就回去重读内容。

**空间自检八项**：气质贴合内容｜主辅环境与重心明确｜注意力集中且平衡｜主体、字、图、信息区有尺度反差｜留白有视觉或信息功能｜图的组合、裁切、边界经过设计｜纵深与材质自然必要｜单页适配任务、整稿有疏密强弱。必须修正：主体不突出、重量失衡、空间分配失当、留白无效、图文互挤、裁切不当、纵深虚假、页面机械重复。达到“信息清晰、主体与层级明确、空间合理、整稿一致且有节奏”即停，不为变化而二次装饰。机器只给事实线索（`W-DOMINANT` `W-VOID` `W-RHYTHM` `W-CENTROID` `W-ATMOS` `W-MONOTONY`），不判好看。

信息设计、排版、色彩见 `craft.md`。
