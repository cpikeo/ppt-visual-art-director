# 设计判断：概念、叙事、构图、图形、诊断

专业判断的依据、成立条件与失效信号。这里不给固定坐标和版式墙；坐标见 `build.md`，手艺细节见 `craft.md`。

## 概念

**概念是一句话，不是形容词。**它必须能回答：从哪条洞察出发，用什么视觉关系让这条洞察被看见，并因此否决什么。

### 从洞察到概念

1. **写洞察句。** 观众原本怎么想、证据说明什么、差距在哪。"他们以为问题在获客，数据显示问题在留存"就是一个洞察；"增长遇到瓶颈"不是。
2. **由洞察推概念。** 概念可来自尺度对比、材质、空间关系、观看视角或叙事结构。不必是比喻，但必须具体到能指导选择。
3. **转成约束。** 概念要能落到五件事上，并能否决具体选择：
   - 图像世界（媒介、光、色域、材质）
   - 明暗与色彩角色（哪里亮、哪里暗、什么色承担什么）
   - 空间母题（重心偏向、留白逻辑、是满还是空）
   - 字族角色（谁大声、谁小声、谁解释）
   - 跨页节奏（哪一页最重、在哪里停顿）

### 概念生成器（洞察句写不出来时用）

| 生成器 | 触发条件 | 长什么样 |
| --- | --- | --- |
| 尺度隐喻 | 内容本身有强烈的大小或数量对比 | 用一个数字压住另一个数字，让落差本身说话 |
| 材质世界 | 主题有可被触摸的材质语义 | 建立可信的材质与光：金属的冷、纸的纤维、食物的湿 |
| 空间视点 | 需要"换个角度看" | 从平视切到俯瞰、从局部拉到系统，让视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、留白停顿、断行重音——版面本身就是论据 |
| 字体姿态 | 标题本身就是论点 | 主张与反主张在同版用不同字重对冲 |

选一种为主，整稿只用一套逻辑。混用两套等于没有概念。

### 概念不成立的样子

- 换掉行业和主题后依然成立——那是通用风格，不是本稿概念。
- 只写在 `visual_concept` 字段里，页面上看不出任何痕迹。
- 无法否决任何具体选择：说得出"应该高级一点"，说不出"这张图不要"。
- 用行业符号顶替推导：把"金融"映射成深蓝金边、把"科技"映射成渐变发光。

行业、品牌调性、受众习惯是**约束输入**，不是答案：它们决定哪些做法不可行，不决定概念本身。

## 叙事

把整稿当成一部有开头、推进、转折、停顿、高潮、收束的作品，而不是独立页面的集合。

| `role` | 叙事动作 | 常见判断 |
| --- | --- | --- |
| `open` | 建立世界与问题 | 识别度优先；少字、强第一印象；让人想知道后面是什么 |
| `build` | 积累证据，逐层加重 | 关系决定语法；同类证据用同一逻辑，避免每页换一种讲法 |
| `turn` | 换视角或换结论方向 | 通常伴随尺度、明暗或构图的明显变化；没有变化就没有转折 |
| `breathe` / `hold` | 让人消化关键结论 | 更空、更慢、单一焦点；不是凑数的过渡页 |
| `close` | 落到决定、下一步或要带走的一句话 | 不求完整收尾，求一个可执行的落点 |

**高潮**是最强的一次集中：最大的数字、最关键的证据、最有力的图像。数量由内容规模和决策节点决定，不预设配额；一页都不给，整稿就平；页页都是高潮，就没有高潮。

**乐谱**（`rhythm`）按页写一句"这页在做什么、有多重"，不要写形容词。危机叙事需要前置张力，方案叙事需要后置释放。

**整稿检查**（对着缩略总览）：

1. 只看轮廓与明暗，能读出开场—推进—转折—收束吗？
2. 相邻页的变化有叙事理由吗？没理由的变化是噪声；没有变化的同构图，若用于同轴比较则成立。
3. 锁定的东西（见「构图 · 什么锁定、什么放开」）逐页稳定吗？
4. 最重的那一页，确实是内容最重要的一页吗？

## 构图

### 先读内容关系，再安排空间

| 内容关系 | 成立的空间组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 结论与支持信息形成明显的尺度、位置或明度差 | 所有内容同重；装饰抢焦点 |
| 机制／流程 | 路径与间距反映已知的顺序和关系 | 图标阵列或箭头暗示未经证实的因果 |
| 对照／并列 | 同一基线、可比尺度；确实等重时才并列 | 为造一个主角偷换权重 |
| 同源数据 | 主张、图形、单位形成一条阅读路径 | 图表缩在角落，正文把数字再念一遍 |
| 场景 | 图像承担空间或情绪，文字进入真实安静区 | 图像与标题互抢，或用浓遮罩掩盖杂乱 |

`composition_rationale` 要说得清：读者先看到什么、用什么手段建立层级、次级阅读顺序是什么、放弃了哪个方案。说不出来，就回去重读内容，别靠增加零件。

### 张力怎么成立

- **尺度与重心**：需要强调就拉开可感知的差距，不要同时加粗、加色、描边。不能只按面积推断谁先被看见——一平方英寸的纯黑比四平方英寸的浅灰更重。
- **平衡**：对称靠数量，非对称靠回秤。偏重一侧之后，让对侧用连续负空间、对齐轴、图像视线或必要的次级信息把它拉回来；没有回秤的偏重就是失衡。
- **边缘与留白**：贴边、出血表达世界延展；内收表达秩序。留白要保护焦点、分组、停顿或容纳视线。零碎空隙不是留白；极空但主角没分量，也不是克制。
- **轴线与密度**：先用邻近、对齐、间距分组，再考虑容器。无关轴线越多越乱。把需要连读的信息组织成密度块，其余空间服务阅读，不要把段落、卡片和空隙平均铺满。
- **动势**：有顺序才有方向；有主次才有引导；有累积才谈积聚；需要理解结论时才停顿。静态对照、严肃表格、真正并列可以完全没有主导运动。斜线、透视和装饰曲线本身不构成动势。

### 什么锁定、什么放开

识别来自少数被锁定的逻辑，而不是每页长得像。

- **锁定**：字族角色与字重分工、墨阶与语义色、主要对齐轴与留白逻辑、图像世界（媒介、光、色域、材质）、图形语言（线、点、块的统一用法）。
- **放开**：构图、尺度、密度、明暗场、图像占比、有没有主角——由本页的叙事职责决定。

锁定的东西逐页变化，整稿就散；放开的东西也被锁死，整稿就单调。

## 版式语法

可调用的设计语言，不是模板。先判本页的信息关系与叙事职责，再选语法；同一语法在相邻页重复，必须有同轴比较的理由。

| 语法 | 何时用 | 关键手法 | 危险 |
| --- | --- | --- | --- |
| 网格秩序 | 多信息、需要严谨层级 | 严格列网格、左缘对齐轴、留白节奏 | 变成没有主角的方格墙 |
| 编辑式 | 故事、人物、观点 | 大标题跨栏、导语、图文分场 | 装饰压过论证 |
| 非对称 | 需要张力与方向 | 偏轴、重轻对比、对侧负空间回秤 | 失衡、无回秤 |
| 字体主导 | 标题本身就是主张 | 字号尺度、断行重音、字重对冲 | 可读性被牺牲 |
| 图像主导 | 图像承担叙事或情绪 | 全出血、安静区叠字、主体偏置 | 主体与文字互抢 |
| 数据主导 | 证据即结论 | 大数字、直标、图表占主 | 数据淹没了结论 |
| 图解主导 | 机制、流程、结构 | 基线、分支、层级、数量编码 | 装饰线暗示不存在的关系 |
| 模块化 | 复杂信息分组 | 模块网格、对齐分组 | 平均铺满、容器套容器 |
| 满幅沉浸 | 情绪高峰、开场 | 大画面、极少字 | 文字落点没有安静区 |
| 表现性 | 强个性、强主题 | 破格构图、强色、动态张力 | 为表现牺牲信息秩序 |

**角色到语法**：`open` 用图像主导／字体主导／编辑式建立世界；`build` 依关系在网格、数据、图解之间选；`turn` 用非对称／表现性制造反转；`breathe`/`hold` 用大量留白与单一焦点；`close` 用字体主导或编辑式收回一句结论。

破格（出血、跨轴、超大字）要能说出理由；说不出就回到网格。**满幅大图＋居中标题不是第四种语法**，它是图像主导的默认做法，用之前先问主体在哪、安静区在哪。

## 信息图形

先写清**实体、关系、方向与范围**，再问：有没有真实时间、可比数值、共同分母、节点归属、条件与证据？数据的精度和不确定性允许什么结论？然后选最简单能保真、可读、可编辑的表达。

| 关系 | 用什么 | 必查与退路 |
| --- | --- | --- |
| 比较 | 柱／条强调绝对量与共同基线；点、哑铃、斜率适合成对差异；排名按明确口径 | 柱／条必须含零点；点图截轴须标注；不同口径、缺失值不画成可比 |
| 时间 | 序列用事件轴；日期间距有意义时按真实比例；持续期用甘特；路线图区分已发生与计划 | 流程先后不等于日期；时区、工期未知就不画伪比例 |
| 组成／数量流 | 饼／环用于少量互斥部分与共同整体；堆叠、树图表达构成；瀑布解释可核对的增减；漏斗用于同口径阶段留存 | 先确认分母、单位、互斥、可加性；宽度表示数量须可核算；缺口标"未分配" |
| 分布／统计 | 散点看配对关系；气泡须说明面积映射；直方图按真实分箱宽度；箱线、区间、热力须有可核对的统计定义 | 分布不等于均值；相关不等于因果；缺样本、区间、分箱边界不臆造 |
| 因果／风险 | 因果链、鱼骨、回路、影响图、故障树按已知机制与条件组织，区分观测、已确认路径与假设 | 共现、相关、先后都不证明因果；机制未知就先列事实或假设表 |
| 流程／决策 | 分支让方向、条件、出口可追；泳道交代责任；状态图交代触发与转换 | 分支条件不能互相误读，出口要完整；顺序不是持续时间，也不是因果 |
| 结构／依赖 | 层级树表达归属；系统架构表达组件边界；数据流标方向与载荷；依赖图标前置与被依赖方 | 归属不是依赖，连接不是方向；未知边与基数不编造 |
| 战略／优先级 | 2×2、风险矩阵先写轴、方向、阈值与位置含义；帕累托先核对可加总 | 象限和颜色不是证据；无阈值就别摆精确位置，改用带状态的清单 |
| 一个数字就够 | 单个关键指标、微趋势、原生表格或一句结论 | 数字必须有单位、期间、来源；微趋势不能暗示不存在的精度 |

**绘制**：先确定读者从哪里读到哪里，再安排重心、主次尺度、密度块与连续负空间。以对齐和邻近分组；线、节点、边界、箭头、标记、颜色各有职责。能直标就别放远距离图例；分支标签贴近对应路径。不要强迫元素等大、居中、平均铺开。

**标注**：页题只说证据支持的结论；图题、单位、期间、分母、来源与限定要可见。类别少且读数重要时直标，只在直标足以读数时收起数值轴。程序能筛查数值、单位、期间和部分方向，但不能证明来源、因果、共同分母或设计质量。

## 诊断

症状只是入口。先归入根因类别，**上游优先**——内容与事实、信息架构一变，下游的构图与排版修改可能全部作废。

| 症状 | 根因类别 | 处理 | 不要 |
| --- | --- | --- | --- |
| 不知先看什么、像模板 | 构图与层级 | 明确阅读重点，删去不承担关系的容器，保留功能信息 | 给配角一起加粗加色 |
| 发空、非对称不稳 | 构图与层级 | 检查主角分量、连续负空间、对侧回秤 | 用图标和装饰填满空白 |
| 拥挤、断行难看 | 字体与排版 | 编辑文案、加宽或拆页，按语义改断点 | 缩字号、压行距、用空格硬推 |
| 图一裁就废、叠字难读 | 色彩与图像 | 按落位框重选画幅或移动文字，检查真实字形落点 | 靠居中裁切或浓遮罩碰运气 |
| 读不出数据、翻页疲劳 | 信息架构 | 回到口径、主张与乐谱，调整直标与密度 | 换装饰、随机换版式 |
| 每页都对，整稿不对 | 视觉概念 | 重写洞察句与概念，重定锁定项 | 逐页涂抹风格 |
| 数字与文字打架 | 内容与事实 | 回到口径与来源，标未决 | 用强调掩盖证据缺口 |
| 预览正常，现场发虚 | 渲染环境 | 记录环境、换字体或提高素材 ppi，交目标机复核 | 为迁就替代字体改设计 |

**模板味的信号**（是症状，不是禁令——能说出它在本页承担的职责就可以留）：

| 信号 | 常见根因 | 改法 |
| --- | --- | --- |
| 每页都是"标题＋三栏卡片" | 没按内容关系选组织方式 | 单一论断、对照、流程、同源数据各用不同空间组织 |
| 一条信息一个圆角卡片、卡片套卡片 | 用容器代替对齐与邻近 | 先用间距和对齐分组，容器只在需要承托或区分层面时出现 |
| 图标阵列代替论证 | 没有真实关系 | 写出实体与关系；没有关系就一句话或一个数字 |
| 渐变、发光、玻璃拟态＝"科技感" | 行业词直接映射成风格 | 图像世界与材质由受众和证据推出 |
| 页标题是话题（"市场分析""总结"） | 没有主张 | 改写成证据支持的论断；写不出就是未决 |
| 正文把图表里的数字再念一遍 | 图与文没有分工 | 图承担读数，文字只写结论与限定 |
| 强调色到处都是、标题下都有装饰条 | 强调不按职责稀缺 | 只保留指向结论或行动的那一处 |
| 一切居中、上下对称堆叠 | 回避取舍 | 找出主角，用尺度与连续负空间建立不对称平衡 |
| 无来源的"权威"数字、占位 Logo、假头像 | 为显得完整而补造 | 删除或标未决；示例数据在页面上写明"示例" |
| 无功能的英文装饰标签（OVERVIEW、KEY TAKEAWAYS） | 套模板气质 | 删除；确为导航需要则整稿一致 |
| 结尾只有"谢谢／Q&A" | 没有收束职责 | 收在决定、下一步或要带走的一句话 |

自检顺序：缩略总览像不像同一模板复制 → 每页能否一句话说出主角 → 删掉任一装饰后信息是否受损。

## 复核维度

逐项给 `PASS / BLOCK / NOT VERIFIED`，每项必须写**实际依据**（机器事实、看过的哪一页 PNG、或仅 plan 声明）。没有依据的项记 `NOT VERIFIED`，不算通过。

| 维度 | PASS 需要看到 | 典型 BLOCK |
| --- | --- | --- |
| 1 语义与事实 | 关系、方向、条件、口径、时间与证据真实；相关和假设没被画成因果 | 无证因果、口径混画、数据与文字矛盾 |
| 2 层级与阅读路径 | 主张、重点、限定、来源按预期顺序被读到；并列没被错误拉开 | 一眼先看到的不是主张；配角和主角同重 |
| 3 构图与空间 | 主次比例、重心、连续留白、分组、相邻页节奏服务内容 | 发空或拥挤；重心无回秤；零碎缝隙冒充留白 |
| 4 图形与数据 | 基线、节点、线、箭头、带宽、统计编码各有职责且可回算 | 装饰线暗示不存在的关系；截轴未标；柱子没有零点 |
| 5 排版 | 断行贴合语义，数字单位同组，字号与观看距离匹配，实际字体与计划一致 | 数字与单位拆行、末行孤字、行首标点、替换字体后溢出 |
| 6 色彩 | 类别、状态、证据的编码一致可辨；前景墨阶随明暗场成套切换 | 强调处处有；深浅切换后前景不对；只靠颜色区分关键状态 |
| 7 概念与整稿 | 概念可追溯到洞察，有辨识度，且真正约束了图像、色彩、构图与字体；各页构成完整叙事，高潮与停顿可辨 | 换行业仍成立；概念只在字段里；缩略总览像同一模板复制或像几套稿拼接 |
| 8 效率与交付 | 每个元素说得出职责，删掉任一都有损失；真实渲染无裁切错位替字，可编辑性与环境风险已说明 | 装饰条、重复数字、无关图标、卡片套卡片；未渲染却声称已预览 |

**否决项不可抵消**：语义错误、数据失真、无证因果、关键内容不可读，先修，且不能被其他维度的表现、总分或机器通过率掩盖。第 7、8 项不能由机器回答，必须看图并写出依据。
