# 设计判断

为什么这样做，什么时候不成立。字段见 `build.md`，流程与原则见 `SKILL.md`，诊断与复核见 `review.md`。这里不给模板，只给判断框架。

三条共同点（取自 Vignelli、Scher、Bierut、Jen 等人的方法，不取外观）：**先有可说清的想法；系统让整套作品一致；每个细节都能回答“为什么”。**

## 一、概念

**洞察句**：观众原以为什么 → 证据说明什么 → 差距在哪。“他们以为问题在获客，数据显示在留存”是洞察；“增长遇到瓶颈”不是。

**概念由洞察推出**，可来自尺度、材质、空间、视角或叙事结构。不必是比喻，但要具体到能指导选择。整稿只用一套生成逻辑。

| 生成器 | 触发 | 做法 |
| --- | --- | --- |
| 尺度隐喻 | 内容有强烈的大小、数量落差 | 用一个数字压住另一个，让落差说话 |
| 材质世界 | 主题有可触摸的材质语义 | 可信的材质与光：金属的冷、纸的纤维 |
| 空间视点 | 需要“换个角度看” | 平视切俯瞰，局部拉到系统，视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、停顿、断行重音，版面本身是论据 |

行业、品牌、受众是**约束**，不是答案：决定哪些做法不可行，不决定概念本身。

概念必须落到五件事上，否则只是形容词：**图像世界**（媒介、光、色域、材质）、**明暗与色彩角色**、**空间母题**（重心偏向、留白逻辑）、**字族角色**（谁大声、谁解释）、**跨页节奏**（哪页最重、在哪停顿）。

**编辑取舍与记忆点**（概念落到版面之前先做）：把内容分成三堆——**放大**（支撑主张的那一两样：用尺度、位置、明度推到前景）、**退隐**（必须在场但不该抢戏：灰阶、小字号、边缘、附录）、**删除**（与主张无关的荣誉、功能墙、第二条故事线）。记忆点来自**一处够强的对比**，不是一堆小装饰：尺度对比（200pt 对 72pt）、明度对比（暗场插在浅场里）、密度对比（极密后接极空）、位置对比（唯一一次破网格）。每份稿先选一个主对比，再让其余页为它让路。风格词（极简、高级、科技感、电影感）只是结果描述：先写“让什么压住什么”，再看它是否被叫作极简。

**原创长在哪**：每条原创都能指到内容独有的关系，比如只有这份数据才有的落差、只有这个对象才成立的裁切、两条证据并置才有的读法。指不到，就还是外观差异。

## 二、艺术指导

概念回答“用什么关系”，艺术指导回答“看起来是什么世界”。缺了它，图随便配、色随便调，整稿没有温度。

先定五个参数，整稿照此执行；换页时只允许其中一个变化（通常是景别或光向）。

| 参数 | 要定什么 | 常见错误 |
| --- | --- | --- |
| 光 | 硬或柔、方向、色温（暖约 3200K，冷约 5600K） | 每页光向不同，像拼贴 |
| 视角与景别 | 平视、俯视、微距；全景、中景、特写 | 一页一视角，像素材库 |
| 材质 | 石、纸、金属、织物、液体；表面哑或亮 | 材质与主题无关 |
| 色域 | 主色相范围、饱和上限、能否用纯黑纯白 | 一页鲜艳一页灰 |
| 颗粒与镜头 | 干净数码、细颗粒、浅景深、长焦压缩 | 颗粒通篇叠加当“质感” |

图像世界选一类为主：**记录**（现场、人物、实拍，承认不完美，保留在场感）；**静物**（可控台面，单光源加接触阴影，主体偏置留安静区）；**结构**（抽象、几何、系统，极简、强对比，不冒充真实对象）。

**光影与材质是同一种语言，不是特效**：一份稿一种主光（方向、软硬、色温）、一种材质逻辑（哑或亮、透明或不透明、粗糙或精密），玻璃、金属、石、纸、木、织物都要有可被反射或透过的环境，否则假。原生图形里的投影、发光、玻璃拟态没有光源依据就不用。

**一致性检查**：把整稿的图排在一起看。光向能连成一条线吗？色温是同一个世界吗？主体尺度是否从头到尾在跳？

**摄影指导**把参数落成可拍、可验的镜头单：机位高度与朝向；焦段感（广角的透视，或长焦的压缩）；主光方向与光比（暗部是否保留细节）；背景处理（连续暗场、纸面、渐变）；主体与留白的位置；后期的色域与颗粒。每张图写一句“为什么是这个镜头”；同一系列只许变一个参数。验收看三处：边缘（毛边、伪文字、融化的接缝）、光（高光与投影方向一致）、安静区（文字落点内最亮与最暗之差）。

**图不对时先改简报，不改形容词。**（各类资产的具体语言见 `imagery.md`。）“再高级一点”不是指令；“侧逆光，背景压到近黑，瓶身占画面三分之一”才是。

## 三、叙事

整稿是一部有开头、推进、转折、停顿、高潮、收束的作品，不是页面的集合。

| `role` | 叙事动作 | 判断要点 |
| --- | --- | --- |
| `open` | 建立世界与问题 | 识别度优先，字少，让人想知道后面 |
| `build` | 积累证据，逐层加重 | 同类证据用同一讲法 |
| `turn` | 换视角或结论方向 | 必须伴随尺度、明暗或构图的明显变化 |
| `breathe` / `hold` | 让人消化关键结论 | 更空、更慢、单一焦点；不是凑数的过渡页 |
| `close` | 落到决定、下一步或要带走的一句话 | 求可执行的落点，不求完整收尾 |

弧线按内容选：论证型（主张→证据→反证→结论）、发现型（现状→异常→解释→行动）、提案型（问题→方案→代价→请求）。

**高潮**是最强的一次集中（最大数字、最关键证据、最有力图像）。数量由内容决定，不预设配额：一页都不给，整稿就平；页页都是，就没有高潮。危机叙事前置张力，方案叙事后置释放。

**母题**带来辨识度，不靠每页长得像：一到两个反复出现的装置，如同一条基线位置、同一色带、同一编号体系、同一裁切比例、同一道留白缺口。

**乐谱**（`rhythm`）每页写一句“这页在做什么、有多重”，用动词与分量词。

**整稿检查**（对着缩略总览，只看轮廓与明暗）：能读出开场、推进、转折、收束吗？相邻页的变化有理由吗？最重的一页是内容最重要的一页吗？把标题连起来读，是一段话，还是五个话题？

## 四、空间构成

**锁定与放开**。锁定：字族角色、墨阶与语义色、对齐轴与留白逻辑、图像世界、图形语言。放开：构图、尺度、密度、明暗场、图像占比、有没有主角，由本页职责决定。锁定的东西逐页变化，整稿就散；放开的东西全被锁死，整稿就单调。

**网格是选的，不是给的**。先问内容要什么秩序：多栏对照、表格与图表要稳定的行列（12 栏、模块网格）；一句论断与一个数字适合少栏、大留白（5 栏、8 栏，左边多空两栏）；整幅图、整页色场、巨型数字是在网格之外建立秩序，靠一条贯穿的边、一条基线或一个裁切来站住。同一份稿可以换网格，但每次换要有理由（密度变了、角色变了），而不是为了不重复。破网格的检验：关掉所有装饰，页面的重心与阅读顺序还说得清吗。

**先读内容关系，再安排空间**：

| 内容关系 | 成立的组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 结论与支持信息形成明显的尺度或明度差 | 所有内容同重 |
| 机制、流程 | 路径与间距反映已知顺序 | 箭头暗示未经证实的因果 |
| 对照、并列 | 同一基线、可比尺度；确实等重才并列 | 为造主角偷换权重 |
| 同源数据 | 主张、图形、单位形成一条阅读路径 | 图表缩在角落，正文重念数字 |
| 场景 | 图像承担空间与情绪，文字进入安静区 | 图文互抢，靠浓遮罩掩盖杂乱 |

`composition_rationale` 要说清：读者先看到什么，用什么手段建立层级，次级顺序是什么，放弃了哪个方案。说不出，就回去重读内容。

**比例是骨架**：等分给秩序（对照、流程）；三分或四分给稳定（主体偏一侧，另一侧留呼吸）；黄金位给紧张。5:7 是“字少图大”，7:5 是“图为主、字压边”，只有内容能决定。

**视平线与尺度**：主体重心低于画布一半显得压、稳；高于一半显得轻、待发生。主体占三分之一是陈述，占一半是主张，满幅是宣告。

**纵深靠尺度差、遮挡、明度后退、边缘处理**，不靠阴影堆和伪透视。前景（出血的大字、裁切的主体）、中景（主信息）、背景（场与纹理）各自只做一件事，明度依次后退，且主体位置与文字安静区互不争夺；跨页时让纵深关系的方向保持一致，节奏靠景别与尺度变化。出血表示“世界还在画布外”，内收表示“这是一张图”。

**重心靠回秤**。非对称时，用对侧连续负空间、对齐轴、视线或必要的次级信息拉回来；补一块同重色块是廉价解法。

**留白**要保护焦点、分组、停顿或容纳视线。极空而主角没分量不是克制，是没做完；零碎缝隙冒充留白最常见。先用邻近、对齐、间距分组，再考虑容器。

**版式语法**（先判关系与职责，相邻页重复同一语法须有同轴比较的理由）：网格秩序（多信息，危险是方格墙）、编辑式（故事与观点，危险是装饰压过论证）、非对称（需要张力，危险是失衡）、字体主导（标题即主张，危险是可读性）、图像主导（危险是主体与文字互抢）、数据主导（危险是数据淹没结论）、图解主导（危险是装饰线暗示不存在的关系）、模块化（危险是平均铺满、容器套容器）。

**张力装置**（每页选一个作主手段，别都用）：尺度反差（标题与正文三倍以上）、明暗反转（一页深场插在浅场中）、方向对冲（斜向压过横排）、密度断层（极密后接极空）、切边出血（关键信息别被切掉）、单一破例（整稿守网格，只一页跨轴）。破格要能说出理由。

## 五、信息设计

**先选最小够用的形式**：一个数字 → 一句话 → 表格 → 图 → 图解 → 组合页。精确读数、多列对照、口径各异用表格；看形状、趋势、分布、占比用图；关系比数值重要（流程、结构、依赖）用图解；证据与结论需同时在场才做组合页，并明确主次。

**关系决定图形**，先写清实体、关系、方向、范围，再问：有没有真实时间、可比数值、共同分母、归属、条件与证据？

| 关系 | 用什么 | 必查 |
| --- | --- | --- |
| 比较 | 竖柱比量级；横条比排名与长标签；哑铃、斜率比成对差异 | 柱与条必须从零起；口径不同不画成可比 |
| 时间 | 时间轴；间距有意义时按真实比例；区分已发生与计划 | 流程先后不等于日期 |
| 组成 | 饼或环只用于少量互斥部分；堆叠看构成变化；百分比堆叠看份额迁移 | 分母、单位、可加性；每列合计 100 |
| 分布 | 散点看配对关系；直方图按真实分箱 | 分布不等于均值；相关不等于因果 |
| 因果、风险 | 因果链、影响图，区分观测、已确认路径与假设 | 共现、先后都不证明因果 |
| 流程、决策 | 分支标明条件与出口；泳道交代责任 | 顺序不是持续时间 |
| 结构 | 层级树表达归属；架构图表达边界 | 归属不是依赖；未知边不编造 |
| 优先级 | 2×2、风险矩阵先写轴、方向、阈值 | 象限与颜色不是证据 |

**量级与比率不共轴**。三条路：换算到同一单位；拆成两张共用基线的图；把比率写成一句话。不用双数值轴，两个轴总能让任何两条线“看起来相关”。

**四层分工，不重复表达**：页题（或图题）说发现；图形呈现数据关系；图注说口径（单位、期间、分母、来源）；正文说意义与限定。正文重念图中数字，说明分工失败。

**不夸大**：基线、坐标、比例、排序与比较条件保持真实；不用面积、立体、截轴放大结论；强调色只突出关键发现；多系列必须有颜色之外的区分。

**标注**：页题只说证据支持的结论；图题、单位、期间、分母、来源与限定可见。能直标就别放远距离图例；分支标签贴近路径；不强迫元素等大、居中、平均铺开。

**图表收尾**：柱与面积从零起，截轴必须写明起点；一根数值轴、一根类别轴，网格比底色浅一级；图例只在多系列且无法直标时用；表格用细横线分组，不用斑马纹与竖线，数字右对齐；饼与环不超过五类。

## 六、排版

**角色与层级**：论断、支撑、限定、来源、读数，每块文字先定职责。层级由字号、字重、墨阶、位置共同承担，其中一项够用时不叠加其余。标题写论断，不写话题。数字、单位、期间、正负号是一组，同行同基线。强调用墨色或字号，不靠合成加粗。

**字号阶梯**按观看场景定：

| 场景 | 论断标题 | 正文 | 关键数字 |
| --- | --- | --- | --- |
| 大厅、远距离发布 | 44–64 | 24–28 | 96–160 |
| 会议投影、路演（默认） | 30–44 | 17–22 | 60–120 |
| 屏幕共享、会后深读 | 24–32 | 14–18 | 36–72 |

级差 1.25–1.6 倍，整稿不超过五档；差不够用字重、墨阶或位置，不再加一档。推导：先定正文，乘 1.4–1.6 得标题，数字取标题的 1.6–2.5 倍，注释取正文的 0.7–0.8。

**字体排印的成熟度**：数字、标题、正文要有角色反差，而不是字号反差；衬线用于叙述与品牌气质，黑体用于数据与论证，整稿不超过两个字族；大字收紧、小字放松；标题与数字用 `pad_in: 0` 贴住对齐轴；巨型数字的单位降一档并换色（用 `runs`），让数字成为图形；不用空格推位。

**行长与行距**：投影一行 18–26 个汉字，深读不超过 32；展示行距 1.05–1.15，正文 1.25–1.4。文字距画布边缘不小于 0.5 in。

**断行按语义断**，不按字数均分：断在分句处；不拆数字与单位、期间与数值、专名、年份区间；末行不孤字；行首不放 `，。、）」』】`，行尾不放 `（「『【`（这两条只能在渲染里查）。

**中西混排**：中西文之间全稿统一一种写法：默认不敲空格、依赖字体原生字距；采用单个普通空格（通行排法）也可，但须整稿一致并写进交付说明（`I-SPACE`）；多于一个、全角或不换行空格一律是错（`W-SPACE`）；中文全角标点，西文半角；同行用同一字族的西文部分；表格与竖向对齐的数字用等宽数字；负号用 `−`（U+2212）。

**中文字体体系**：先定角色，再按目标机选字，最后写进 `fonts`。一套稿两个字族：**叙述与论断**用衬线，**数据与读数**用黑体；正文跟黑体。

| 角色 | 取向 | 字重 |
| --- | --- | --- |
| 论断标题 | 衬线，字面有笔画对比，大字才显出气质 | Bold；整稿一种 |
| 关键数字 | 黑体，拉丁数字在中文衬线里常偏细小，读数需要稳定字宽 | Bold |
| 正文、图表标注 | 黑体；投影不用 Light | Regular，强调用墨色或 Bold |
| 注释、来源 | 同正文字族，降字号与墨阶 | Regular |

| 目标环境 | 衬线 | 黑体 | 说明 |
| --- | --- | --- | --- |
| 自有或可控的放映机 | 思源宋体（Noto Serif CJK SC） | 思源黑体（Noto Sans CJK SC） | 字重齐全，跨系统同形；须在目标机安装（编译器不嵌入） |
| Windows 默认环境 | 宋体系统字体（字面偏瘦，只适合中大字号） | 微软雅黑 | 宽度与断行以实机为准 |
| macOS 默认环境 | 宋体-简 | 苹方-简 | 苹方只在苹果系统 |
| 不知道在哪放 | 选黑体单字族，以字重与字号做层级 | | 衬线缺失时替换差异最大 |

规则：字体名只在观看机器上存在才生效，缺失时 PowerPoint 静默替换，宽度与断行都变；声明字体的字重必须真实存在，否则是合成加粗，笔画发糊；中文没有真斜体，强调用字重、墨色或尺度，不用倾斜；大字（≥ 48pt）可 `letter_spacing_pt` 收 0 到 −1，注释里的英文大写可放松 +1；渲染中检出替换，结论只能是 `PARTIAL`。

## 七、色彩

色彩是关系系统：先有世界，再有颜色。不要先套色板再给它找理由。

**从事实推导**。依次问：内容里有什么真实颜色（产品、品牌、材质、图像）？使用环境是什么（投影、屏幕、印刷、明亮或暗室）？概念要求什么温度与明度？答案共同限定色域。品牌色是硬性值，可调位置与面积，不偷偷调浅。

**色彩方向（整稿先写这一段，再进页面）**：用三到五句话落成 `brief.art.gamut`（色相范围、饱和上限、明度骨架、纯黑纯白能不能用）与根 `palette`（只放数据色序列）。内容须覆盖：①品牌或事实色（硬值）；②主导场与它的温度；③唯一主强调色及其语义；④中性的色温（跟着图与纸走）；⑤图片色域如何并入——取图中最暗与最亮处的色相，把中性色、强调色向它靠，必要时 `duotone`/选图而非整页滤镜。方向要能否掉东西（“不用冷灰、不用荧光蓝”），否则只是色板。品牌高饱和、精密中性、暗场戏剧、暖纸编辑，各自成立；最终由内容、概念与环境决定，不是默认色板。

**四种职责，不混用**：

| 职责 | 做什么 | 边界 |
| --- | --- | --- |
| 环境（底与大面积场） | 决定整体基调与前景墨阶 | 中性或同色相深浅；一个场只有一个温度主导 |
| 结构（墨阶、线、图表的非重点） | 承担层级主力，可无彩色 | 用明度分层，不靠色相换来“丰富” |
| 强调 | 只指向结论或行动 | 稀缺：整稿一个主强调色，面积通常不过 5%，且语义跨页一致 |
| 状态与数据 | 识别、分类、比较 | 互斥可辨；重点色突出一个类别，其余退到中性但仍可读 |

**中性色也要分清**：环境中性（纸白、墨黑，带整稿的色温）、结构中性（灰阶）、文字中性（对比达标的墨阶）、真实材质色（图片里的木、金属、肤色，不被统一滤镜篡改）。图是暖纸，版面就不能用冷灰。

**明度先于色相**。先定背景、主墨、次墨的明度骨架并算最坏对比，再决定色相。同一色相的深浅也能成熟（单色系统不靠频繁换色制造丰富）；深底不是浅底反相，要成套换前景（墨阶、图表系列、页码）。

**深浅切换要有叙事依据**（转折、停顿、高潮），不为“变化”而切。每次切换都问：这一页在整稿里承担什么？

**图表里的颜色各司其职**：语义色（谁是谁）、结构色（轴、网格、图例）、标注色（直标）、承载面（它们真正落在的底）是四件事。标注色跟着**落点**走：落在底上用结构墨，落在色块里按色块取深/白/黑墨，线与点的标注在读得清时沿用系列色以保持归属；永远先保可读，再谈颜色一致。图放在面板上，一切按面板算，不按页面。

**数据色**：分类色靠明度与色相共同区分；顺序色同色相单调推进；发散色围绕有意义的中心；多系列必须有颜色之外的区分方式（直标、线型、标记、位置）。编译器与核验器按灰度明度差（CIE L*）对**全部系列两两比较**，提示 `W-GRAY`／`V-GRAY`；默认色板已按明度错开，自定义色板要自己守住。

**自检三件事**：① 灰度：整稿转灰度，层级、类别、状态是否仍可辨？② 缩略图：色彩是否连续，变化是否有依据？③ 投影：浅场正文不低于 4.5:1，24pt 以上大字不低于 3:1，且留出投影衰减的余量。这是底线，不是好看的标准。

**高级感不等于低饱和**。精密中性、高饱和品牌场、深色戏剧场、暖色编辑场都可以成熟；用强色时，强色只在主视觉与强调处出现，面积受控，层级由明度承担。
