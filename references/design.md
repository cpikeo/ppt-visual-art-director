# 设计判断

为什么这样做，什么时候不成立。字段见 `build.md`，流程与原则见 `SKILL.md`。这里不给模板，只给判断框架。

## 一、概念

**洞察句**：观众原以为什么 → 证据说明什么 → 差距在哪。“他们以为问题在获客，数据显示在留存”是洞察；“增长遇到瓶颈”不是。

**概念由洞察推出**，可来自尺度、材质、空间、视角或叙事结构。不必是比喻，但要具体到能指导选择。整稿只用一套生成逻辑。

| 生成器 | 触发 | 做法 |
| --- | --- | --- |
| 尺度隐喻 | 内容有强烈的大小、数量落差 | 用一个数字压住另一个，让落差说话 |
| 材质世界 | 主题有可触摸的材质语义 | 可信的材质与光：金属的冷、纸的纤维 |
| 空间视点 | 需要“换个角度看” | 平视切俯瞰，局部拉到系统，视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、停顿、断行重音，版面本身是论据 |

行业、品牌、受众是**约束**，不是答案：决定哪些做法不可行，不决定概念本身。

概念必须落到五件事上，否则只是形容词：**图像世界**（媒介、光、色域、材质）、**明暗与色彩角色**、**空间母题**（重心偏向、留白逻辑）、**字族角色**（谁大声、谁解释）、**跨页节奏**（哪页最重、在哪停顿）。

**原创长在哪**：每条原创都能指到内容独有的关系，比如只有这份数据才有的落差、只有这个对象才成立的裁切、两条证据并置才有的读法。指不到，就还是外观差异。

## 二、艺术指导

概念回答“用什么关系”，艺术指导回答“看起来是什么世界”。缺了它，图随便配、色随便调，整稿没有温度。

先定五个参数，整稿照此执行；换页时只允许其中一个变化（通常是景别或光向）。

| 参数 | 要定什么 | 常见错误 |
| --- | --- | --- |
| 光 | 硬或柔、方向、色温（暖约 3200K，冷约 5600K） | 每页光向不同，像拼贴 |
| 视角与景别 | 平视、俯视、微距；全景、中景、特写 | 一页一视角，像素材库 |
| 材质 | 石、纸、金属、织物、液体；表面哑或亮 | 材质与主题无关 |
| 色域 | 主色相范围、饱和上限、能否用纯黑纯白 | 一页鲜艳一页灰 |
| 颗粒与镜头 | 干净数码、细颗粒、浅景深、长焦压缩 | 颗粒通篇叠加当“质感” |

图像世界选一类为主：**记录**（现场、人物、实拍，承认不完美，保留在场感）；**静物**（可控台面，单光源加接触阴影，主体偏置留安静区）；**结构**（抽象、几何、系统，极简、强对比，不冒充真实对象）。

**一致性检查**：把整稿的图排在一起看。光向能连成一条线吗？色温是同一个世界吗？主体尺度是否从头到尾在跳？

**图不对时先改简报，不改形容词。**“再高级一点”不是指令；“侧逆光，背景压到近黑，瓶身占画面三分之一”才是。

## 三、叙事

整稿是一部有开头、推进、转折、停顿、高潮、收束的作品，不是页面的集合。

| `role` | 叙事动作 | 判断要点 |
| --- | --- | --- |
| `open` | 建立世界与问题 | 识别度优先，字少，让人想知道后面 |
| `build` | 积累证据，逐层加重 | 同类证据用同一讲法 |
| `turn` | 换视角或结论方向 | 必须伴随尺度、明暗或构图的明显变化 |
| `breathe` / `hold` | 让人消化关键结论 | 更空、更慢、单一焦点；不是凑数的过渡页 |
| `close` | 落到决定、下一步或要带走的一句话 | 求可执行的落点，不求完整收尾 |

弧线按内容选：论证型（主张→证据→反证→结论）、发现型（现状→异常→解释→行动）、提案型（问题→方案→代价→请求）。

**高潮**是最强的一次集中（最大数字、最关键证据、最有力图像）。数量由内容决定，不预设配额：一页都不给，整稿就平；页页都是，就没有高潮。危机叙事前置张力，方案叙事后置释放。

**母题**带来辨识度，不靠每页长得像：一到两个反复出现的装置，如同一条基线位置、同一色带、同一编号体系、同一裁切比例、同一道留白缺口。

**乐谱**（`rhythm`）每页写一句“这页在做什么、有多重”，用动词与分量词。

**整稿检查**（对着缩略总览，只看轮廓与明暗）：能读出开场、推进、转折、收束吗？相邻页的变化有理由吗？最重的一页是内容最重要的一页吗？把标题连起来读，是一段话，还是五个话题？

## 四、空间构成

**锁定与放开**。锁定：字族角色、墨阶与语义色、对齐轴与留白逻辑、图像世界、图形语言。放开：构图、尺度、密度、明暗场、图像占比、有没有主角，由本页职责决定。锁定的东西逐页变化，整稿就散；放开的东西全被锁死，整稿就单调。

**先读内容关系，再安排空间**：

| 内容关系 | 成立的组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 结论与支持信息形成明显的尺度或明度差 | 所有内容同重 |
| 机制、流程 | 路径与间距反映已知顺序 | 箭头暗示未经证实的因果 |
| 对照、并列 | 同一基线、可比尺度；确实等重才并列 | 为造主角偷换权重 |
| 同源数据 | 主张、图形、单位形成一条阅读路径 | 图表缩在角落，正文重念数字 |
| 场景 | 图像承担空间与情绪，文字进入安静区 | 图文互抢，靠浓遮罩掩盖杂乱 |

`composition_rationale` 要说清：读者先看到什么，用什么手段建立层级，次级顺序是什么，放弃了哪个方案。说不出，就回去重读内容。

**比例是骨架**：等分给秩序（对照、流程）；三分或四分给稳定（主体偏一侧，另一侧留呼吸）；黄金位给紧张。5:7 是“字少图大”，7:5 是“图为主、字压边”，只有内容能决定。

**视平线与尺度**：主体重心低于画布一半显得压、稳；高于一半显得轻、待发生。主体占三分之一是陈述，占一半是主张，满幅是宣告。

**纵深靠尺度差、遮挡、明度后退、边缘处理**，不靠阴影堆和伪透视。出血表示“世界还在画布外”，内收表示“这是一张图”。

**重心靠回秤**。非对称时，用对侧连续负空间、对齐轴、视线或必要的次级信息拉回来；补一块同重色块是廉价解法。

**留白**要保护焦点、分组、停顿或容纳视线。极空而主角没分量不是克制，是没做完；零碎缝隙冒充留白最常见。先用邻近、对齐、间距分组，再考虑容器。

**版式语法**（先判关系与职责，相邻页重复同一语法须有同轴比较的理由）：网格秩序（多信息，危险是方格墙）、编辑式（故事与观点，危险是装饰压过论证）、非对称（需要张力，危险是失衡）、字体主导（标题即主张，危险是可读性）、图像主导（危险是主体与文字互抢）、数据主导（危险是数据淹没结论）、图解主导（危险是装饰线暗示不存在的关系）、模块化（危险是平均铺满、容器套容器）。

**张力装置**（每页选一个作主手段，别都用）：尺度反差（标题与正文三倍以上）、明暗反转（一页深场插在浅场中）、方向对冲（斜向压过横排）、密度断层（极密后接极空）、切边出血（关键信息别被切掉）、单一破例（整稿守网格，只一页跨轴）。破格要能说出理由。

## 五、信息设计

**先选最小够用的形式**：一个数字 → 一句话 → 表格 → 图 → 图解 → 组合页。精确读数、多列对照、口径各异用表格；看形状、趋势、分布、占比用图；关系比数值重要（流程、结构、依赖）用图解；证据与结论需同时在场才做组合页，并明确主次。

**关系决定图形**，先写清实体、关系、方向、范围，再问：有没有真实时间、可比数值、共同分母、归属、条件与证据？

| 关系 | 用什么 | 必查 |
| --- | --- | --- |
| 比较 | 竖柱比量级；横条比排名与长标签；哑铃、斜率比成对差异 | 柱与条必须从零起；口径不同不画成可比 |
| 时间 | 时间轴；间距有意义时按真实比例；区分已发生与计划 | 流程先后不等于日期 |
| 组成 | 饼或环只用于少量互斥部分；堆叠看构成变化；百分比堆叠看份额迁移 | 分母、单位、可加性；每列合计 100 |
| 分布 | 散点看配对关系；直方图按真实分箱 | 分布不等于均值；相关不等于因果 |
| 因果、风险 | 因果链、影响图，区分观测、已确认路径与假设 | 共现、先后都不证明因果 |
| 流程、决策 | 分支标明条件与出口；泳道交代责任 | 顺序不是持续时间 |
| 结构 | 层级树表达归属；架构图表达边界 | 归属不是依赖；未知边不编造 |
| 优先级 | 2×2、风险矩阵先写轴、方向、阈值 | 象限与颜色不是证据 |

**量级与比率不共轴**。三条路：换算到同一单位；拆成两张共用基线的图；把比率写成一句话。不用双数值轴，两个轴总能让任何两条线“看起来相关”。

**标注**：页题只说证据支持的结论；图题、单位、期间、分母、来源与限定可见。能直标就别放远距离图例；分支标签贴近路径；不强迫元素等大、居中、平均铺开。

**图表收尾**：柱与面积从零起，截轴必须写明起点；一根数值轴、一根类别轴，网格比底色浅一级；图例只在多系列且无法直标时用；表格用细横线分组，不用斑马纹与竖线，数字右对齐；饼与环不超过五类。

## 六、排版

**角色与层级**：论断、支撑、限定、来源、读数，每块文字先定职责。层级由字号、字重、墨阶、位置共同承担，其中一项够用时不叠加其余。标题写论断，不写话题。数字、单位、期间、正负号是一组，同行同基线。强调用墨色或字号，不靠合成加粗。

**字号阶梯**按观看场景定：

| 场景 | 论断标题 | 正文 | 关键数字 |
| --- | --- | --- | --- |
| 大厅、远距离发布 | 44–64 | 24–28 | 96–160 |
| 会议投影、路演（默认） | 30–44 | 17–22 | 60–120 |
| 屏幕共享、会后深读 | 24–32 | 14–18 | 36–72 |

级差 1.25–1.6 倍，整稿不超过五档；差不够用字重、墨阶或位置，不再加一档。推导：先定正文，乘 1.4–1.6 得标题，数字取标题的 1.6–2.5 倍，注释取正文的 0.7–0.8。

**行长与行距**：投影一行 18–26 个汉字，深读不超过 32；展示行距 1.05–1.15，正文 1.25–1.4。文字距画布边缘不小于 0.5 in。

**断行按语义断**，不按字数均分：断在分句处；不拆数字与单位、期间与数值、专名、年份区间；末行不孤字；行首不放 `，。、）」』】`，行尾不放 `（「『【`（这两条只能在渲染里查）。

**中西混排**：中西文之间留四分之一到二分之一字宽，或依赖字体原生字距，整稿一致；中文全角标点，西文半角；同行用同一字族的西文部分；表格与竖向对齐的数字用等宽数字；负号用 `−`（U+2212）。

**字族与可用性**：按职责选，展示（标题、数字）、阅读（正文）、信息（注释）。字体名只在观看机器上存在才生效，缺失时 PowerPoint 静默替换，宽度与断行都变。微软雅黑不要假定 macOS 或 Linux 有；苹方只在苹果系统；思源黑体、Noto Sans CJK 需目标机安装。要多平台放映，选目标机实测可用的字体并写进 `fonts`。编译器不嵌入字体，渲染中检出替换即结论只能是 `PARTIAL`。

## 七、色彩

**先定职责，再定颜色**：底色场（决定前景墨阶）、中性墨阶（层级主力，可无彩色）、品牌色（硬性值不擅改，可改位置与面积）、强调色（指向结论或行动，按职责稀缺）、状态色（跨页语义一致）、数据色。品牌色在底上不可读时，保留品牌值，换角色或换底，不偷偷调浅。

**五步建色**：① 明度骨架：先定底、主墨、次墨三层，算最坏对比；② 色相策略：单色、邻近、互补、三角，整稿选一种为主；③ 面积分配：大面积给中性或深场，强调色不超过约 5%；④ 冷暖对位：一个场只有一个温度主导；⑤ 材质联动：图是暖纸，版面不能用冷灰。

**明度先于色相**。深底也要有前景层级，不是把浅底颜色反相。叠图上的文字看字形实际落点的最不利背景。

**深浅切换要有叙事依据**，并成套换前景：浅场墨阶约 `#111827 / #374151 / #6B7280`，深场约 `#F3F4F6 / #D1D5DB / #9CA3AF`；图表系列换成深底可辨的明度。为“变化”而切场，是最常见的假深度。

**数据色**：分类互斥可辨，不只靠红绿区分状态；顺序色同一色相单调推进；发散色围绕有意义的中心；重点色强调一个类别，其余退到中性但仍可读。

可用起点（对红绿色盲较稳健）：分类 `#2F5597 #C55A11 #2E7D5B #6A4C93 #B08505 #1F9DAA`；冷顺序 `#F2F4F7 → #9AA7B8 → #4B5B70 → #1B2735`；暖顺序 `#FBF3E7 → #E6B97A → #B5651D → #5C2E0E`；状态 `#1E7A46` 增长、`#B58500` 注意、`#B23A3A` 风险。

**灰度自检**：整稿转灰度，类别与状态还能按明度区分吗？不能就补线型、标记或直接标签。

**高级感不等于低饱和**。精密中性、高饱和品牌场、双互补撞色、深色戏剧场、暖色编辑场都可以成熟。用强色时：强色只在主视觉与强调处出现，用明度而非色相承担层级，面积受控，跨页语义一致。

**可读性下限**：正文对比不低于 4.5:1，24pt 以上大字不低于 3:1。这是底线，不是好看的标准；达标不等于好看，不好看也不等于不可读。

## 八、图像

**先选路线**：真实素材（产品、人物、现场、可核查证据，核实来源与权利）；原生图形（数值、结构、流程本身即内容，只画已知关系）；生成图（概念、氛围、理想场景，登记生成记录，不能证明真实对象或数据）；纯排版（图片没有独特职责时，不假装完整）。

**先问职责**：它承担证据、结构、语境、情绪还是质感？删掉会损失什么？答不出就不用图。

**简报**（缺一条就别开提示词）：视觉意图（服务哪个主张）；主体与景别（结构、机位、朝向）；裁切与文字安静区（叠字区须连续、低纹理、低对比；不叠字写 `none`）；淘汰条件（可观察的否决项，如“瓶身接缝不可辨即淘汰”）。“显得高端”不是简报。

**提示词顺序**：用途与主体 → 构图与落点 → 光 → 材质 → 色与明度 → 环境 → 风格 → 少量负向排除。好的写法是“主体是一只无标签的厚玻璃瓶，琥珀液体与深色金属盖结构完整；瓶身在右侧三分之一，左侧留连续暗区给白字；右上柔光形成边缘高光，瓶底有接触阴影；不出现任何文字”。一条“主体加落字区加光向”胜过十句“高级、电影感”。

**画幅与裁切**：提示词画幅与最终版面一致。`crop_focus` 只是裁窗中心，每次换裁切都要重看主体、朝向、安静区与有效分辨率（低于 72 ppi 投影会发虚）。

**压进整稿色域**，按侵入程度：选（只留与 `art` 同族的图，宁缺勿滥）→ 压（`duotone` 替换色相，不改结构）→ 收（`alpha` 或渐变蒙版降权）。不用双色调掩盖结构错误的图。

**三级检查**：原图（结构、透视、材质可信吗，有伪文字与错误部件吗）→ 最终裁切（主体残缺吗，文字区还在吗）→ 整页与相邻页（主次成立吗，光色是否同族）。生成失败先定位根因，不靠反复抽图碰运气。

**真实性边界**：生成图的伪文字、假界面、假数据不能当真实信息；精确文字用原生文字层。照片中的品牌、水印可能与证据有关，不为统一色调擅自抹除。权利未确认写 `pending`，不伪造授权。

## 九、诊断

症状是入口，按根因归类，**上游优先**：内容与事实、信息架构一变，下游修改可能全部作废。

| 症状 | 根因 | 处理 | 不要 |
| --- | --- | --- | --- |
| 数字与文字打架 | 内容与事实 | 回到口径与来源，标未决 | 用强调掩盖缺口 |
| 无来源的“权威”数字、占位 Logo | 为显得完整而补造 | 删除或标未决，示例写明“示例” | 把生成图当证据 |
| 每页都对，整稿不对 | 视觉概念 | 重写洞察与概念，重定锁定项 | 逐页涂抹风格 |
| 图干净，整稿没气质 | 艺术指导 | 重定五参数，统一光与色温 | 换更多图、加滤镜 |
| 图好看但读不懂 | 信息设计 | 换更简单的形式，删到必要节点 | 加图例、箭头、说明 |
| 不知先看什么，像模板 | 构图与层级 | 明确阅读重点，删不承担关系的容器 | 给配角一起加粗加色 |
| 拥挤，断行难看 | 排版 | 改文案、加宽或拆页，按语义改断点 | 缩字号、压行距、空格硬推 |
| 同页深浅底，前景对不上 | 色彩 | 成套换前景与图表编码，或不切 | 只换底色 |
| 预览正常，目标机发虚 | 渲染环境 | 记录环境，换字或提高素材分辨率，交目标机复核 | 为替代字体改设计 |
| 标题加三栏卡片，每页一样 | 没按内容关系选组织 | 按关系换语法 | 同一骨架套所有页 |
| 卡片套卡片，图标阵列代替论证 | 用容器代替对齐与邻近 | 先用间距分组；没有关系就一句话或一个数字 | 用卡片制造层级 |
| 渐变、发光即“科技感” | 行业词直接映射风格 | 由受众与证据推出图像与材质 | 拿风格词当概念 |
| 页题是话题（“市场分析”） | 没有主张 | 改写成论断，写不出就是未决 | 用栏目名占位 |
| 正文重念图表数字 | 图文没分工 | 图承担读数，文字写结论与限定 | 让文字替图说话 |
| 结尾只有“谢谢／Q&A” | 没有收束职责 | 收在决定或下一步 | 用致谢代替结论 |

自检顺序：缩略总览像不像同一模板复制；每页能否一句话说出主角；删掉任一装饰后信息是否受损。

## 十、复核维度

逐项给 `PASS／BLOCK／NOT VERIFIED`，每项写**实际依据**：机器事实、看过的 PNG 页码，或仅 plan 声明。没有依据的记 `NOT VERIFIED`。

| 维度 | PASS 需要看到 | 典型 BLOCK |
| --- | --- | --- |
| 1 语义与事实 | 关系、条件、口径、时间、证据真实；假设没被画成因果 | 无证因果、口径混画 |
| 2 层级与阅读路径 | 主张、重点、限定、来源按预期被读到 | 一眼先看到的不是主张 |
| 3 构图与空间 | 主次、重心、留白、分组、节奏服务内容 | 发空或拥挤，重心无回秤 |
| 4 图形与数据 | 基线、节点、线、统计编码各有职责且可回算 | 截轴未标，柱子不从零起 |
| 5 排版 | 断行贴合语义，数字单位同组，实际字体与计划一致 | 数字与单位拆行，末行孤字，替换字体后溢出 |
| 6 色彩 | 编码一致可辨，深浅切换后前景成套 | 只靠颜色区分关键状态 |
| 7 概念与整稿 | 概念可追溯到洞察，真正约束了图像、色彩、构图；高潮与停顿可辨 | 换行业仍成立，概念只在字段里 |
| 8 效率与交付 | 每个元素职责清楚；渲染无错位；环境风险已说明 | 装饰条、重复数字；未渲染却声称已预览 |

**否决项不可抵消**：语义错误、数据失真、无证因果、关键内容不可读，先修，不能被其他维度或总分掩盖。第 7、8 项机器无法回答，必须看图并写依据。

**机器证据归口**，别跨维引用。`V-TEXT-RENDER` 只证明文字与 plan 一致、渲染没掉字，不证明内容为真。

| 维度 | 机器事实来源 |
| --- | --- |
| 2 | `W-MONOTONY` `W-CLAIM` `W-EMPTY`（报形态，读不读得到主张要看图） |
| 3 | `V-GEOM` `V-CLIP` `V-OVERFLOW` `E-OVERLAP` `V-BLANK` |
| 4 | `V-CHART` `E-CHART` `W-CHART` `W-NOTE` `W-PPI` |
| 5 | `V-TEXT` `V-TEXT-RENDER` `V-RUNS` `V-FONT` `V-PUNCT` `V-ORPHAN` `W-FIT` |
| 6 | `V-STYLE` `V-CONTRAST` `W-CONTRAST` `W-CROP` |
| 8 | `V-FORMAT` `V-PARTS` `status` `W-IMG-REUSE` `I-OPEN` `E-PRESERVE` |
| 1、7 | 无。brief 字段填满不等于概念成立，也不等于事实为真 |

`PARTIAL` 意味着依赖渲染的第 2、3、5、6 维没有依据，或声明字体未参与渲染。此时只能写 `NOT VERIFIED`，不能因为对象核对通过就记 `PASS`。


## 十一、国际一线审美基准（成熟与克制）

高质量演示文稿的标志不是元素数量或装饰复杂度，而是**每一平方英寸都有明确理由**：

1. **减法优先**：能用对齐轴与留白分清的组，不加框线；能用字号与墨阶拉开的层级，不加底色块；能用一句话说清的结论，不硬塞三栏图标。
2. **母题克制**：全稿只保留 1–2 个结构母题（如固定的顶部细基线、左下角统一编号体系或 5:7 黄金裁切窗），让观众在缩略图尺度就能认出这是一套作品。
3. **破格必有据**：当某页选择全黑反转、超大尺度数字或跨轴出血时，必须能指明它在整稿叙事弧线中的功能（`turn` 或 `hold`），而非为了“不单调”。
4. **图表即论证**：图题直接写结论，数据系列用“主角高饱和 + 配角中性灰”建立视线焦点，去掉多余网格线与重复单位说明。
