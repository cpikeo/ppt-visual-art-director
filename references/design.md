# 设计判断与手艺

判断的依据、成立条件与失效信号。坐标与字段见 `build.md`，原则与流程见 `SKILL.md`。这里不给模板墙；给的是"为什么"和"什么时候不成立"。

## 概念

**概念是一句话，不是形容词。**它必须回答：从哪条洞察出发，用什么视觉关系让这条洞察被看见，并因此否决什么。

### 从洞察到概念

1. **写洞察句。** 观众原本怎么想、证据说明什么、差距在哪。"他们以为问题在获客，数据显示问题在留存"是洞察；"增长遇到瓶颈"不是。
2. **由洞察推概念。** 概念可来自尺度对比、材质、空间关系、观看视角或叙事结构。不必是比喻，但必须具体到能指导选择。
3. **转成约束。** 概念要能落到五件事上，并能否决具体选择：图像世界（媒介、光、色域、材质）、明暗与色彩角色、空间母题（重心偏向、留白逻辑、满还是空）、字族角色（谁大声、谁小声、谁解释）、跨页节奏（哪页最重、在哪停顿）。

### 概念生成器（洞察句写不出来时用）

| 生成器 | 触发条件 | 长什么样 |
| --- | --- | --- |
| 尺度隐喻 | 内容本身有强烈的大小或数量对比 | 用一个数字压住另一个数字，让落差本身说话 |
| 材质世界 | 主题有可被触摸的材质语义 | 建立可信的材质与光：金属的冷、纸的纤维、食物的湿 |
| 空间视点 | 需要"换个角度看" | 从平视切到俯瞰、从局部拉到系统，让视角反转承担论点 |
| 编辑装置 | 论证靠节奏与证据推进 | 连续基线、留白停顿、断行重音——版面本身就是论据 |
| 字体姿态 | 标题本身就是论点 | 主张与反主张在同版用不同字重对冲 |

选一种为主，整稿只用一套逻辑。混用两套等于没有概念。

行业、品牌调性、受众习惯是**约束输入**，不是答案：它们决定哪些做法不可行，不决定概念本身。

### 原创性

原创不是外观差异。换一套配色、换一种字体、加圆角、换图标、换背景图、把卡片改成无边框——改的都是表皮，关系没变。

原创来自内容独有的关系，通常出现在这几处：只有这份数据才有的尺度落差、只有这个对象才成立的裁切、把两条证据并置才出现的读法、只有这个受众才需要的顺序。

两个检验：

- **换稿测试**：把行业、品牌、主题都换掉，概念还成立吗？成立，就退回洞察重写。
- **否决测试**：这个概念能不能否掉一个你本来很想做的漂亮东西？不能，它没有约束力。

**风格化的信号**：每页同一骨架、标题下一条细线、全大写英文小标签、满幅图配居中标题、图标阵列代替论证、一处强调色到处用。它们不是禁令，是默认惯性的痕迹——留在页面上就要说得出它在本页承担的职责。编译器的 `W-*` 信号只指出位置，判断仍在你。

## 艺术指导

概念回答"用什么关系"，艺术指导回答"看起来是什么世界"。缺了这一步，页面会停在版式层面：图随便配、色随便调，整稿没有温度。

### 先定五参数

写下五个值，整稿照此执行。换页时只允许其中一个变化（通常是景别或光向），不要同时换材质与色温。

| 参数 | 要定什么 | 常见错误 |
| --- | --- | --- |
| 光 | 硬光／柔光、方向、色温（暖 3200K ／中性 ／冷 5600K） | 每页光向不同，像拼贴 |
| 视角与景别 | 平视／俯视／微距；全景／中景／特写 | 一页一个视角，读起来像素材库 |
| 材质 | 石、纸、金属、织物、液体、皮肤；表面是哑还是亮 | 材质与主题无关，只是"好看" |
| 色域 | 主色相范围、饱和度上限、是否允许纯黑纯白 | 一页鲜艳一页灰，没有统一世界 |
| 颗粒与镜头 | 干净数码／细颗粒／浅景深／长焦压缩 | 颗粒被当成"质感"通篇叠加 |

### 三种图像世界

| 世界 | 适合 | 做法 |
| --- | --- | --- |
| 记录 | 需要"真的发生过"：现场、人物、产品实拍 | 承认不完美：环境杂、光不均；裁切保留在场感 |
| 静物 | 可控台面，强调材质与工艺 | 单光源＋接触阴影＋明确背景；主体偏置留安静区 |
| 结构 | 抽象、几何、系统、材质宏观 | 极简构图、强对比、局部放大；不冒充真实对象 |

### 一致性

把整稿的图排在一起看：光向能连成一条线吗？色温是同一个世界吗？主体尺度是否从头到尾在跳？三问有一问答不上，就不是一套稿。

**图不对时先改简报，不要改形容词。**"再高级一点"不是指令；"换成侧逆光、背景压到近黑、瓶身占画面 1/3"才是。

## 叙事

把整稿当成一部有开头、推进、转折、停顿、高潮、收束的作品，而不是独立页面的集合。

| `role` | 叙事动作 | 常见判断 |
| --- | --- | --- |
| `open` | 建立世界与问题 | 识别度优先；少字、强第一印象；让人想知道后面是什么 |
| `build` | 积累证据，逐层加重 | 关系决定语法；同类证据用同一逻辑，避免每页换讲法 |
| `turn` | 换视角或换结论方向 | 通常伴随尺度、明暗或构图的明显变化；没有变化就没有转折 |
| `breathe` / `hold` | 让人消化关键结论 | 更空、更慢、单一焦点；不是凑数的过渡页 |
| `close` | 落到决定、下一步或要带走的一句话 | 不求完整收尾，求一个可执行的落点 |

### 三种弧线

| 弧线 | 结构 | 适合 |
| --- | --- | --- |
| 论证型 | 主张 → 证据 → 反证 → 结论 | 汇报、评审、投资判断 |
| 发现型 | 现状 → 异常 → 解释 → 行动 | 复盘、诊断、事故分析 |
| 提案型 | 问题 → 方案 → 代价 → 请求 | 方案提案、立项、融资 |

弧线决定哪一页必须是高潮。**高潮**是最强的一次集中：最大的数字、最关键的证据、最有力的图像。数量由内容规模与决策节点决定，不预设配额；一页都不给，整稿就平；页页都是高潮，就没有高潮。

### 母题与复现

辨识度来自少量被反复使用的装置，不是每页长得像。选一到两个，不要四个都用：同一条基线位置、同一条色带或色块位置、同一套编号或标记、同一裁切比例、同一道斜切或留白缺口。

**乐谱**（`rhythm`）按页写一句"这页在做什么、有多重"，不要写形容词。危机叙事需要前置张力，方案叙事需要后置释放。

### 整稿检查（对着缩略总览）

1. 只看轮廓与明暗，能读出开场—推进—转折—收束吗？
2. 相邻页的变化有叙事理由吗？没理由的变化是噪声；没有变化的同构图，若用于同轴比较则成立。
3. 锁定的东西逐页稳定吗？
4. 最重的那一页，确实是内容最重要的一页吗？
5. 把每页标题连起来读，是一段连贯的话，还是五个话题？

## 视觉系统

识别来自少数被锁定的逻辑，而不是每页长得像。

- **锁定**：字族角色与字重分工、墨阶与语义色、主要对齐轴与留白逻辑、图像世界（媒介、光、色域、材质）、图形语言（线、点、块的统一用法）。
- **放开**：构图、尺度、密度、明暗场、图像占比、有没有主角——由本页的叙事职责决定。

锁定的东西逐页变化，整稿就散；放开的东西也被锁死，整稿就单调。

## 构图

### 先读内容关系，再安排空间

| 内容关系 | 成立的空间组织 | 失败信号 |
| --- | --- | --- |
| 单一论断 | 结论与支持信息形成明显的尺度、位置或明度差 | 所有内容同重；装饰抢焦点 |
| 机制／流程 | 路径与间距反映已知的顺序与关系 | 图标阵列或箭头暗示未经证实的因果 |
| 对照／并列 | 同一基线、可比尺度；确实等重时才并列 | 为造一个主角偷换权重 |
| 同源数据 | 主张、图形、单位形成一条阅读路径 | 图表缩在角落，正文把数字再念一遍 |
| 场景 | 图像承担空间或情绪，文字进入真实安静区 | 图像与标题互抢，或用浓遮罩掩盖杂乱 |

`composition_rationale` 要说得清：读者先看到什么、用什么手段建立层级、次级阅读顺序是什么、放弃了哪个方案。说不出来，就回去重读内容，别靠增加零件。

### 七个张力装置

不要每页都用，也不要一页都不用。选一个作为本页主要手段，其余退到次要。

| 装置 | 怎么用 | 失效 |
| --- | --- | --- |
| 尺度反差 | 主标题与正文拉到 3 倍以上，让大小本身承担层级 | 所有东西都大，等于都不大 |
| 明暗反转 | 一组浅场中插入一页深场，或在深场里留一块亮区 | 为了"变化"切场，切完没有叙事理由 |
| 方向对冲 | 文字横排，图像或色带用斜向、竖向压过去 | 斜线只是装饰，和内容没关系 |
| 密度断层 | 极密的一页之后接一页极空 | 空页没有主角，变成没做完 |
| 切边出血 | 主体或色块被画布边缘切断，暗示世界延展 | 关键信息被切掉 |
| 单一破例 | 整稿都在网格里，只一页跨轴或超大字 | 每页都破格，就没有破例 |
| 空白围合 | 用连续负空间把主角围起来 | 零碎缝隙冒充留白 |

### 平衡、边缘与动势

- **平衡**：对称靠数量，非对称靠回秤。偏重一侧之后，让对侧用连续负空间、对齐轴、图像视线或必要的次级信息把它拉回来；没有回秤的偏重就是失衡。
- **边缘与留白**：贴边、出血表达世界延展；内收表达秩序。留白要保护焦点、分组、停顿或容纳视线。极空但主角没分量，也不是克制。
- **轴线与密度**：先用邻近、对齐、间距分组，再考虑容器。无关轴线越多越乱。把需要连读的信息组织成密度块，其余空间服务阅读。
- **动势**：有顺序才有方向；有主次才有引导；有累积才谈积聚；需要理解结论时才停顿。静态对照、严肃表格、真正并列可以完全没有主导运动。

## 版式语法

可调用的设计语言，不是模板。先判本页的信息关系与叙事职责，再选语法；同一语法在相邻页重复，必须有同轴比较的理由。

| 语法 | 何时用 | 关键手法 | 危险 |
| --- | --- | --- | --- |
| 网格秩序 | 多信息、需要严谨层级 | 严格列网格、左缘对齐轴、留白节奏 | 变成没有主角的方格墙 |
| 编辑式 | 故事、人物、观点 | 大标题跨栏、导语、图文分场 | 装饰压过论证 |
| 非对称 | 需要张力与方向 | 偏轴、重轻对比、对侧负空间回秤 | 失衡、无回秤 |
| 字体主导 | 标题本身就是主张 | 字号尺度、断行重音、字重对冲 | 可读性被牺牲 |
| 图像主导 | 图像承担叙事或情绪 | 全出血、安静区叠字、主体偏置 | 主体与文字互抢 |
| 数据主导 | 证据即结论 | 大数字、直标、图表占主 | 数据淹没结论 |
| 图解主导 | 机制、流程、结构 | 基线、分支、层级、数量编码 | 装饰线暗示不存在的关系 |
| 模块化 | 复杂信息分组 | 模块网格、对齐分组 | 平均铺满、容器套容器 |

**角色到语法**：`open` 用图像主导／字体主导／编辑式建立世界；`build` 依关系在网格、数据、图解之间选；`turn` 用非对称、切边出血或明暗反转制造反转；`breathe`/`hold` 用大量留白与单一焦点；`close` 用字体主导或编辑式收回一句结论。

破格（出血、跨轴、超大字）要能说出理由；说不出就回到网格。**满幅大图＋居中标题不构成新的语法**——它是图像主导的默认做法，用之前先问主体在哪、安静区在哪。

## 信息设计

### 先选形式，再选图形

按顺序挑最小的够用形式，不要一上来就画图：**一个数字 → 一句话 → 表格 → 图 → 图解 → 组合页**。

一个关键指标、一个落差，就用大数字＋一句限定；需要精确读数、多列对照、口径各异，用表格；需要看形状、趋势、分布、占比，用图；关系比数值更重要（流程、结构、依赖、分支），用图解；一段论证需要证据与结论同时在场，才做组合页，并明确谁主谁次。

### 关系决定图形

先写清**实体、关系、方向与范围**，再问：有没有真实时间、可比数值、共同分母、节点归属、条件与证据？数据的精度与不确定性允许什么结论？

| 关系 | 用什么 | 必查与退路 |
| --- | --- | --- |
| 比较 | 竖向柱比量级；横向条比排名与长标签；点、哑铃、斜率适合成对差异 | 柱／条必须含零点；不同口径、缺失值不画成可比 |
| 时间 | 序列用事件轴；日期间距有意义时按真实比例；路线图区分已发生与计划 | 流程先后不等于日期；时区、工期未知就不画伪比例 |
| 组成／数量流 | 饼／环用于少量互斥部分与共同整体；堆叠看构成变化；百分比堆叠看份额迁移 | 先确认分母、单位、互斥、可加性；百分比堆叠每列必须合计 100 |
| 分布／统计 | 散点看配对关系；气泡须说明面积映射；直方图按真实分箱宽度 | 分布不等于均值；相关不等于因果；缺样本、区间、分箱边界不臆造 |
| 因果／风险 | 因果链、鱼骨、回路、影响图、故障树按已知机制与条件组织，区分观测、已确认路径与假设 | 共现、相关、先后都不证明因果；机制未知就先列事实或假设表 |
| 流程／决策 | 分支让方向、条件、出口可追；泳道交代责任；状态图交代触发与转换 | 分支条件不能互相误读，出口要完整；顺序不是持续时间，也不是因果 |
| 结构／依赖 | 层级树表达归属；系统架构表达组件边界；数据流标方向与载荷 | 归属不是依赖，连接不是方向；未知边与基数不编造 |
| 战略／优先级 | 2×2、风险矩阵先写轴、方向、阈值与位置含义；帕累托先核对可加总 | 象限与颜色不是证据；无阈值就别摆精确位置，改用带状态的清单 |

### 量级与比率不共轴

把量级与比率画在同一根轴上，是商业演示最常见的失真。三条路，按顺序选：**换算到同一单位**（都改成亿元、都改成指数、都改成人均）→ **拆图**（一页两张图，共用基线，各自带轴）→ **放弃**（把比率写成一句话或一个大数字）。不要用双数值轴：两个轴永远能让任何两条线"看起来相关"。

### 绘制与标注

先确定读者从哪里读到哪里，再安排重心、主次尺度、密度块与连续负空间。以对齐与邻近分组；线、节点、边界、箭头、标记、颜色各有职责。能直标就别放远距离图例；分支标签贴近对应路径。不要强迫元素等大、居中、平均铺开。

页题只说证据支持的结论；图题、单位、期间、分母、来源与限定要可见。类别少而读数重要时直标，只在直标足以读数时收起数值轴。程序能筛查数值、单位、期间和部分方向，但不能证明来源、因果、共同分母或设计质量。

**图表收尾**：柱与面积从零起，截轴必须写明起点；一根数值轴、一根类别轴，线色比网格深一级；只在需要横向参照时留水平网格，颜色接近底色；图例只在两个以上系列且直标不可行时用，顺序与图形一致；表格用细横线分组，不用斑马纹与竖线，数字右对齐、文本左对齐，表头字重比正文重一档而不是加底色块；饼与环不超过五类，类别多、差异小、要跨期比较就换条形。

## 排版

### 角色与层级

先给每块文字一个职责，再给样式：论断、支撑、限定、来源、读数。层级由**字号、字重、墨阶、位置**四者共同承担；任何一项够用时，不要叠加其余三项。

- 标题写论断，不写话题（"留存才是增长"，不是"增长分析"）。
- 数字、单位、期间、正负号是一个语义组，永远同组、同基线；单位用小一号或 `runs`。
- 来源靠近它所说明的对象；口径与限定的字号可以小，但不能省。
- 强调用墨色或字号，不靠合成加粗——投影时合成粗体会发虚。

### 字号阶梯

按观看场景定，不是按页面尺寸定。

| 场景 | 论断标题 | 正文 | 关键数字 | 备注 |
| --- | --- | --- | --- | --- |
| 大厅／远距离发布 | 44–64 | 24–28 | 96–160 | 少字，一页一事 |
| 会议室投影／路演 | 30–44 | 17–22 | 60–120 | 默认起点 |
| 屏幕共享／会后深读 | 24–32 | 14–18 | 36–72 | 可适度加密 |

- 级差拉开 1.25–1.6 倍；整稿字号档数通常不超过 5 级。差不够时用字重、墨阶或位置，而不是再加一档。
- 推导顺序：定正文档（观看距离决定下限）→ 乘 1.4–1.6 得标题 → 数字取标题的 1.6–2.5 倍 → 注释取正文的 0.7–0.8。
- 正文行长：投影一行 18–26 个汉字，深读不超过 32 个。超过就换行、加栏或减字。
- 行距：展示类 1.05–1.15，正文 1.25–1.4。行距不是用来塞字的工具。
- 安全边距：除出血元素外，文字距画布边缘不小于 0.5 in，避免投影裁边与打印被切。
- 4:3 画布更窄，列宽与每行字数同比缩小，不要照搬 16:9 的坐标。

### 断行

按语义断，不按字符数均分。

- 找分句与主张重心，断在分句处："无糖是入场券，／口感才是复购的理由"。
- 不拆开：数字与单位、期间与数值、正负号、专名、年份区间。"2026 年第三季度／营收 13 亿元"，不是"2026 年第三季／度营收 13 亿元"。
- 末行不孤字：最后一两个字单独成行时，回头改文案或改宽度，不要用空格推。
- 行首不放 `，。、）」』】` 等收尾标点，行尾不放 `（「『【` 等开启标点。这些只能在真实渲染里查。
- 手动换行用 `\n`；同一行内不同字重或颜色用 `runs`，不要拆成两个文本框——拆框必然基线漂移。

### 中西混排与数字

- 中文与西文、数字之间留 1/4 到 1/2 字宽的空隙，或依赖字体原生字距；整稿体例一致。
- 中文用全角标点，西文词内用半角；引号与括号的层级前后一致。中文正文可两端对齐，但西文多的行会出现字间空洞，宁可左对齐。
- 同行中英混排用同一字族的西文部分，避免中文黑体配西文衬线造成基线错落。
- 表格与需要竖向对齐的数字用等宽（tabular）数字；千分位、小数点、单位、币种、百分号整稿统一（`12.4%` 不要与 `12.4 %` 混用）；负数用减号 `−`（U+2212）。
- `letter_spacing_pt` 只用于标题重音与超大字；正文加字距会破坏阅读节奏。

### 字族

选字先看四件事：**骨架**（衬线／无衬线／等宽）、**字面率与 x 高**、**笔画对比**、**可用字重与西文配套**。先按职责选：展示（标题、数字）、阅读（正文）、信息（注释、来源）；字重足够区分时，不必用两种字族。

- 中文字体的西文部分常是短板：同行混排英文与数字时，先看它的西文字形是否与中文同族。
- 字体名只有在观看机器上存在才生效；缺失时 PowerPoint 静默替换，宽度与断行都变。微软雅黑是 Windows 常见字体，不要假定 macOS 或 Linux 上有；苹方只在苹果系统；思源黑体／Noto Sans CJK 开源可商用，但需目标机安装。
- 要多平台放映，就选目标机实测可用的字体并写进 `fonts`；商业字体先确认授权。只用目标字体真实存在的字重档位，不依赖合成粗体。编译器只写字体名，不嵌入字体文件。

## 色彩

### 先定职责，再定颜色

| 职责 | 承担什么 | 注意 |
| --- | --- | --- |
| 底色场 | 页面明度基调 | 决定前景墨阶，不只是"好看" |
| 中性墨阶 | 主标题、正文、辅助三级 | 层级主力；可以没有彩色 |
| 品牌色 | 识别 | 硬性品牌值不可擅改，但可改位置、面积、角色 |
| 强调色 | 指向结论或行动 | 按**职责**稀缺，不按次数 |
| 状态色 | 增长、风险、通过 | 跨页语义一致；涨跌红绿先确认市场约定 |
| 数据色 | 类别、顺序、重点 | 见下 |

同一个色可以兼任角色，但不能让语义含混。品牌亮黄在白底不可读时，保留品牌值、换角色（色条、深底锚点）或换背景，不要偷偷调浅。

### 五步构建一套色

1. **明度骨架**：先定底色、主墨、次墨三个明度层，算最坏情况下的对比。骨架不对，色相怎么调都不对。
2. **色相策略**：单色（最稳，靠明度分层）／邻近（同族变化，适合叙事）／互补（冲突与转折）／三角（多类别）。整稿只选一种为主。
3. **面积分配**：大面积给中性或深场；强调色面积通常 ≤5%，品牌色可到 15%。面积决定气质，色相只决定味道。
4. **冷暖对位**：一个场只能有一个温度主导。冷底上的一个暖点自然会成为焦点——这正是强调的物理基础，也是滥用的地方。
5. **材质联动**：图的色温决定版面中性色偏冷还是偏暖。图是暖纸，版面用冷灰就会脱节。

### 明度先于色相

先定背景明暗与观看环境，再建前景的可辨墨阶，最后选色相、饱和度与冷暖。深底同样要有适合该场的前景层级，不是把浅底的颜色反相。

叠图或渐变上的文字，看的是**字形实际落点的最不利背景**，不是平均色。墨色相同，面积、字重、材质不同，视觉重量也不同——一平方英寸的纯黑压得住四平方英寸的浅灰。

### 深浅场

切换要有叙事或阅读依据（转折、开场、沉浸结论），并且**成套换前景**：

- 浅场墨阶约 `#111827 / #374151 / #6B7280`；深场约 `#F3F4F6 / #D1D5DB / #9CA3AF`，图表系列要换成深底可辨的明度与彩度——浅底色板直接搬来会"沉下去"。
- 全出血图的角区明暗常与页面底色不同，页码要按实际角区声明 `page_number_tone`。
- 渐变蒙版的末端透明度要接近 0，否则蒙版边界会在图上显出一条硬边。

为了"变化"而切场，是整稿最常见的假深度。

### 数据色

- **分类**：互斥类别，彼此可辨，对常见色觉缺陷友好；别只靠红／绿区分状态。
- **顺序**：数值由低到高，同一色相明度单调推进。
- **发散**：围绕有意义的中心（0、基准、均值）两端冷暖；中心没有语义就改用顺序色。
- **重点**：强调一个类别、其余退到中性——但退隐的柱仍承载数值，必须仍然可读（编译器会按当页底色把中性色兜到对比下限之上）。

可直接用的起点（对红绿色盲较稳健）——分类 `#2F5597 / #C55A11 / #2E7D5B / #6A4C93 / #B08505 / #1F9DAA`；冷调顺序 `#F2F4F7 → #9AA7B8 → #4B5B70 → #1B2735`；暖调顺序 `#FBF3E7 → #E6B97A → #B5651D → #5C2E0E`；发散 `#2E5C8A ← #EDEFF2 → #B23A3A`；状态 `#1E7A46 通过/增长`、`#B58500 注意`、`#B23A3A 风险/下降`。

**灰度自检**：把整稿缩成灰度，类别与状态还能按明度区分吗？只靠色相的差异在灰度里消失，就要补线型、标记或直接标签。灰度可读不等于色觉无障碍通过。

### 高级感不等于低饱和

"低饱和＋低对比＋灰白"不是高级的定义。以下都可以是成熟方案，区别在职责与执行：

| 方向 | 适用 | 风险 |
| --- | --- | --- |
| 精密中性 | 专业报告、咨询、金融，靠墨阶与留白建立秩序 | 冷、空、没有记忆点 |
| 高饱和品牌场 | 消费、发布、文化事件，大面积强色建立识别 | 抢阅读、色觉疲劳、投影偏色 |
| 双互补撞色 | 冲突、转折、强对比主张 | 过度对抗、破坏层级 |
| 深色戏剧场 | 发布会、夜间、沉浸结论 | 前景墨阶没拉开、图表编码失效 |
| 暖色编辑场 | 人、食物、生活方式、叙事 | 与冷数据并置时语义错配 |

用强色时靠四件事保持秩序：强色只出现在主视觉场与强调处，其余交给中性墨阶；用明度而不是色相承担层级；强色面积受控（色块、色条、锚点），不铺满；跨页保持同一套色相与语义，用面积与明暗制造变化。

### 可读性

正文对比不低于 4.5:1，24pt 以上大字不低于 3:1——这是可辨的下限，不是好看的标准。图表里的小标记、细线、直标要留更宽的余量，投影、低亮度、旧屏会压缩对比。达标不等于好看；不好看也不等于不可读，两件事分开判断。

## 图像

### 先选路线

| 路线 | 何时用 | 边界 |
| --- | --- | --- |
| 真实素材 | 具体产品、真实人物或现场、可核查的证据 | 核实来源、权利与隐私；不为配色涂改证据 |
| 原生图形 | 数值、结构、关系或流程本身就是内容 | 只画已知关系，不用装饰冒充机制 |
| 生成图 | 可虚构的概念、氛围或理想化场景 | 登记真实生成记录；不能证明真实对象、现场或数据 |
| 纯排版 | 合格图片没有独特职责，或合理成本内不存在 | 事实需要具象证据时，要报告素材缺口，不能假装完整 |

**先问职责**：它承担证据、结构、语境、情绪还是质感？删掉会损失什么？与整稿图像世界和最终裁切一致吗？答不出就不用图。

### 简报（落位之前想清楚）

按最终用途写四件事，缺一条就别开提示词或选片：

1. **视觉意图**：服务哪个主张。
2. **主体与景别**：识别结构、机位、占比、朝向。
3. **最终裁切与文字安静区**：叠字区必须是连续、低纹理、低对比的安静区；不叠字就写 `none — no overlay`。
4. **淘汰条件**：可观察的否决项，例如"瓶身接缝不可辨即淘汰"。"显得高端"不是简报。

### 提示词

顺序是：**用途与主体（结构必须正确）→ 构图与落点 → 光 → 材质 → 色与明度 → 环境 → 风格 → 少量负向排除**。只写会影响本图结果的约束。

- 差："高级香水广告，电影感，极致质感。"——主体、落点、光都没有。
- 可执行："概念产品摄影，主体是一只无标签的矩形厚玻璃瓶，深琥珀液体与深色金属盖结构完整；瓶身位于横幅右侧三分之一，左侧留连续暗区给白字；右上柔光在玻璃边缘形成连贯高光，瓶底有接触阴影；色域以炭黑与琥珀为主，不出现任何文字。"

一条"主体结构＋落字区＋光向"胜过十句"高级、电影感、超清"。堆长串否定词会稀释主体指令。模型参数只在工具真的支持时才写，不虚构。

### 画幅与裁切

提示词必须和最终版面画幅一致，否则一裁就废。16:9 全出血把主体放一侧或下三分之一，为标题留真实可用的空间；竖版和侧栏更窄，主体更集中，文字区更受限。

`crop_focus` 是等比裁窗的**中心位置**，不是"程序认出了主体"。每次换裁切都要重看：主体关键部分还在吗、朝向还对吗、安静区还在吗、有效分辨率够吗（低于 72 ppi 投影会发虚）。

### 把图压进整稿色域

同一份稿里的图来自不同拍摄、不同生成、不同年代，色温与饱和会各自为政。三种处理，按侵入程度排：

1. **选**：只留与 `brief.art` 同族的图；不同族的宁缺勿滥。最省事也最有效。
2. **压**：`duotone` 给暗部与亮部各一个颜色，把图压进整稿的墨阶与色域。单色稿常用「炭黑 + 纸白」，暖场用「深褐 + 米白」。它替换色相，不改明暗结构——主体的结构仍要看得清。
3. **收**：`alpha` 或渐变蒙版降低图的权重，让它退回承载层，文字与数据留在前景。

不要用双色调掩盖一张结构不对的图：伪文字、错部件、糊掉的接触阴影，压成单色仍然是错的。`duotone` 在 PowerPoint 生效，LibreOffice 只做去饱和——渲染里"看起来灰了"不等于色相验证通过。

### 三级检查

1. **原图**：符合简报吗？主体结构、透视、接触阴影、反射、材质可信吗？有伪文字、重复肢体、错误部件吗？
2. **最终裁切**：主体残缺吗？方向还对吗？文字区还在吗？
3. **整页与相邻页**：文字与图的主次成立吗？光色与媒介和整稿同族吗？

机器对比检查不等于这三级通过。生成失败先定位根因（结构、画幅、光、职责），再决定重试或换路线；不以反复抽图代替判断。重大缺陷反复出现且没有进展时，换路线。

### 真实性的边界

生成图不能作证据，不能替代真实产品、人物、现场与数据；有可核查外观要求时，先拿到真实素材。生成图里的伪文字、假界面、假数据不能当真实信息，需要精确标注就用原生文字层。真实照片与截图里的文字、品牌、水印可能与证据有关：核查权限与可读性，不要为了统一色调擅自抹除。权利未确认就写 `pending` 并在交付说明里点明；不要伪造授权，也不要用占位图冒充。

## 诊断

症状只是入口。按根因归类，**上游优先**——内容与事实、信息架构一变，下游的构图与排版修改可能全部作废。后六行是"模板味"，它们是症状不是禁令：能说出它在本页承担的职责，就可以留。

| 症状 | 根因 | 处理 | 不要 |
| --- | --- | --- | --- |
| 数字与文字打架 | 内容与事实 | 回到口径与来源，标未决 | 用强调掩盖证据缺口 |
| 无来源的"权威"数字、占位 Logo、假头像 | 为显得完整而补造 | 删除或标未决；示例数据在页面上写明"示例" | 把生成图当证据 |
| 每页都对，整稿不对 | 视觉概念 | 重写洞察句与概念，重定锁定项 | 逐页涂抹风格 |
| 图很干净但整稿没气质 | 艺术指导 | 重定五参数，统一光与色温 | 换更多图，加滤镜 |
| 读不出数据、翻页疲劳 | 信息架构 | 回到口径、主张与乐谱，调整直标与密度 | 换装饰、随机换版式 |
| 图好看但读不懂 | 信息设计 | 换更小的形式；删到只剩必要节点与边 | 加图例、加箭头、加说明 |
| 不知先看什么、像模板 | 构图与层级 | 明确阅读重点，删去不承担关系的容器 | 给配角一起加粗加色 |
| 发空、非对称不稳 | 构图与层级 | 检查主角分量、连续负空间、对侧回秤 | 用图标和装饰填满空白 |
| 拥挤、断行难看 | 字体与排版 | 编辑文案、加宽或拆页，按语义改断点 | 缩字号、压行距、用空格硬推 |
| 图一裁就废、叠字难读 | 色彩与图像 | 按落位框重选画幅或移动文字，看真实字形落点 | 靠居中裁切或浓遮罩碰运气 |
| 一页里既有深底又有浅底，前景都对不上 | 色彩与图像 | 明暗场成套换前景与图表编码，或干脆不切 | 只换底色，前景沿用 |
| 预览正常，现场发虚 | 渲染环境 | 记录环境、换字体或提高素材 ppi，交目标机复核 | 为迁就替代字体改设计 |
| 每页都是"标题＋三栏卡片" | 没按内容关系选组织方式 | 单一论断、对照、流程、同源数据各用不同空间组织 | 拿同一骨架套所有页 |
| 一条信息一个圆角卡片、卡片套卡片 | 用容器代替对齐与邻近 | 先用间距和对齐分组，容器只在需要承托或区分层面时出现 | 用卡片制造层级 |
| 图标阵列代替论证 | 没有真实关系 | 写出实体与关系；没有关系就一句话或一个数字 | 用图标凑版面 |
| 渐变、发光、玻璃拟态＝"科技感" | 行业词直接映射成风格 | 图像世界与材质由受众与证据推出 | 拿风格词当概念 |
| 页标题是话题（"市场分析""总结"） | 没有主张 | 改写成证据支持的论断；写不出就是未决 | 用栏目名占位 |
| 正文把图表里的数字再念一遍 | 图与文没有分工 | 图承担读数，文字只写结论与限定 | 让文字替图说话 |
| 强调色到处都是、标题下都有装饰条 | 强调不按职责稀缺 | 只保留指向结论或行动的那一处 | 逐页换强调色 |
| 一切居中、上下对称堆叠 | 回避取舍 | 找出主角，用尺度与连续负空间建立不对称平衡 | 用居中回避排序 |
| 无功能的英文装饰标签（OVERVIEW、KEY TAKEAWAYS） | 套模板气质 | 删除；确为导航需要则整稿一致 | 中英各写一遍 |
| 结尾只有"谢谢／Q&A" | 没有收束职责 | 收在决定、下一步或要带走的一句话 | 用致谢代替结论 |

自检顺序：缩略总览像不像同一模板复制 → 每页能否一句话说出主角 → 删掉任一装饰后信息是否受损。

## 复核维度

逐项给 `PASS / BLOCK / NOT VERIFIED`，每项必须写**实际依据**（机器事实、看过的哪一页 PNG、或仅 plan 声明）。没有依据的项记 `NOT VERIFIED`，不算通过。

| 维度 | PASS 需要看到 | 典型 BLOCK |
| --- | --- | --- |
| 1 语义与事实 | 关系、方向、条件、口径、时间与证据真实；相关和假设没被画成因果 | 无证因果、口径混画、数据与文字矛盾 |
| 2 层级与阅读路径 | 主张、重点、限定、来源按预期顺序被读到；并列没被错误拉开 | 一眼先看到的不是主张；配角和主角同重 |
| 3 构图与空间 | 主次比例、重心、连续留白、分组、相邻页节奏服务内容 | 发空或拥挤；重心无回秤；零碎缝隙冒充留白 |
| 4 图形与数据 | 基线、节点、线、箭头、带宽、统计编码各有职责且可回算 | 装饰线暗示不存在的关系；截轴未标；柱子没有零点 |
| 5 排版 | 断行贴合语义，数字单位同组，字号与观看距离匹配，实际字体与计划一致 | 数字与单位拆行、末行孤字、行首标点、替换字体后溢出 |
| 6 色彩 | 类别、状态、证据的编码一致可辨；前景墨阶随明暗场成套切换 | 强调处处有；深浅切换后前景不对；只靠颜色区分关键状态 |
| 7 概念与整稿 | 概念可追溯到洞察，有辨识度，且真正约束了图像、色彩、构图与字体；各页构成完整叙事，高潮与停顿可辨 | 换行业仍成立；概念只在字段里；缩略总览像同一模板复制或像几套稿拼接 |
| 8 效率与交付 | 每个元素说得出职责，删掉任一都有损失；真实渲染无裁切错位替字，可编辑性与环境风险已说明 | 装饰条、重复数字、无关图标、卡片套卡片；未渲染却声称已预览 |

**否决项不可抵消**：语义错误、数据失真、无证因果、关键内容不可读，先修，且不能被其他维度的表现、总分或机器通过率掩盖。第 7、8 项不能由机器回答，必须看图并写出依据。
