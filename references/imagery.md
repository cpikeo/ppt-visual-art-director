# 图片与视觉资产的艺术指导

图片是整稿里最贵的东西：一张对的图抵十段文字，一张错的图会让整稿掉价。本文只讲判断；字段见 `build.md`，整稿的光色世界见 `design.md` 二、七节。

## 一、先判路线，再谈画面

| 路线 | 何时 | 边界 |
| --- | --- | --- |
| 真实素材 | 产品、人物、现场、可核查证据 | 核实来源、权利、肖像与隐私；可以当证据 |
| 原生图形 | 数值、结构、流程本身就是内容 | 只画已知关系，不用图片冒充 |
| 生成图 | 氛围、概念、理想场景、静物 | 登记记录；**永远不是证据**，不承载文字与数据 |
| 纯排版 | 图片没有独特职责 | 一等方案，不是图片失败后的备选 |

没有职责的图不要放。职责说不出“删掉会损失什么”，就是装饰。

## 二、四类资产，四种语言

同一张图换了职责，好坏标准就变了。先在 plan 里写 `image_role`，再按它写简报。

**背景图（`background` `texture`）**：承载空间、气氛、光影，核心是**安静区**。
- 落字区连续、低纹理、明暗范围窄；主体与光推到另一侧，留出整块负空间，而不是靠遮罩压暗。
- 简报里写**明度数字**，不写“浅色”：“左侧墙面明度约 80–85%，左半任何位置不低于 70%”。生成工具对“浅”“暗”的理解很宽：本仓库样本里，第一版写了“暖纸灰”的墙面实际只有约 50% 明度，深色正文约 3.5:1，编译器量测报出 `W-CONTRAST` 后改写简报重出图，才达标。
- 背景是舞台不是主角：低饱和，纹理细而均匀，没有会吸走视线的小物件（有也只放在对角的边缘）。

**主题主视觉（`hero`）**：承载识别度与记忆点，核心是**一个只属于这份内容的概念**。
- 一个主体、一个冲突：尺度对比（小物件对大空间）、明暗冲突（一束光对大面积暗场）、材质反差（锐利玻璃对哑光石）、冷暖对位（一点暖对大片冷）。冲突多于一个就散。
- 视觉重心偏置，主体落在三分位，另一侧留给标题；用低机位、长焦压缩、浅景深制造纵深，不靠伪透视与特效。
- 检验：缩成缩略图，还认得出是这一套吗？换个主题还成立吗？成立，就是模板。

**插图（`illustration`）**：承载解释与质感，核心是**主体明确、结构完整**。
- 先定主体与陪体：主体占主导（体量、明度、位置），陪体小而反差鲜明（尺度、材质、色温），陪体不得抢戏。
- 物体不裁切、轮廓干净，能脱离版面独立成立；背景简单到可以融入页面底色。要融入场景，背景色取页面色。
- 结构类插图（器物、产品、建筑）重点验证透视、比例、接缝、连接处；结构错了不能用 `duotone` 掩盖。

**图标（原生优先）**：承载识别，核心是**语义准确、造型统一**。
- 图标只在需要被快速辨认时才有意义；一排装饰图标代替不了论证。
- 能用原生形状与路径画就用原生：可编辑、可换色、与字体同源。需要位图图标时，整组一次生成，统一线宽、圆角、留白、视角；逐个抽图必然不统一。
- 同一页只用一种图标风格；同组图标的视觉重量一致。

**人物与产品（`subject`）**：先判断是真实素材还是生成。真实产品与真实人物不用生成图替代。
- 重视姿态、比例、轮廓、材质、光线：人物看视线方向、肢体、手与五官是否自然；产品看比例、接缝、反光是否可信，单光源加接触阴影。
- 人物肖像要留意权利；生成的“人物”不能暗示真实个人或真实客户。

## 三、简报：五句话，缺一就别开提示词

其中三句写进 `assets.<id>.generation.brief`（`intent` `quiet_zone` `reject`），其余写进提示词：

1. **职责**（`intent`）：服务哪条主张，承担证据、结构、语境、情绪还是质感。
2. **主体与景别**：谁是主体、陪体是什么、机位、朝向、占画面多大。
3. **落字区**（`quiet_zone`）：文字在哪，那里要多安静、明暗范围多少；不叠字写 `none`。
4. **画幅与裁切**：提示词里的画幅与最终框一致；`crop_focus` 只是裁窗，每次换裁切都要重看。
5. **淘汰条件**（`reject`）：可观察的否决项，如“棱镜形体不完整即淘汰”“左半明度低于 70% 即淘汰”。

“显得高端”“有质感”不是简报。

## 四、提示词怎么写

顺序：**资产角色与用途 → 主体 → 构图与落点 → 空间与机位 → 光 → 材质 → 色与明度 → 画质 → 排除项**。每一句都要对应一个可观察的画面事实。

- 用具体名词与关系，不堆风格词：写“深色玄武岩台面上立着一块透明玻璃棱镜，暖光从左缘射入”，不写“高级、科技、电影感、大片”。
- 光写**方向、软硬、色温、光比**；材质写**表面状态**（哑或亮、粗或细）；色写**主色相范围、饱和上限、明度区间**。
- 构图写**位置与比例**：“主体在右侧三分之一、约 55% 高度”“左半是连续近黑”。
- 允许适度的优雅、神秘与戏剧张力：单一光源、大面积暗场、一点暖色、克制的反光。判据是服务主题、留有余地；观众先注意到“效果”而不是内容，就过了。
- 默认排除：文字、字母、Logo、水印、界面、手部与面部畸变、多余物件。精确文字永远用原生文字层；生成图里的“字形”一律视为缺陷。
- 同一系列只改一个变量（景别或光向）；整稿图排在一起，光向能连成线、色温是同一个世界、主体尺度不乱跳。

## 五、验收：三级看图

1. **原图**：结构、透视、材质可信吗？有伪文字、错误部件、融化的接缝吗？
2. **最终裁切**：主体残缺了吗？落字区还在吗？有效分辨率够吗（`W-PPI`）？
3. **整页与相邻页**：主次成立吗？光色同族吗？缩略总览里这张图是节奏的峰还是谷？

编译器会替你**量**图上文字的落点：对文字框正下方的真实像素（含裁切、`duotone`、`alpha`）算对比与纹理。`W-CONTRAST` 表示落点有大片像素达不到对比线，`W-BUSY` 表示对比够但纹理太碎。这只是静态近似（不含渲染器的色彩管理；图与字之间隔着色块或渐变蒙版时不适用，只给 `I-CONTRAST`），达标不等于好看，不达标说明**字没落在安静区**。

**不要靠加浓遮罩修**。处置顺序：移动文字 → 改 `crop_focus` → 改简报重出图 → 最后才是 `alpha` 或蒙版。生成失败先定位根因（是简报没写到数字，还是主体与落字区冲突），不靠反复抽图碰运气。

## 六、压进整稿色域

按侵入程度：**选**（只留与 `art` 同族的图，宁缺勿滥）→ **压**（`duotone` 替换色相，不改结构）→ **收**（`alpha` 或渐变蒙版降权）。`duotone` 在 PowerPoint 生效，LibreOffice 只做去饱和，量测用的是近似。

## 七、真实性与文件边界

- 生成图不当证据：`image_role: evidence` 不能指向生成图（`E-ASSET`）。
- 照片里的品牌、水印可能与证据有关，不为统一色调擅自抹除。
- 权利未确认写 `pending`，不伪造授权。样本图的权利状态就是 `pending`。
- 素材文件必须在素材根内；`image_id` 不接受绝对路径、`..` 与指向素材根之外的符号链接。
