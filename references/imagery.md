# 图片与视觉资产的艺术指导

一张对的图抵十段文字，一张错的图让整稿掉价。本文只讲判断与口径；字段见 `plan.schema.json` 与 `elements.md`，整稿光色世界见 `design.md` 二、`craft.md` 色彩。

## 一、三个维度，互不替代

| 维度 | 回答什么 | 字段 |
| --- | --- | --- |
| **素材来源** | 文件从哪来、权利归谁 | `assets.<id>.source` `generated`／`generation` `rights` `used_as_evidence` |
| **资产角色** | 在版面里是什么、坐在哪 | 元素 `image_role`：`background` `texture` `hero` `subject` `illustration` `icon` `detail`（旧写法 `evidence` 仍接受） |
| **信息职责** | 承担什么信息，删掉损失什么 | 元素 `info_duty`（`evidence` `structure` `identity` `atmosphere` `mood` `material` `none`）＋`asset_reason`；生成图另加 `generation.brief.intent` |

1. 来源不能由角色推断：`hero` 可真可生成；`info_duty: evidence` **只能**指向真实素材（唯一的来源约束，`E-ASSET`）。
2. 角色不能由职责推断：同一条证据，封面是满幅 `background`，论证页是右侧 `subject`。
3. 职责不能含糊：每张图写 `info_duty`；`none` 即纯装饰，收 `W-ASSET`，说不出“删掉会损失什么”就删。

**路线**：真实素材（产品、人物、现场、可核查证据；核实来源、权利、肖像隐私；只有它能当证据）｜原生图形（数值、结构、流程本身是内容，可编辑、随数据走，不进 `assets`）｜生成图（氛围、概念、理想场景、静物；登记工具、提示词、简报、SHA-256、权利；**永远不是证据**，不承载文字与数据）｜纯排版（图片没有独特职责时是一等方案）。

## 二、六种语言

同一张图换了角色，好坏标准就变。先定 `image_role` 再写简报。

- **背景（`background` `texture`，承载层）**：核心是**安静区**。落字区连续、低纹理、明暗范围窄；主体与光推到另一侧，留整块负空间，不靠遮罩压暗。简报写**明度数字**而非“浅色”：“暖纸灰”实际只有约 50% 明度，深色正文约 3.5:1，出 `W-CONTRAST`；改写成“左侧约 60% 近黑连续暗场、主体偏右三分之一”后一次达标。背景是舞台：低饱和、细而均匀的纹理，没有吸走视线的小物件。
- **主视觉（`hero`）**：核心是**一个只属于这份内容的概念**。一个主体、一个冲突——尺度（小物件对大空间）、明暗（一束光对大面积暗场）、材质（锐利玻璃对哑光石）、冷暖（一点暖对大片冷）；多于一个就散。检验：缩成缩略图认得出是这一套吗？换主题还成立吗？成立就是模板。
- **插图（`illustration`）**：主体明确、结构完整。主体占主导，陪体小而反差鲜明；物体不裁切、轮廓干净；结构类（器物、产品、建筑）验证透视、比例、接缝，结构错了不能用 `duotone` 掩盖。
- **图标（`icon`）**：语义准确、造型统一。只在需要快速辨认时有意义；能用原生形状就用原生；位图图标整组一次生成，统一线宽、圆角、留白、视角；同页一种风格。
- **人物与产品（`subject`）**：真实产品与人物不用生成图替代。人物看视线、肢体、手与五官；产品看比例、接缝、反光，单光源加接触阴影；肖像留意权利，生成人物不暗示真实个人或客户。
- **局部（`detail`）**：给抽象论断一个可感的表面；裁切须保住可辨认特征，裁到认不出就退化成 `texture`。

## 三、构图是情境判断，不是比例公式

三分法、主体占三分之一是结果，不是方法。先答六问：①主题要稳还是要紧？②主体是谁、画幅多大（先看素材自身重心再定裁窗）？③图文是并置比较（两侧可比）还是图承载空间（落字区连续）？④阅读路径怎么走（标题在左则主体在右，路径上不能有第二个竞争焦点）？⑤文字空间在哪（先定 `quiet_zone`，再定主体与光；反过来只能靠遮罩救）？⑥这页在整稿里多重（峰值页允许满幅出血，停顿页允许大面积空）？凡套公式得到的构图，都要过一遍“换掉主题还成立吗”。

## 四、明度、对比度、纹理：唯一口径

量测口径若不唯一，“简报写达标、量测报不达标”会无限循环。`model.zone_probe`／`zone_contrast` 与 `limits.json` 的 `image.zone` 按下表执行：

| 术语 | 定义 | 用在哪 |
| --- | --- | --- |
| **感知明度** | CIELAB L\*，0–100% | **写进简报与提示词**（“左侧墙面明度不低于 70%”） |
| **线性相对亮度 Y** | sRGB 展开 gamma 后按 `0.2126R+0.7152G+0.0722B` 加权，0–1 | 对比度计算的输入 |
| **对比度** | `(Y亮+0.05)/(Y暗+0.05)` | 正文 4.5:1，≥24pt 大字 3:1（`limits.contrast`） |
| **纹理** | 落字区灰度（sRGB 编码值，Rec.709 权重，0–255）减去 3px box 模糊后的 RMS——只量碎细节，不把平滑的雾、光晕、渐变当噪声 | ≤ 8.0（`image.zone.max_texture`，provisional，依据见 `dev/CALIBRATION.md`） |

两者不要换算：L\* 70 的灰面约 Y 0.36，压深墨约 8:1、压白字约 1.9:1。所以简报给生成工具写感知明度（“左半任何位置不高于 15%”），验收给自己写对比度（“深墨 `#1A1A1A` 在该区 ≥ 4.5:1”），缺一条就会“图看着够亮、字读不出”。

**量测方式**：区域＝文字框与图片的交集，按 `crop_focus` 反算回源图；处理链＝裁切 → `duotone` → `alpha` 与底色混合 → 才算亮度与纹理；对比：缩放到 40×40 共 1600 样本（BOX）取线性亮度，指标＝达标像素占比 ≥ 90%、最不利 5% 像素的对比度；纹理：另缩放到 128×128 做高通残差 RMS。不含色彩管理、图之上的其他元素、图与字之间的色块或渐变蒙版（隔了蒙版退回 `I-CONTRAST`，以真实渲染为准）。

**达标 ≠ 好看；不达标 = 字没落在安静区。** 处置顺序：移动文字 → 改 `crop_focus` → 改简报重出图 → 最后才是 `alpha` 或蒙版；不靠浓遮罩，也不改阈值。

## 五、简报与提示词

简报五句，缺一就别开提示词；前三句之外的写进提示词，其中 `intent` `quiet_zone` `reject` 写进 `assets.<id>.generation.brief`：

1. **信息职责**（`intent`）：`info_duty` 哪一档，服务哪条主张。
2. **主体与景别**：主体、陪体、机位（高度与朝向）、焦段感（广角透视或长焦压缩）、占画面多大。
3. **落字区**（`quiet_zone`）：文字在哪，多安静、明度多少（写数字）；不叠字写 `none`。
4. **画幅与裁切**：与最终框一致；`crop_focus` 只是裁窗，每次换裁切都要重看。
5. **淘汰条件**（`reject`）：可观察的否决项，如“棱镜形体不完整即淘汰”“左半明度低于 70% 即淘汰”。

提示词顺序：角色与职责 → 主体 → 构图与落点 → 机位 → 光（方向、软硬、色温、光比；暗部是否保留细节）→ 材质（表面状态）→ 色与明度（主色相范围、饱和上限、感知明度区间）→ 画质 → 排除项。用具体名词与关系：“深色玄武岩台面上立着一块透明玻璃棱镜，暖光从左缘射入”，不写“高级、科技、电影感”。允许适度的优雅与戏剧张力（单一光源、大面积暗场、一点暖色），判据是观众先注意到内容而非“效果”。默认排除文字、字母、Logo、水印、界面、手脸畸变、多余物件；精确文字用原生文字层。同一系列只改一个变量（景别或光向）。

**一致性来自世界**（同一套光、材质、色域、颗粒），不来自同一套滤镜；缩略总览里图可以互换、可以换成任何一家公司的年度稿，说明服务的是风格——换图，不换滤镜。品牌色是硬值，可调位置与面积，不偷偷调浅。

## 六、验收与边界

三级看图：**原图**（结构、透视、材质可信吗？伪文字、错误部件、融化的接缝？）→ **最终裁切**（主体残缺？落字区还在？有效分辨率 `W-PPI`？）→ **整页与相邻页**（主次、光色同族、缩略图里是峰还是谷）。

压进整稿色域，按侵入程度：**选**（只留与 `art` 同族的图，宁缺勿滥）→ **压**（`duotone`，PowerPoint 生效，LibreOffice 只去饱和，量测为近似）→ **收**（`alpha` 或渐变蒙版降权）。

真实性：生成图不当证据（`E-ASSET`）；照片里的品牌、水印可能与证据有关，不擅自抹除；权利未确认写 `pending`，不伪造授权；素材须在素材根内，`image_id` 不接受绝对路径、`..` 与指向根外的符号链接（`E-IMG`）。

**分工**：AI 判断这张图成不成立、独不独特、光与色是不是同一个世界、构图是否服务信息关系、简报数字是否到位——没有阈值也没有开关。编译器只量可计算的：几何与分辨率（`W-GEOM` `E-OVERLAP` `W-CROP` `W-PPI`）、像素（`W-CONTRAST` `W-BUSY` `I-CONTRAST`）、素材登记（`E-ASSET` `W-ASSET` `E-IMG`），不说“不好看”；它说“字没落在安静区”时给的是位置与数字，怎么改由你判断。
