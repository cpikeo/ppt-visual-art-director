# 信息设计、排版与色彩

做图表与信息层级、定字体与字号、定色彩系统时读本文（接 `design.md` 一至四）。

## 五、信息设计

**先选最小够用的形式**：一个数字 → 一句话 → 表格 → 图 → 图解 → 组合页。精确读数、多列对照、口径各异用表格；看形状、趋势、分布、占比用图；关系比数值重要（流程、结构、依赖）用图解；证据与结论需同时在场才做组合页，并明确主次。

**关系决定图形**，先写清实体、关系、方向、范围，再问：有没有真实时间、可比数值、共同分母、归属、条件与证据？

| 关系 | 用什么 | 必查 |
| --- | --- | --- |
| 比较 | 竖柱比量级；横条比排名与长标签；哑铃、斜率比成对差异 | 柱与条必须从零起；口径不同不画成可比 |
| 时间 | 时间轴；间距有意义时按真实比例；区分已发生与计划 | 流程先后不等于日期 |
| 组成 | 饼或环只用于少量互斥部分；堆叠看构成变化；百分比堆叠看份额迁移 | 分母、单位、可加性；每列合计 100 |
| 分布 | 散点看配对关系；直方图按真实分箱 | 分布不等于均值；相关不等于因果 |
| 因果、风险 | 因果链、影响图，区分观测、已确认路径与假设 | 共现、先后都不证明因果 |
| 流程、决策 | 分支标明条件与出口；泳道交代责任 | 顺序不是持续时间 |
| 结构 | 层级树表达归属；架构图表达边界 | 归属不是依赖；未知边不编造 |
| 优先级 | 2×2、风险矩阵先写轴、方向、阈值 | 象限与颜色不是证据 |

**量级与比率不共轴**。三条路：换算到同一单位；拆成两张共用基线的图；把比率写成一句话。不用双数值轴，两个轴总能让任何两条线“看起来相关”。

**四层分工**：页题说发现；图形呈现关系；图注说口径（单位、期间、分母、来源）；正文说意义与限定——正文重念图中数字即分工失败。**不夸大**：基线、坐标、比例、排序保持真实，不用面积、立体、截轴放大结论，多系列须有颜色之外的区分。能直标就别放远距离图例；分支标签贴近路径。

**图表收尾**：柱与面积从零起，截轴必须写明起点；一根数值轴、一根类别轴，网格比底色浅一级；图例只在多系列且无法直标时用；表格用细横线分组，不用斑马纹与竖线，数字右对齐；饼与环不超过五类。

## 六、排版

**角色与层级**：论断、支撑、限定、来源、读数，每块文字先定职责。层级由字号、字重、墨阶、位置共同承担，其中一项够用时不叠加其余。标题写论断，不写话题。数字、单位、期间、正负号是一组，同行同基线。强调用墨色或字号，不靠合成加粗。

**字号阶梯**按观看场景定：

| 场景 | 论断标题 | 正文 | 关键数字 |
| --- | --- | --- | --- |
| 大厅、远距离发布 | 44–64 | 24–28 | 96–160 |
| 会议投影、路演（默认） | 30–44 | 17–22 | 60–120 |
| 屏幕共享、会后深读 | 24–32 | 14–18 | 36–72 |

级差 1.25–1.6 倍，整稿不超过五档；差不够用字重、墨阶或位置，不再加一档。推导：先定正文，乘 1.4–1.6 得标题，数字取标题的 1.6–2.5 倍，注释取正文的 0.7–0.8。

**字体排印**：靠角色反差而非字号反差；整稿不超过两个字族；大字收紧、小字放松；标题与数字用 `pad_in: 0` 贴住对齐轴；巨型数字的单位降一档并换色（`runs`）；不用空格推位。

**行长与行距**：投影一行 18–26 个汉字，深读不超过 32；展示行距 1.05–1.15，正文 1.25–1.4。文字距画布边缘不小于 0.5 in。

**断行按语义断**，不按字数均分：断在分句处；不拆数字与单位、期间与数值、专名、年份区间；末行不孤字；行首不放 `，。、）」』】`，行尾不放 `（「『【`（这两条只能在渲染里查）。

**中西混排**：中西文之间全稿统一一种写法：默认不敲空格、依赖字体原生字距；采用单个普通空格（通行排法）也可，但须整稿一致并写进交付说明（`I-SPACE`）；多于一个、全角或不换行空格一律是错（`W-SPACE`）；中文全角标点，西文半角；同行用同一字族的西文部分；表格与竖向对齐的数字用等宽数字；负号用 `−`（U+2212）。

**中文字体**：先定角色再按目标机选字，写进 `fonts`：叙述与论断用衬线，数据、读数与正文用黑体。

| 角色 | 取向 | 字重 |
| --- | --- | --- |
| 论断标题 | 衬线，字面有笔画对比，大字才显出气质 | Bold；整稿一种 |
| 关键数字 | 黑体，拉丁数字在中文衬线里常偏细小，读数需要稳定字宽 | Bold |
| 正文、图表标注 | 黑体；投影不用 Light | Regular，强调用墨色或 Bold |
| 注释、来源 | 同正文字族，降字号与墨阶 | Regular |

| 目标环境 | 衬线 | 黑体 | 说明 |
| --- | --- | --- | --- |
| 自有或可控的放映机 | 思源宋体（Noto Serif CJK SC） | 思源黑体（Noto Sans CJK SC） | 字重齐全，跨系统同形；须在目标机安装（编译器不嵌入） |
| Windows 默认环境 | 宋体系统字体（字面偏瘦，只适合中大字号） | 微软雅黑 | 宽度与断行以实机为准 |
| macOS 默认环境 | 宋体-简 | 苹方-简 | 苹方只在苹果系统 |
| 不知道在哪放 | 选黑体单字族，以字重与字号做层级 | | 衬线缺失时替换差异最大 |

规则：字体名只在观看机器上存在才生效，缺失时 PowerPoint 静默替换，宽度与断行都变；声明字体的字重必须真实存在，否则是合成加粗，笔画发糊；中文没有真斜体，强调用字重、墨色或尺度，不用倾斜；大字（≥ 48pt）可 `letter_spacing_pt` 收 0 到 −1，注释里的英文大写可放松 +1；渲染中检出替换，结论只能是 `PARTIAL`。

## 七、色彩

色彩是关系系统：先有世界，再有颜色。不要先套色板再给它找理由。

**从事实推导**。依次问：内容里有什么真实颜色（产品、品牌、材质、图像）？使用环境是什么（投影、屏幕、印刷、明亮或暗室）？概念要求什么温度与明度？答案共同限定色域。品牌色是硬性值，可调位置与面积，不偷偷调浅。

**色彩方向**（整稿先写，再进页面）：三到五句落成 `brief.art.gamut`（色相范围、饱和上限、明度骨架、纯黑纯白能否用）与根 `palette`（只放数据色序列），覆盖：①品牌或事实色（硬值）；②主导场与温度；③唯一主强调色及语义；④中性色温（跟图与纸走）；⑤图片色域如何并入（取图中最暗最亮处的色相，让中性色、强调色向它靠；必要时 `duotone`/选图，而非整页滤镜）。方向要能否掉东西（“不用冷灰、不用荧光蓝”），否则只是色板。

**四种职责，不混用**：

| 职责 | 做什么 | 边界 |
| --- | --- | --- |
| 环境（底与大面积场） | 决定整体基调与前景墨阶 | 中性或同色相深浅；一个场只有一个温度主导 |
| 结构（墨阶、线、图表的非重点） | 承担层级主力，可无彩色 | 用明度分层，不靠色相换来“丰富” |
| 强调 | 只指向结论或行动 | 稀缺：整稿一个主强调色，面积通常不过 5%，且语义跨页一致 |
| 状态与数据 | 识别、分类、比较 | 互斥可辨；重点色突出一个类别，其余退到中性但仍可读 |

**中性色分四类**：环境（纸白、墨黑，带整稿色温）、结构（灰阶）、文字（对比达标的墨阶）、真实材质色（图里的木、金属、肤色，不被滤镜篡改）。图是暖纸，版面就不能用冷灰。

**明度先于色相**。先定背景、主墨、次墨的明度骨架并算最坏对比，再决定色相。同一色相的深浅也能成熟（单色系统不靠频繁换色制造丰富）；深底不是浅底反相，要成套换前景（墨阶、图表系列、页码）。

**深浅切换要有叙事依据**（转折、停顿、高潮），不为“变化”而切；深底不是浅底反相，要成套换前景。

**图表里的颜色各司其职**：语义色（谁是谁）、结构色（轴、网格、图例）、标注色（直标）、承载面（它们真正落在的底）是四件事。标注色跟着**落点**走：落在底上用结构墨，落在色块里按色块取深/白/黑墨，线与点的标注在读得清时沿用系列色以保持归属；永远先保可读，再谈颜色一致。图放在面板上，一切按面板算，不按页面。

**数据色**：分类色靠明度与色相共同区分；顺序色同色相单调推进；发散色围绕有意义的中心；多系列必须有颜色之外的区分方式（直标、线型、标记、位置）。编译器与核验器按灰度明度差（CIE L*）对**全部系列两两比较**，提示 `W-GRAY`／`V-GRAY`；默认色板已按明度错开，自定义色板要自己守住。

**自检三件事**：① 灰度：整稿转灰度，层级、类别、状态是否仍可辨？② 缩略图：色彩是否连续，变化是否有依据？③ 投影：浅场正文不低于 4.5:1，24pt 以上大字不低于 3:1，且留出投影衰减的余量。这是底线，不是好看的标准。

高级感不等于低饱和：用强色时只在主视觉与强调处出现，面积受控，层级由明度承担。
