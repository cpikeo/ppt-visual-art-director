# PPT 图像生成提示词规范

本文件是 `ppt-visual-art-director` 的条件性设计资源，仅在**需要设计 PPT 背景图、插图提示词，或对生成图像进行质量评审与迭代**时按需读取一次。本规范将上游已确定的页面叙事与构图意图转译为高可用提示词与控制策略，不替代上游内容判断，也不替外部生成器虚构本地图片文件。

## 一、决策主线与三级变量控制

遵循 **明确页面职责 → 继承整稿视觉语法 → 划分变量控制等级 → 适配模型能力 → 组装提示词 → 按需评审迭代**，简单任务直接输出精炼提示词。

### 1. 参考继承的四类职责

存在参考图、既有页面或品牌规范时，区分继承维度而非机械照搬原图：

- **风格继承**：沿用色温、材质、光线逻辑与媒介笔触，不复制原图无关对象。
- **结构继承**：沿用主体比例、透视层次与留白方位。
- **内容继承**：锁定特定产品形态、人物身份或关键识别细节。
- **版面适配**：严格依据本页标题、正文、图表的实际落位安排画幅比例与安静区。

### 2. 视觉变量三级控制（按出错后果分配精度）

- **必须锁定**：决定语义正确性、核心主体形态、关键动作/空间关系、品牌禁忌与文字承载留白方位。
- **适度引导**：色相冷暖倾向、光源质感、材质反射、景深虚实与构图动势。
- **保持开放**：不影响页面表达的环境次要细节与自然纹理，交由模型发挥，避免过度限定导致画面僵硬。

## 二、语义组织与两类 PPT 图像控制重点

### 1. 语义组织顺序（按需取舍，不输出机械字段表）

**用途与画幅 → 主体与空间关系 → 视觉焦点 → 色彩与物理材质 → 光照与景深 → 构图与落字留白 → 媒介一致性 → 必要的负向排除**。

优先描写具体物理与视觉关系（如漫射侧逆光、磨砂玻璃与拉丝金属反射差异、近实远虚层次），拒绝堆砌“极致高级、大师级、超清震撼”等无效空洞形容词。

### 2. 背景图 vs 插图差异化纪律

| 维度 | PPT 背景图（Background） | PPT 叙事/概念插图（Illustration / Hero） |
| --- | --- | --- |
| **核心职责** | 建立空间氛围与情绪基调，稳妥托举前景文字与数据 | 直观呈现核心对象、空间结构、对比或品牌意象 |
| **留白与落字区** | 明确指定标题/正文所在方位（如画面左侧 `45%` 区域）为低频、低对比、柔和过渡区，严禁高光噪点刺穿文字 | 主体轮廓在幻灯片实际尺寸下清晰易辨，关键部位远离裁切边缘（匹配 `16:9` 或分栏竖框真实长宽比） |
| **视觉权重** | 主动退后服从信息层级，不生成抢夺注意力的中心杂物 | 建立单一主体焦点，主次对象比例、朝向与连接关系准确 |
| **硬性禁令** | **严禁生成任何伪文字、乱码标题、图表框线、UI 边框或整页 PPT 模板结构** | **严禁以华丽视觉隐喻冒充真实科学机制或实测数据；无透明输出支持时不强求直接透明底，改为纯色净底便于合成** |

### 3. 中文与专业语境真实性

- 面向中文受众的人物与生活/办公场景，明确指定东亚人物面孔、自然衣着神态与真实建筑/室内细节。
- **主动排除廉价图库隐喻**：除非用户明确要求，严禁生成西装握手、振臂握拳、堆叠金币、发光大脑连线、悬浮全息折线等陈旧商业套图意象。

## 三、冲突优先级与模型适配策略

### 1. 约束冲突优先级

**任务与主体语义正确 ＞ 核心结构与对象关系 ＞ 版面画幅与落字可用性 ＞ 整稿视觉语言一致 ＞ 光影构图表现力 ＞ 次要装饰细节**。

正向描述优先把“要什么”说准；负向提示词只针对当前高发风险（如多余文字水印、肢体结构畸变、主体重复、边框杂物）精简排除，不附带冗长通用负面词表，且避免正负指令自相矛盾。

### 2. 执行层分工与模型中立原则

- **自然语言提示词**：负责主体、关系、材质、光影、构图与安静区方位。
- **模型控制与参考机制**：已知目标模型时使用其真实支持的画幅参数、风格/结构参考图或局部重绘；**未知目标模型时输出自然完整的模型中立提示词，绝不虚构专属参数或伪指令**；仅在模型支持独立负向字段时才拆分输出 Negative Prompt。
- **排版与设计工具层**：精确中文文案、真实数字图表、品牌 Logo 与像素级对齐一律交回 PPT 原生元素层完成，绝不试图靠生图模型“画出整页 PPT”。

### 3. 输出纪律

默认直接交付立即可用的高质量提示词（及必要的画幅/落字区简短说明），**不向用户倾倒内部检查清单或冗长自评报告**。未实际调用生图模型出图并查看图像前，绝不宣称“图像效果已验证”。实际纳入 PPTX 时，按 `scripts/plan.schema.json` 登记统一素材记录；生成属性、授权/隐私状态和证据用途必须明确，生成图不得声明为事实证据。

## 四、生成结果条件性评审与停止准则

仅在任务实际生成了图像后执行基于画面的评审：

- **阻断性缺陷（必改）**：主体错误、关键结构/伦理/文化语境失真、出现大面积乱码伪文字、或落字区剧烈杂乱导致无法排字。优先改主体关系、换参考控制或重设构图。
- **重要缺陷（定向微调）**：色调偏离整稿色板、焦点分散、裁切过紧。保留有效描述，仅定向修改问题变量。
- **停止信号**：主体准确、与整稿气质统一、放入目标幻灯片框等比裁切后落字清晰即停止迭代，不为微小纹理差异反复重抽。
